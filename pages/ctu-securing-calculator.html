計算根拠・適用上の注意

CTUコード：外力 F = m × 9.81 × cₓ,ᵧ

CSS Code：F(x,y,z) = m × a(x,y,z) + Fw(x,y) + Fs(x,y)

CSS先進の計算方法：CS = 最小MSL ÷ 1.5

CSS代替の方法：CS = 最小MSL ÷ 1.35

横滑り：Fy ≤ μmg + Σ(fy × CS)

縦滑り：Fx ≤ μ(mg − fz×Fz) + Σ(fx × CS)

fz は MSC.1/Circ.1623 Annex 13 の縦力補正係数（摩擦係数に応じた表値）を使用します。

横転倒：横転倒モーメント ≤ bmg + 0.9Σ(CS × c)

直接固定を含む方向では、CTUコード付属書7 2.2.2.2に従い、摩擦係数を入力値の75%として評価します。CTU境界抵抗は、貨物が強い境界内に密着して積み付けられ、荷重を境界へ適切に分散できること、および実際のCTU最大積載量Pを確認した場合だけ算入します。CTU種類の選択だけでは算入しません。支保・当て材と直接固縛は、簡易確認だけでは単純加算しません。詳細設定で承認された荷重分担・剛性・独立した荷重経路を確認した場合だけ加算モードを使用します。CTU境界抵抗と支保・直接固縛も、独立した荷重経路・剛性・承認根拠が確認できない限り単純加算せず、保守的に大きい方を採用します。

CSS Code Annex 13では、固縛器具の最小MSL、安全係数、固縛角度、転倒軸から固縛作用線までの距離、風圧力、波洗い力、船長・速力・B/GM補正および弾性差を確認します。頂部を越える固縛は、CSS Code Annex 13の平衡計算では抵抗力として算入しません。

本機能は参考算出です。非常に重い貨物・非常に大型の貨物、新規または特殊な用途、局部強度・溶接部・船体構造の評価が必要な場合は、検証済みの詳細計算、承認されたCargo Securing Manualおよび主管庁の指示を優先してください。
