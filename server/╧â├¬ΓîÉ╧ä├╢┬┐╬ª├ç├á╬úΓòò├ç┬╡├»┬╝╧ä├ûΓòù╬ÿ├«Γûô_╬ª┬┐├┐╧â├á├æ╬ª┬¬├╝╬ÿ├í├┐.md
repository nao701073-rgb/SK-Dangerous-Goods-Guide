# 利用者一括登録CSV 記入要領

|列|内容|
|---|---|
|login_id|半角英数字、ピリオド、ハイフン、アンダースコア。3～100文字。|
|display_name|氏名または表示名。|
|email|任意。ただしMFA利用者はメールアドレスが必要。|
|role|office-user / office-admin / safety-environment-director / safety-environment-staff / safety-environment-admin|
|office_id|検査員・事業所管理者のみ必須。安全環境室は空欄。|
|initial_password|空欄の場合は自動生成。登録後に初期認証情報CSVへ出力。|
|mfa_required|true または false。|

事業所管理者は原則1事業所1名です。安全環境室は室長1名、職員5名を想定し、氏名確定後にテンプレートを更新してください。
