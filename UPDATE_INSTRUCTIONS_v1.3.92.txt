SKDG v1.3.92 CTU 同率最厳方向表示・算出結果可読性修正

適用対象:
- v1.3.91 完全版

変更内容:
- 最厳方向の余裕／不足量が表示上0.1 kN単位で同率の場合、先に比較された方向だけを代表表示しない。
- 前方＋後方同率: 「前後方向（前・後同率）」
- 左＋右同率: 「側面方向（左・右同率）」
- 4方向同率: 「前後・側面方向（全方向同率）」
- その他の複数方向同率: 各方向名＋「（同率）」
- 算出結果上部の説明・抵抗内訳について、文字色、行間、余白、背景コントラストを改善。

変更しないもの:
- CTU Code / CSS Code の方向別作用力
- 摩擦・支保・CTU境界・直接固縛・トップオーバーの算式
- 最弱MSLロジック
- v1.3.81 三段階判定
- 申請番号連携
