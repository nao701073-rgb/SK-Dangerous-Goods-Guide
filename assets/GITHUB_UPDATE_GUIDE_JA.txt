SKDG GitHub 更新ツール v2

1. この3ファイルを SK-Dangerous-Goods-Guide の最上位へ置きます。
2. GITHUB_UPDATE.cmd をダブルクリックします。
3. 変更候補一覧を確認します。
4. 公開してはいけないファイルが含まれていないことを確認後、Y を入力します。
5. 初回だけ GitHub リポジトリURL、Gitユーザー名、メールアドレス等を入力する場合があります。
6. push に失敗した場合は force push をせず、その画面で停止してください。

注意:
GitHub Pagesなどで公開する場合、社内情報・個人情報・非公開資料をGitHubへ送らないでください。
