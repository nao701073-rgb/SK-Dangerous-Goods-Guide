Part 508 第2段階 更新手順

1. Part 507適用済みのシステムフォルダを複製して保管してください。
2. Part 508更新ZIPをフォルダ構成のまま上書きしてください。
3. serverフォルダで npm install を実行してください。
4. npm run migrate を実行してください。
5. APIを再起動してください。
6. システム管理者で「法令原典照合・承認管理」を開いてください。
7. 「照合対象台帳を更新」を実行してください。
8. 進捗件数が次と一致することを確認してください。
   危険物・判定基準 2,725件／コード 594件／法令原典 9件／合計 3,328件
9. 別の利用者による原典照合と承認を試験してください。
10. 正式運用への切替は、全対象の承認とIT室の本番環境確認後に行ってください。

CLIで台帳を作成する場合：
  cd server
  npm run regulations:catalog

静的検証：
  cd server
  npm run security:phase2
