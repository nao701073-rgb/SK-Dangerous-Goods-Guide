# Part 228 利用履歴監査・承認・保存管理要領

## 1. 目的
利用履歴の確認、異常利用候補の対応、定期監査レビュー、レビュー承認、保存対象の事前確認および定期レポート予定を一つの管理画面で扱う。

## 2. 基本方針
- 本システムの利用は任意とする。
- 利用頻度の低さや未使用を不適切利用と判定しない。
- 利用履歴はセキュリティ確認、不適切利用調査、障害調査、運用改善および正当な監査に限定して利用する。
- 管理者による履歴閲覧も監査ログへ記録する。
- 保存対象の事前確認画面では削除を実行しない。削除処理は別途承認されたクラウド運用手順に従う。

## 3. 監査レビュー承認
監査レビューを保存した後、システム管理者が承認または差戻しを行う。承認者、日時、コメントを記録する。

## 4. 保存期間管理
設定済み保存日数に基づき、保存期間を超えた詳細履歴、監査レビュー、対応記録の件数を表示する。件数確認結果を保存できるが、画面から即時削除は行わない。

## 5. 定期レポート
週次または月次の作成予定、対象範囲、次回予定日、通知先に関する備考を記録する。自動配信にはクラウド側の定期実行機能とメール設定が必要である。

## 6. 将来機能
透かし表示、スクリーンショット検知・追跡および画面自動保存は現時点では実装しない。
