# v1.3.37 危険物検索ヘッダー共通化

現在の危険物検索画面のヘッダーを、主要機能の唯一の共通基準とした。

## 共通寸法
- PCヘッダー高さ: 64px
- 左右余白: 16px
- 要素間隔: 10px
- タイトル: 1.38rem / 800
- 補助文字: 0.82rem / 600
- メニュー・ホームボタン: 42px四方
- 利用者ボタン: 38px以上、アバター28px

## 旧ヘッダー除去
対象17画面から以下への参照を削除した。
- v1333-header.css
- v1334-header-menu.css
- v1334-header-menu.js

主要ヘッダーは静的HTMLとして最初から配置し、DOMContentLoaded後のヘッダーDOM再構築を行わない。
これにより旧ヘッダーが一瞬表示される経路と、ヘッダー再構築による初期負荷を削減した。

## サブメニュー
初期状態ではDOM生成せず、メニューボタンを押した時のみ生成する。
