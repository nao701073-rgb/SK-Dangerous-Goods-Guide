# Part 325 更新内容

## ログイン画面の操作性強化

- 時間帯テーマを毎分および画面復帰時に再判定
- パスワード表示・非表示切替
- Caps Lock警告
- ログインボタンの二重送信防止
- フォーカス表示とスマートフォン表示の改善
- 100dvhおよびセーフエリア対応

## 維持する仕様

- 時間帯区分は06:00～10:00、10:00～16:00、16:00～19:00、19:00～翌06:00
- 色調変化はログイン画面のみ
- SKロゴ演出は認証成功時のみ
- ログイン後は既存の白・青基調
