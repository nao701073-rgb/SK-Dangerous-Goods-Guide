# Part 545 包装要件・P200許容容量・危告示原文ジャンプ

## 1. 目的

事前審査確認欄だけで、危険物ごとに「どの包装要件を参照したか」「許容容量・許容質量は何か」「原文のどこを確認するか」を追えるようにする。

## 2. 参照包装要件

各危険物No.の確認帯に「参照包装要件」を常時表示する。

- 申請書と危険物マスターが一致：一致表示
- 申請書に記載なし、マスターにあり：危険物マスターを参照
- 申請書とマスターが不一致：「包装要件 不一致・要確認」
- マスターに包装要件がある場合、事前審査上の参照先はマスターを優先し、申請書記載との差を警告する

## 3. 全包装要件の原文参照

危険物マスターで使用されるPコード84種類すべてについて、危険物検索と同じ `DOMESTIC_CODE_PAGE_RANGES` / `LEGAL_CODE_MASTER` を使用し、危告示原文ページへのボタンを表示する。

P112のようにページ範囲マスター側に単独エントリがないコードは、危険物検索で使用する法令コードマスターをフォールバックとして利用する。

## 4. P200

### 4.1 通常のP200

事前審査欄へ次を表示する。

- 溶接容器：1,000 L
- 継目なし容器：3,000 L

実際に使用できる容器、充てん定数、最大圧力その他の条件は、P200の当該国連番号の行を原文で確認する。

### 4.2 P200当該欄が「x」の国連番号

一般のP200許容容量を表示して適合扱いにはしない。従来ルールを維持し、次の文言をそのまま表示する。

**地方運輸局長の許可が必要です。**
危告示別表第1 P200の当該欄は「x」です。社内既存システムの許可証データベースに登録された許可証から、使用容器と許容容量を確認してください。

同時に「地方運輸局長等の許可確認が必要」を有効にし、確認事項へ同じ内容を保持する。

### 4.3 P200原文ページ

危険物検索側と同じP200原文分割ロジックを使用し、国連番号が掲載されているページを特定する。

例：
- UN1077 → PDF 301頁
- UN1953 / UN1954 → PDF 302頁

## 5. 維持する既存ルール

- 個数、1容器当たり正味質量、許容容量・許容質量の強調
- 同一単位で規定量を超えた場合の「規定量超過・要確認」
- Lとkgは換算しない
- Lとkgの数値差が±20%以内の場合だけ「容量比較 要確認」
- 少量危険物は従来の内装容器上限・外装容器総質量30kgルールを使用
- 編集フォームは維持

## 6. IBC容器への対応

危険物マスターのIBC要件と申請書の実際のIBC容器コードを組み合わせ、IBC容器の種類・材質・細分類まで解析して最大内容積を表示する。特定の代表コードだけを個別対応せず、危告示 別表第1 備考6(3)(ii)・(iii)のコード体系全体を共通ロジックで扱う。

### 6.1 材質コード

プラスチック製内容器付複合IBC容器の `HZ` の `Z` は固定文字ではなく、実際の外装容器の材質記号へ置き換える。次の全材質を扱う。

- A：鋼
- B：アルミニウム
- C：天然木材
- D：合板
- F：再生木材
- G：ファイバ板
- H：プラスチック材
- L：織布
- M：紙（多層のもの）
- N：金属（鋼又はアルミニウム以外のもの）

したがって、原文上の `31HZ1` は実容器では `31HA1`、`31HB1` 等のように材質記号へ置換されたコードとして扱う。原文の `HZ1/HZ2` をワイルドカードとして照合し、全材質コードに適用する。

### 6.2 複合IBCの細分類

- 末尾1：内容器が硬質プラスチック製
- 末尾2：内容器がフレキシブルプラスチック製

この細分類と外装材質を組み合わせて最大内容積を判定する。

### 6.3 最大内容積

危告示の最大内容積表に従い、次のとおり判定する。

- 容器等級I・固体：金属製IBC容器は3,000 L。
- 容器等級I・固体：硬質プラスチック製、複合、フレキシブル、ファイバ板製、木製IBC容器は1,500 L。
- 容器等級II・III：原則3,000 L。
- 容器等級II・IIIの液体用複合IBCで、外装材質が鋼（A）又はプラスチック材（H）、かつ内容器がフレキシブルプラスチック製（末尾2）のものは1,250 L。

例として `31HA1` は外装が鋼、内容器が硬質プラスチック製のため、上記1,250 Lの例外には該当しない。一方 `31HA2` と `31HH2` は、容器等級II・IIIの液体用途では1,250 Lの条件に該当する。これは代表コードだけの特例ではなく、材質記号と細分類を解析した共通判定である。

### 6.4 IBC包装要件との照合

IBC01～IBC08、IBC100、IBC520、IBC620、IBC99等の原文に `31HZ1` のようなコードが記載されている場合、実容器コードのZ相当位置を材質記号として照合する。例えば原文の `31HZ1` は `31HA1`、`31HB1`、`31HC1`、`31HD1`、`31HF1`、`31HG1`、`31HH1`、`31HL1`、`31HM1`、`31HN1` を同じコード体系として照合できる。

IBC520は国連番号・化学名・IBC種類により容量が異なるため、当該UNの行から候補を抽出し、必要な場合は化学名確認とする。原文ボタンは危険物検索と同じ国内法令マスターを使用する。

## 7. ポータブルタンクへの対応

申請書の容器コード・容器種別等からポータブルタンク使用が明確な場合は、危険物マスターのTコードを主参照要件として表示する。

- T1～T22は最小試験圧力、タンク外板最小板厚、圧力安全装置、底部開口条件を表示する。
- T23、T50、T75は国連番号・物質・ガス等に応じた個別条件を表示し、原文確認へ直接ジャンプする。
- Tコードは一律の最大内容積を示すコードではないため、固定のL値を推定しない。実タンクの許可容量・充てん条件等が必要な場合は別途確認事項として残す。
- すべての使用中Tコードについて危険物検索と同じ危告示原文参照先を使用する。

## 8. 容器コードによる参照要件の優先順位

事前審査では次の順序で主参照要件を決める。

1. 容器コードがIBCコード（11/13/21/31系）で、危険物マスターにIBC要件がある場合：IBC要件を優先。
2. 容器コード・容器種別がポータブルタンクを示し、危険物マスターにTコードがある場合：T要件を優先。
3. 上記以外：小型容器のPコードを使用。
4. 判別できない場合：候補を表示し「要確認」として手入力を可能とする。

主参照要件以外にも危険物マスターにIBC/T/P要件が登録されている場合は、「他の容器要件」として簡潔に表示する。
