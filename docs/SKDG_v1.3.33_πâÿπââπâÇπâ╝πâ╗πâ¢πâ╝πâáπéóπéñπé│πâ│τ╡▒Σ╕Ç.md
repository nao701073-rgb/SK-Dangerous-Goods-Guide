# SKDG v1.3.33 ヘッダー・ホームアイコン統一

## 基準
申請番号管理のヘッダーを共通基準とし、主要機能のホーム導線・タイトル位置・利用者表示を揃える。

## 対応
- 危険物検索 / 危険物詳細: 共通ホームアイコンをヘッダー左側へ追加
- 申請書取込・確認: 戻る矢印をホームアイコンへ統一
- 固縛力参考算出: 共通ヘッダーを追加し、本文内の重複ホームリンクを削除
- 改善要望 / 検索履歴: ホームアイコンのSVG、サイズ、背景、角丸を統一
- 関連法令 / 関連資料 / オーバーパック表示作成 / ユーザー設定等: 共通ヘッダールールを適用
- 利用者名ボタン: 実表示名・ユーザー設定遷移を維持
- 権限制御: v1.3.30仕様を維持
