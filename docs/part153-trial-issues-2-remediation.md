# Part 153 試験運用課題その2への対応

## 対応項目

### 1. CSCの二重表記解消
国際条約・国際規則画面で、CSCの英語正式名称が二重に表示されていたため、重複する表示項目を削除しました。

### 2. 主要機能画面のホームボタン左寄せ
各主要機能画面のヘッダーにあるホームボタンを左側へ統一しました。スマートフォンで左手操作しやすい配置です。

### 3. 原文ページ図表・イラストの前面表示
P520、D、SW1、SP122等のコード詳細から原文ページ画像を開いた場合、画像拡大画面がコード詳細画面より常に前面に表示されるよう、重なり順を修正しました。開いた際に拡大画面へフォーカスし、先頭位置から表示します。
