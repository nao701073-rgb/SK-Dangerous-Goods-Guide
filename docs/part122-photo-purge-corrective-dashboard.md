# Part 122 写真完全削除・是正処置ダッシュボード

## 概要
月次照合で検出した要確認事項について、是正処置の進捗、対応期限、担当者別件数、期限超過、管理者へのエスカレーションを一画面で確認できるようにしました。

## 主な機能
- 対応中、完了確認待ち、期限超過、管理者エスカレーション、完了の件数表示
- 対象月、事業所、状態、キーワードによる絞り込み
- 担当者別の未処理件数表示
- 期限超過案件の抽出
- 未完了案件を管理者へエスカレーション
- エスカレーション実行者、日時、理由の履歴保存
- 月次報告JSONの出力
- 是正処置CSV出力

## 権限
- 事業所管理者：所属事業所内の是正処置を管理・エスカレーション可能
- 管理者：全事業所の是正処置を管理可能

## 月次報告JSON
以下を含みます。
- 対象月
- 作成日時、作成者
- 全体件数
- 対応中件数
- 完了確認待ち件数
- 期限超過件数
- エスカレーション件数
- 完了件数
- 事業所別集計
- 対象となる是正処置一覧

## 注意
エスカレーションは是正処置の完了や承認を意味しません。管理者への引継ぎ後も、対応完了と別担当者による完了確認が必要です。
