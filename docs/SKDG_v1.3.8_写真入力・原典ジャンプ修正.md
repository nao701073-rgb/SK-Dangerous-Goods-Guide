# SKDG v1.3.8 Hotfix

## 1. 写真から入力する欄が開かない問題

v1.3.7では、写真登録用の互換イベントが「写真から登録」という文言を主対象としており、旧レイアウト等で表示される「写真から入力する（必要な場合のみ）」を十分に拾えていませんでした。

v1.3.8では次を実施しました。

- `#photoInputPanel` を写真入力の主パネルとして優先。
- `hidden`、`display:none`、`visibility:hidden`、旧折りたたみクラスを解除。
- 旧 `<details><summary>写真から入力する…</summary>` を検出した場合は強制的に開く。
- `写真から登録`、`写真から入力`、`写真を撮影・アップロード` の各導線を互換対象化。
- Excel取込や遅延描画後にも再確認し、写真入力欄を利用可能な状態へ戻す。
- 申請書・航路パネルの直後へ写真入力パネルを安定配置。

## 2. 任意欄の初期折りたたみ

v1.3.7で同梱した `v137-ctu.css` がCTU画面から参照されていなかったため、登録済み案件等の初期折りたたみが適用されない状態がありました。

v1.3.8ではCSSを明示的に読み込み、さらに折りたたみ時に見出し自身まで消えないよう `v137-collapse-head` を保持する方式に修正しました。

写真入力、写真AI候補、かんたん入力、結果は初期折りたたみの対象にしません。

## 3. 算出根拠 → 原典ページへジャンプ

「算出根拠を開く」で表示する別ウィンドウに、項目ごとの **原典ページへジャンプ** ボタンを追加しました。

主なリンク先：

- CTU Code Annex 7 Appendix 2（摩擦係数）
- CTU Code 固縛原則
- CTU Code 直接固縛
- CTU Code 固縛配置評価
- IMO CSS Code

別ウィンドウ下部にも「原典をまとめて確認」を設け、同じ名称のボタンから原典へ進めます。
