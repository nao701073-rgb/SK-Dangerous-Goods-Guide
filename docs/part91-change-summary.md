# Part 91 変更概要

1. 川崎事業所を先行試験運用拠点として登録。
2. ログインにメールアドレスではなくログインIDを使用。
3. メールアドレスは二段階認証、利用開始、パスワード再設定に使用。
4. 利用者本人が任意のパスワードを設定する招待方式を追加。
5. 6桁メールワンタイムコード、期限、再送待機、試行回数制限を追加。
6. 検査員、事業所管理者、安全環境室管理者、ゲスト、検証者の権限を追加。
7. ゲストと検証者は検査員以外の社内職員を対象とし、申請番号・写真へのアクセスを制限。
8. 川崎事業所用の検証アカウント、検証用申請番号、試験運用ページを追加。
9. 認証・権限・試験運用・中止基準の手順書を追加。
