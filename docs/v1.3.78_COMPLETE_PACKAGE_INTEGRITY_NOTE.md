# v1.3.78 完全パッケージ整合性補正

## 目的
v1.3.78 時点のシステム構築一式を、単独で再配置・再構築できる完全パッケージとしてまとめる際の参照整合性確認を記録する。

## 参照整合性補正
`pages/ctu-securing-calculator.html` に残っていた次の3件は、回収できた Part 534 完全スナップショット、Part 535～590 更新パッケージ、v1.0～v1.3.78 更新系列のいずれにも実体ファイルが存在しない旧参照であった。

- `assets/css/ctu-securing-part542.css`
- `assets/js/ctu-field-assist-part541.js`
- `assets/js/ctu-field-correction-part542.js`

これらはブラウザ上では取得失敗となる参照であり、現行 v1.3.78 の CTU 画面では後続の CSS / JavaScript 群により表示・操作・計算機能が構成されているため、完全パッケージ作成時に HTML から旧参照のみ削除した。

計算ロジック、CTU Code / CSS Code の算出ロジック、支保荷重経路、申請書判定、申請番号管理、権限・認証、保存データ構造には変更を加えていない。

## 旧ファイル名の復旧
一部の過去文書は、更新 ZIP 内で文字化けした長いファイル名となっており、一般的なファイルシステムの1ファイル名長制限を超えていた。内容を失わないため `docs/legacy-filename-recovered/` に安全な名称で格納し、`ORIGINAL_FILENAME_MAP.json` に元の ZIP 内ファイル名との対応を保存した。
