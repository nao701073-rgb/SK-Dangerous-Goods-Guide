# part495 判定基準・国内法令参照表示の統一

## 対象範囲

登録済みの危険物2,725行、国連番号2,248件を対象とします。UN1203など一部の国連番号だけの個別対応ではありません。

## 判定基準

「判定基準の国内法令」を開いた際、PDF画像を大きく表示する形式ではなく、コード詳細画面と同じカード書式で表示します。

- 上部：国内法令の主な参照
- 中央：判定基準・該当内容
- 下部：必要な国内法令原文リンク

危告示別表第1「備考2」に具体的な判定基準がある危険物は、備考2の該当本文を画面内に表示します。病毒をうつしやすい物質、放射性物質等及び備考2の対象外となる危険物も、同じカード書式で固有の参照情報を表示します。

## 国内法令・IMDG Codeの主な参照

品名・国連番号表示に関する参照欄を、標札表示の「国内法令の主な参照」と同じ枠、文字、余白及び箇条書きの書式に統一します。

- 危規則 第8条第1項・第9条
- 危告示 第7条の3第1項・第2項
- 危告示 第14条の2の2（オーバーパック表示）
- IMDG Code 5.2.1.1

## 積載方法区分

AからEまでの積載方法区分は、告示の表にある船舶・旅客条件と積載方法を画面幅内の2列表で表示します。スマートフォンでは縦並びに切り替え、横スクロールを使用しません。

## デザイン

既存の色、フォント、罫線、角丸及び余白を変更せず、既存画面の書式に統一します。
