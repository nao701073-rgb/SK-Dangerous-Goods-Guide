# SKDG v1.3.69

## 根本原因
- 初期 v1.3 の `v13-ctu.js` が現在の Step 4/5/6 のヘッダーをロード後に再度書き換えていた。
- Part552〜560 の旧ワークフローCSS/JSが現行HTMLから引き続きロードされ、旧ナビゲーション、余白、補助カード等が累積していた。
- その結果、HTML上では正しい①〜⑥でも、実表示では④→⑤、⑤→⑥となるなど二重管理が発生した。

## 対処
- `v13-ctu.js` をCTU画面から完全に外した。
- Part552〜560 の旧ワークフローCSS/JSをCTU画面から外した。
- Step 1〜6はHTMLの `data-ctu-step` を唯一の正本とし、v1369で順序・見出し・可視状態のみを検証する。
- Step 1/2の旧detailsラッパー、旧3段階進捗、旧固定次へバー等はDOMから除去する。
- 入力状況バーはstickyを維持し、現在スクロール中のStepも控えめに追跡表示する。
- Step5は固縛材単独時1列、併用時だけ2列。

## 維持
計算式、Excel申請書取込、航路/海域推定、申請番号管理データ、保存済み算出結果のデータ構造は変更しない。
