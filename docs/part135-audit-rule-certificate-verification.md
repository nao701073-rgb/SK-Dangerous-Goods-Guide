# Part 135 監査ルール適用証明の検証・月次照合

## 概要
監査ルールの適用証明JSONについて、証明書本文、検証ハッシュ、変更申請、承認・適用イベント、適用後ルールの整合性を再確認します。

## 個別検証
管理画面では次の2通りで検証できます。

- 適用証明台帳から「再検証」
- 外部保存した適用証明JSONを読み込んで検証

確認項目は次のとおりです。

- 必須項目の存在
- 証明書本文から再計算した検証ハッシュ
- 対応する変更申請の存在
- 変更申請が適用済みであること
- 適用日時・適用者の一致
- 適用ルールの一致
- 承認イベント・適用イベントの存在
- 現在の監査ルールとの差異（注意情報）

## 検証結果
検証結果には次を記録します。

- 検証ID
- 証明書ID
- 変更申請ID
- 合否
- エラー・注意事項
- 登録ハッシュ・再計算ハッシュ
- 検証者・検証日時
- 検証元（台帳、JSON読込、月次照合）

## 月次照合
対象月を指定し、その月に適用された証明書を一括照合します。

- 証明書件数
- 検証合格・不合格件数
- 対応申請が見つからない件数
- 証明書IDの重複
- 変更申請IDの重複

月次照合結果はJSONで出力し、監査記録として保存できます。

## 留意事項
現在の監査ルールと証明書の適用ルールが異なる場合でも、後続の正規な変更適用による差異である可能性があるため、原則として注意事項として扱います。
