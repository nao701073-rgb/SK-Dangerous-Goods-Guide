# SKDG v1.3.92 同率最厳方向表示と可読性修正

## 目的
従来は左・右、または前・後の不足量が同一でも、配列上で先に評価された方向だけを「最も厳しい方向」と表示していました。計算値は同一でも、利用者には片側だけが厳しいように見えるため表示を修正します。

## 表示ルール
- 前方・後方が同率: **前後方向（前・後同率）**
- 左・右が同率: **側面方向（左・右同率）**
- 前後左右すべて同率: **前後・側面方向（全方向同率）**
- 上記以外で複数方向同率: 対象方向を列記して **（同率）**

同率判定は画面表示と同じ 0.1 kN 単位の余裕／不足量で比較します。

## 可読性
算出結果上部の黄色系説明領域について、本文色を濃くし、行間と余白を拡大。抵抗内訳カードと補足説明も文字サイズ・コントラストを改善します。

## 計算への影響
計算式、係数、抵抗力、判定閾値は変更していません。表示・要約ロジックのみの変更です。
