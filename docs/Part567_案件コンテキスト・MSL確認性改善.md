# Part 567 案件コンテキスト・MSL確認性改善

## 目的
Part 566までの「かんたん操作」導線を維持し、画面を移動した際に対象案件を選び直す操作と、固縛力算出時にMSLの制限箇所を読み解く手間を減らす。

## 1. 申請番号管理
- 選択中案件から「申請書を確認」へ直接進める。
- `applicationId` を引き継いで戻った場合、同じ案件をかんたん登録欄へ復元する。
- 案件検索は Enter で先頭一致案件を選択、Esc または「検索をクリア」で解除できる。
- 選択案件に「申請書確認状況」「危険物件数」「MSL取付点件数」を簡潔に表示する。
- 簡易メモに未保存表示を追加し、Ctrl+Enter / Command+Enter でも保存できる。

## 2. 申請書取込・確認
- 申請番号管理から開いた場合、照合対象案件を画面上部に表示する。
- 対象案件の申請年度・申請番号を空欄時のみ補完し、取込後の入力値と一致しているか表示する。
- 不一致の場合は警告表示のみとし、既存の登録・更新判定ロジックには介入しない。
- 対象案件の申請詳細、固縛力参考算出へ直接移動できる。

## 3. 申請詳細
- 対象案件を維持したまま「申請番号管理」「申請書を再確認」「固縛力参考算出」へ移動できる共通操作バーを追加する。
- 戻る操作でも `applicationId` を申請番号管理へ引き継ぐ。

## 4. 固縛力参考算出
- 選択中の申請番号、案件名、船名・コンテナ番号、申請書確認状態を案件欄に表示する。
- 直接固縛では、固縛材MSL・貨物側取付部MSL・CTU側固縛点MSLのうち最小値を「採用MSL」として即時表示し、どこが制限箇所か明示する。
- トップオーバーではMSL最小値表示を誤用せず、「STFで評価」と表示する。
- 引張系＋支保・当て材併用時は、成立条件確認済み／未確認を即時表示する。未確認時は従来どおり単純加算しない。

## 変更しないもの
- `caseData.intake.reviewEvidence` の保存形式
- P/P200/IBC/T、許容容量・許容質量等の申請書判定
- 海上輸送 海域B（標準）の初期値
- 引張系固縛材と支保・当て材の別寄与計算
- 併用成立条件未確認時の保守評価
- MSL、摩擦、方向別必要抵抗力等の計算式
- 取付点MSL・根拠写真台帳
- DBスキーマ
