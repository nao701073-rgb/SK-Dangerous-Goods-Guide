# SKDG v1.3.90 申請書番号と固縛力参考算出の登録連動

## 目的
固縛力参考算出で読み込んだ申請書と、申請番号管理へ登録する案件番号の整合性を維持する。

## 登録先の決定
- Excel申請書から申請年度・申請番号を取得できた場合、その値を登録の基準値とする。
- 同じ年度・番号の案件が既に申請番号管理に存在する場合は、新規作成せず既存案件へ算出結果を保存する。
- 未登録の場合は、申請書と同じ年度・番号で新規登録する。
- 登録直前にも番号を再照合し、申請書取得番号と登録先が異なる場合は登録を停止する。

## 年度の取得順
1. 申請年度の明記
2. `2026-1434` 等、申請番号に含まれる4桁年
3. 申請日（Excel日付・Excelシリアル値・西暦・和暦）

年度まで確認できない場合は、自動で現在年度を推定せず、従来の手入力登録を使用する。

## 既存機能への影響
CTU Code／CSS Code計算、方向別外力、摩擦、支保、固縛材MSL、最弱MSL、三段階参考判定には変更を加えていない。
