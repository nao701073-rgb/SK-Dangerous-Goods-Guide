# Part 364 更新内容

## 対応概要
Part 363で発生していた以下の問題を修正し、ログインまわりを全面的に作り直しました。

- クラウドAPI接続先が未設定だとログインできない
- 未認証でも一部ページへ直接アクセスできる
- ログイン画面の背景画像が粗く見える
- 背景に不要な縦帯が入る
- 時間帯ごとの背景切替が安定しない

## 主な修正点
1. **ローカル認証モードを追加**
   - クラウドAPI未設定でもログイン可能
   - 認証情報、利用者一覧、アクセス方針はブラウザのローカル保存で管理
   - システム設定 → 利用者管理から、ID・表示名・権限・所属・パスワードを変更可能

2. **未認証アクセスを遮断**
   - 起動時は必ずログイン画面から開始
   - 未認証ではホーム、危険物検索、詳細、関連法令、関連資料を含む保護ページへ直接アクセス不可
   - URL直接入力時もログイン画面へ転送

3. **ログイン画面を再構成**
   - 背景表示を4K画像ベースで再構成
   - 縦帯の原因となる擬似的な背景表現を撤去
   - 朝・昼・夕・夜で背景画像が自動切替
   - クラウド認証／ローカル認証の動作モードを画面上で案内

4. **検証用アカウントの初期登録**
   - IDは苗字想定で初期登録
   - 仮パスワードは共通設定
