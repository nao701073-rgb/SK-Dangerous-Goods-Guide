# Part 286 更新内容

## 利用環境診断の拡充

- ブラウザ保存領域の使用量と推定上限を表示します。
- 使用率が75%以上の場合は注意、90%以上の場合は警告として表示します。
- ブラウザ表示／アプリ表示／全画面表示を判定します。
- Microsoft Edge、Google Chrome、Mozilla Firefox、Safariを簡易判定します。
- 現在の画面サイズを表示します。
- 確認結果のコピー内容に保存容量、表示方式、ブラウザ、画面サイズ、ユーザーエージェントを追加しました。
- 設定画面からシステムを再読み込みできるボタンを追加しました。
- 画面サイズ変更時や設定画面へ戻った際に診断結果を更新します。

## 注意

保存容量はブラウザが返す推定値です。端末全体の空き容量やサーバー側の保存容量を示すものではありません。
