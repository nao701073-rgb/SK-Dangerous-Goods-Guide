# Part 150 試験運用向け統合完成候補版

## 位置付け
本パッケージは、ブラウザ上での機能確認と社内試験運用を開始するための統合完成候補版です。
本番稼働には、社内サーバー、PostgreSQL、メール認証、HTTPS、バックアップ、複数端末同期の環境別検証が必要です。

## 統合済み機能

### 危険物検索・法令
- 国連番号、正式輸送品名、等級、容器等級、標札、EmS、包装、積載方法、隔離等の検索
- 危規則、危告示、IMDG Code、その他国内・国際法令の版管理
- 改正PDF、構造化データ、差分、原文照合、承認、公開、ロールバック
- 適用日判定、旧版参照、案件判定根拠スナップショット

### 申請番号・写真
- 申請番号別の写真登録、代表写真、コメント、検索
- 自動圧縮、容量上限、向き補正、EXIF日時、GPS選択保存
- 重複検出、論理削除、復元、保全指定、保存期間、完全削除承認
- 削除証明書、検証、月次照合、是正処置

### 組織・権限
- 利用者
- 事業所管理者
- 管理者
- 事業所管理者は所属事業所、管理者は全事業所を管理する想定
- 承認工程では自己承認を禁止

### 運用・保守
- 整合性診断、バックアップ、復元前検査
- 本番導入判定、設定固定、運用開始チェックリスト
- 障害管理、復旧訓練、定期点検、月次報告
- 監査証明、改ざん検知、是正・再発防止・再開案件管理

## 試験運用開始前の必須確認
1. 川崎事業所の利用者・事業所管理者アカウントを個別発行する。
2. 管理者アカウントの担当者と代行者を決定する。
3. 危規則・危告示・IMDG Codeの採用版、施行日、原本PDFを確認する。
4. 写真保存上限、保存期間、GPS保存方針を決定する。
5. バックアップ取得先、復元担当者、障害連絡先を決定する。
6. 社内API、PostgreSQL、HTTPS、メール認証を導入環境で検証する。
7. テスト申請番号で検索、写真登録、承認、バックアップ、復元訓練を実施する。

## 既知の制約
- オフライン開発版ではブラウザの localStorage を使用する箇所があります。
- 写真を大量に保存する本番環境では、画像本体をサーバーストレージへ保存してください。
- PDFから法令データを完全自動更新するのではなく、抽出、差分確認、原文照合、承認を必要とします。
- AI要約は法令原文の代替ではなく、確認支援情報です。

## 最終判定
静的検査に合格しても、実際の社内ネットワーク・端末・サーバー環境での受入試験をもって試験運用開始可否を判断してください。
