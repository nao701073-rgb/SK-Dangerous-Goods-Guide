# Part 223 日次利用状況・異常利用対応要領

## 1. 目的
システム管理者が、指定日ごとの利用人数、ログイン人数、機能別利用件数、利用者別操作件数および異常利用候補を確認するための機能です。

## 2. 確認項目
- 1日あたりの利用者数
- 総操作件数
- ログインした利用者数
- 機能別利用件数
- 利用者ごとの最初・最後の利用時刻
- 操作件数と主な利用機能
- 大量閲覧等の警告候補
- 当日未利用の有効利用者数

## 3. 運用上の注意
警告候補だけで不適切利用と断定せず、担当業務、当日の作業内容、上長の指示等を確認してください。利用履歴を閲覧した操作自体も監査ログへ記録されます。

## 4. 権限
本機能はシステム管理者専用です。安全環境室長、事業所管理者、一般利用者、ゲストは利用できません。
