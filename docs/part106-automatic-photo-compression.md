# 第106回　申請写真の自動圧縮

## 目的
スマートフォン等で撮影した高解像度写真を、申請番号への登録前にブラウザ上で自動圧縮し、通信量と保存容量を抑える。

## 仕様
- 初期値は「自動圧縮（推奨・容量上限内）」とする。
- 自動圧縮では長辺1600px、JPEG品質86%から処理を開始する。
- 原則1MB以下、かつ事業所設定の「写真1枚の容量」以下になるまで、JPEG品質と長辺を段階的に調整する。
- 圧縮後も管理上限を超える場合は登録を停止する。
- 選択後に、圧縮前容量、圧縮後容量、削減率、保存寸法を表示する。
- 元画像はサーバーへ送信せず、圧縮済み画像のみを同期・保存する。
- 「元サイズ（圧縮なし）」も選択可能だが、容量上限の検査は適用する。
- 登録データには元容量、保存容量、画像寸法、圧縮モードを記録する。

## セキュリティ・運用
- サーバー側の画像形式判定および容量上限検査は従来どおり維持する。
- クライアント側圧縮だけを信用せず、サーバー側でも最大容量を拒否する。
- 圧縮により写真の確認に必要な文字・表示が読めない場合は、長辺2048pxを選択する。
