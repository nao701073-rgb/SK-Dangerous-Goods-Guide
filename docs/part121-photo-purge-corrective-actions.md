# Part 121 月次照合の是正処置管理

## 目的
月次照合で検出した要確認事項を放置せず、原因調査、是正、完了確認まで追跡します。

## 処理フロー
1. 月次照合の要確認事項から是正処置を登録
2. 原因、是正内容、担当者、対応期限を記録
3. 担当者が対応結果を登録
4. 対応者とは別の事業所管理者または管理者が完了確認
5. 完了状態として履歴を保持

## 権限
- 登録・更新・対応完了・完了確認は、事業所管理者または管理者のみ
- 事業所管理者は所属事業所内のみ
- 管理者は全事業所
- 対応完了者本人による完了確認は禁止

## 状態
- open: 対応中
- completed-awaiting-verification: 完了確認待ち
- closed: 完了

## 出力
画面の表示条件に基づいて是正処置一覧をCSV出力できます。
