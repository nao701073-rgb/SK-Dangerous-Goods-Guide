# Part 310 更新内容

## 初回パスワード変更手続き

本番運用時の初期アカウント配布を想定し、`passwordChangeRequired` が有効な利用者を専用画面へ誘導します。ログイン成功時のSKロゴ演出は維持し、演出終了後に初回パスワード変更画面へ移動します。

## 画面制御

- 未認証利用者はログイン画面へ戻します。
- 変更要求がない利用者はホーム画面へ移動します。
- 変更要求中はホーム画面や各機能への直接アクセスを抑止します。
- パスワード変更成功後に要求状態を解除し、ホーム画面へ移動します。

## セキュリティ

サーバー側の既存パスワードポリシーと照合し、現在のパスワード確認後に変更します。画面側でも確認入力の一致、新旧パスワードの相違を確認します。
