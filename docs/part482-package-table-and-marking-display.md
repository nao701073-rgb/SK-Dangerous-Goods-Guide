# part482 正式輸送品名実寸比較・包装要件表の再構成

## 変更内容

- 正式輸送品名の実寸比較では、英語品名原文から大文字部分だけを候補として抽出する。
- `or` および括弧書きで複数候補が得られる場合は、利用者が1候補を選択できる。
- 国連番号は登録値のまま表示する。
- 実寸比較では国連番号と選択した正式輸送品名を別行表示し、単語途中での不自然な改行を防止する。
- Pコード原文表の列分割処理を修正し、「外装容器の種類」と「外装容器の許容容量又は許容質量」を混在させない。
- PDF抽出テキストの2個以上の空白を列境界として読み取り、表見出し位置に基づいて4列へ割り当てる。
- P110、P114、P132等の改行されたセル文字列を同じ列内で連結する。
- P001・P002の容器等級別表示は、従来のお手本となる濃紺系の表形式を維持する。
- スマートフォンでは包装原文表を無理に縮小せず、横スクロールで列構造を維持する。

## 保存データへの影響

正式輸送品名原文および危告示原文のデータは変更しない。加工した文字列は実寸比較表示にのみ使用する。
