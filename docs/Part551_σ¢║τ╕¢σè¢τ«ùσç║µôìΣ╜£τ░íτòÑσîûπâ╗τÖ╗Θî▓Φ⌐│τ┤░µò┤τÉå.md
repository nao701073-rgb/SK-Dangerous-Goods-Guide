# Part 551 固縛力算出 操作簡略化・登録詳細整理

## 目的
Part 550で追加した登録済み算出結果の再利用を維持しながら、通常利用者が迷いやすい入力・確認箇所を段階的に表示し、申請番号管理の登録済み詳細も見やすくする。

## 1. 固縛力参考算出

### 1.1 入力状況を3段階で表示
- 案件・貨物
- 固縛条件
- 算出・登録

貨物質量、材質、本数、確認済みMSL等の入力状況を補助表示する。
この表示は操作案内であり、適合判定・安全判定を代替しない。

### 1.2 「次へ」導線
基本入力の各段階に次工程へ移動するボタンを追加する。
入力値の自動確定や条件の省略は行わない。

### 1.3 補助機能を必要時だけ表示
以下は通常時に折りたたみ、必要な場合だけ開く。
- 登録案件の危険物明細
- 申請書・航路からの入力補助
- 写真からの入力補助
- 鉛直角・強度根拠等の追加確認欄

鉛直角は折りたたみ見出しにも現在値を表示し、値が隠れたまま分からなくならないようにする。

### 1.4 登録後の確認
算出結果を申請番号管理へ登録した後は、同じ画面から「登録結果を新しいタブで確認」で申請詳細の固縛力算出タブへ移動できる。

## 2. 申請番号詳細
- 固縛力算出タブは最新版を最初に表示する。
- 貨物質量、固縛方法、判定、登録日時を最新版概要として先に表示する。
- 過去結果は「過去の算出履歴」を開いた場合だけ表示する。
- 各結果の「この条件で再計算」は維持する。
- 再計算結果は従来どおり履歴として追加し、旧結果を上書きしない。

## 3. 変更しない事項
- CTU Code / CSS Codeの計算式
- 輸送条件係数
- 摩擦抵抗
- 方向別必要抵抗力
- MSL最小値判定
- 引張系固縛材と支保・当て材の併用ロジック
- 取付点MSL台帳・写真・確認履歴
- 登録前の最終確認

DBマイグレーションは不要。
