# Part 314 更新内容

## 権限別ログイン後ホーム画面
- 事業所利用者、事業所管理者、安全環境室長、安全環境室職員、システム管理者、ゲスト、検証者ごとに、ログイン後の案内・集計・主要導線を切り替えるダッシュボードを追加した。
- 事業所利用者・事業所管理者は所属事業所の案件件数を表示する。
- 安全環境室長・安全環境室職員・システム管理者は全事業所の案件件数を表示する。
- 安全環境室職員は閲覧専用であることを明示し、管理機能への導線を非表示にする。
- ゲストは利用可能な4機能のみを案内する。
- 検証者は総合検証および検証対象画面への導線を表示する。
- 既存の白と青を基調としたホーム画面デザインを維持した。
