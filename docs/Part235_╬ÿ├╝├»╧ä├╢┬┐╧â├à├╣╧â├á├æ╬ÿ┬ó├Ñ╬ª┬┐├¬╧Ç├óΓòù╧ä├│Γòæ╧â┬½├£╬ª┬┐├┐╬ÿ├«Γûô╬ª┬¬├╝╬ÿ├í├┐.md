# Part 235 運用受入集計・確定記録要領

## 1. 目的
運用受入・定期点検の結果を四半期・年次で集計し、承認済み記録を確定記録として保全するとともに、是正対応の期限超過と次回点検予定を一画面で確認する。

## 2. 追加機能
- 点検記録、承認待ち、承認済み、未完了是正、期限超過の集計
- 四半期・年次の期間レポートJSON出力
- 承認済み点検記録の確定表示と再承認防止
- 是正対応の期限管理
- 次回点検予定の確認

## 3. 運用
1. 点検記録を保存する。
2. 点検結果を承認または差戻しする。
3. 承認済み記録は確定記録として扱い、内容変更が必要な場合は新しい点検記録を作成する。
4. 不合格・条件付き受入・未完了事項は是正対応として登録する。
5. 四半期または年次の終了時に期間レポートを出力し、所定の保存先へ保管する。

## 4. 留意事項
- 「正式運用可」は全分野が合格の場合のみ選択できる。
- 期限超過は自動表示されるが、対応の優先順位は業務影響を確認して判断する。
- 本システムの利用は任意である。
