# 第105回 法令データ公開・ロールバック管理

## 目的
法令PDFと構造化データの更新を、監査合格後にのみ本番へ公開し、誤公開時に直前の承認済み版へ戻せるようにする。

## 公開ゲート
公開計画は次の条件をすべて満たした場合だけ作成できる。

1. 整合性監査結果が `passed`
2. 監査結果SHA-256が記録済み
3. 監査対象の法令ID・版と更新マニフェストが一致
4. データ作成者と公開承認者が別人
5. 影響対象の確認が完了
6. 適用開始日が登録済み
7. 予約公開の場合は公開日時が登録済み
8. ロールバック先となる直前の承認済み版が指定済み

## 公開方式
- 即時公開：承認・監査合格後に公開処理へ進める。
- 予約公開：指定日時にサーバー処理が公開する。適用開始日より前に検索結果へ反映しない。

## 取消・ロールバック
- 公開前の予約は取消可能。取消理由と実行者を保存する。
- 公開後の記録は上書き・削除しない。
- 問題発生時は指定済みのロールバック版を再公開し、理由・実行者・時刻をイベント履歴へ保存する。
- ロールバックはデータ削除ではなく、適用版ポインタを承認済み旧版へ戻す操作とする。
