# Part481 Excel申請書の一時解析・原本非保存

## 対象

- 申請書確認
- 固縛力参考算出

## 仕様

1. `.xls`／`.xlsx`はブラウザ内の一時メモリでのみ解析する。
2. Excel原本、ArrayBuffer、Workbook、全シート行データを、`localStorage`、`sessionStorage`、`IndexedDB`、Cache Storage、申請番号管理または操作ログへ保存しない。
3. 解析終了時にWorkbook参照を破棄し、ArrayBufferを可能な範囲でゼロクリアしてから参照を解放する。
4. ファイル入力欄は解析終了時にリセットする。
5. 取消、取込データ消去、画面移動、画面終了時にも一時参照を破棄する。
6. 申請番号管理へ登録する場合は、利用者が画面上で確認した確認結果・算出結果・必要な入力項目だけを保存する。
7. 登録結果にはExcel原本を含めない。申請書確認ではExcelファイル名も登録しない。
8. 固縛力参考算出では、登録用のExcel取込情報を貨物・港・寸法・質量等の必要項目に限定し、シート名や抽出行全体は保存しない。

## 注意

Webブラウザのメモリ管理はブラウザに委ねられるため、物理メモリ上の即時完全消去を保証するものではない。本実装は、アプリケーションがExcel原本を永続保存・外部送信せず、参照を速やかに解放することを目的とする。
