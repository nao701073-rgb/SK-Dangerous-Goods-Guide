# Part 546 事前審査表示重複整理

## 1. 目的
申請書取込・確認画面で、同じ「包装要件」「許容容量・許容質量」が上段の事前審査確認と下段編集フォームに重複して表示されていたため、事前審査確認を正本表示として整理する。

## 2. 表示仕様
- 上段の「事前審査確認」を確認用の正本表示とする。
- 個数、1容器当たり正味質量、許容容量・許容質量は上段で強調表示する。
- 参照包装要件、参照IBC要件、参照ポータブルタンク要件も上段で表示する。
- 下段編集フォームから「包装要件」と「許容容量・許容質量」の重複欄を削除する。
- 国連番号、品名・原文、等級、容器等級、容器コード、個数、申請総N/W、申請総G/W、許可・確認事項、削除操作は維持する。

## 3. データ保持
画面から重複入力欄を削除しても、取込データの `packingInstruction` と `allowableCapacityOrMass` は案件データに保持する。許容値は上段の判定更新時に自動反映し、JSON/CSV出力・案件登録で従来どおり使用できる。

## 4. 維持する判定
Part 545までの次のロジックは変更しない。
- P001/P002等の許容容量・許容質量
- P200通常容量
- P200の当該欄「x」の地方運輸局長許可案内
- 全Pコードの危告示原文ジャンプ
- IBCの全材質コード・HZワイルドカード・末尾1/2判定
- IBC最大内容積と原文ジャンプ
- ポータブルタンクTコード表示・原文ジャンプ
- 少量危険物の従来ルール
- 同一単位の規定量超過警告
- Lとkgの±20%近接時のみ「容量比較 要確認」

## 5. レスポンシブ
PC・スマートフォンとも、上段の事前審査確認を最初に表示し、下段は編集に必要な項目のみとする。横スクロールを増やす変更は行わない。
