# part492 Tコード詳細・コード画面表示の改善

- T1〜T22のコード詳細に、危告示別表第1備考6(4)の次の情報を表示する。
  - 最小試験圧力（MPa）
  - タンク外板の最小板厚（基準鋼）
  - 圧力安全装置の種類（N／NF）
  - 底部開口（A／B／C）
  - 代替使用可能なTコード
- T1〜T22のIMDG Code原文リンクを4.2.5.2.6（PDF 260ページ）へ統一する。
- Pコード詳細内のPPコードは通常の文字情報として表示し、青文字・下線・個別リンクを付けない。PP単独詳細画面では従来どおり原文リンクを維持する。
- IBC・T等のコード詳細を開いた際は、前回のスクロール位置を引き継がず、最上部から表示する。
- 判定基準の国内法令全画面表示で、ページ情報をHTML文字列として二重処理していた不具合を修正し、「資料 undefinedp」および空白表示を解消する。
- UN1203の判定基準は、危告示第2条第3項（PDF 1ページ）および危規則第2条第1号ハ(1)〜(3)（PDF 2ページ）を表示する。
- 既存画面と同じ色、フォント、罫線、角丸、余白を維持する。
