# Part 237 改善計画統合・次年度引継ぎ要領

## 1. 目的
運用受入・定期点検で発生した改善計画を、責任者、期限、状態、年度を横断して確認し、未完了事項を確実に次年度へ引き継ぐための管理方法を定めます。

## 2. 主な機能
- 未完了、期限超過、次期引継ぎ、責任者未設定、30日以内期限の集計
- 責任者・区分・状態による絞り込み
- 計画、対応中、完了、次期引継ぎの簡易更新
- 当年度と前年度の改善計画件数比較
- 責任者別の引継ぎJSON出力
- クラウド運用時の進捗履歴・引継ぎ出力履歴保存

## 3. 運用上の注意
- 簡易更新で完了にした場合も、正式な完了証跡を後から追記してください。
- 責任者未設定と期限超過を優先して確認してください。
- 次期へ引き継ぐ場合は、引継ぎ理由、責任者、次年度期限を明確にしてください。
- 本システムの利用は任意です。

## 4. 権限
本画面はシステム管理者権限を持つ利用者のみが使用します。閲覧、更新、出力操作は監査ログへ記録します。
