# Part 224 利用状況分析・異常利用対応要領

## 1. 目的
システム管理者が日次・週次・月次の利用状況を把握し、過剰閲覧等の警告候補について業務上の必要性を確認し、対応経過を監査可能な形で保存する。

## 2. 集計機能
- 日次、週次（月曜日から日曜日）、月次で集計する。
- 利用者数、総操作数、ログイン人数、警告候補、未使用者を表示する。
- 機能別件数と利用者別の利用日数・操作件数・主要機能を確認する。
- 集計結果はJSONで出力できる。

## 3. 異常利用候補への対応
警告候補のみで不適切利用と断定しない。担当案件、教育、法令改定作業等の業務上の理由を確認し、「未確認」「確認中」「確認済み」「対象外」の状態と確認内容を記録する。

## 4. 保存期間
詳細履歴と監査・集計記録の保存期間を別に設定する。実際の削除処理は、会社の情報管理規程、個人情報保護、監査要件および承認手続に従ってクラウド側で実施する。本画面は方針と次回監査日を記録するものである。

## 5. 権限制御
本機能はシステム管理者のみ利用できる。管理者が利用履歴、期間集計、対応案件を閲覧・変更した操作も監査ログへ記録する。

## 6. 非実装項目
透かし表示、スクリーンショット検知・追跡、自動画面保存は現時点では実装しない。
