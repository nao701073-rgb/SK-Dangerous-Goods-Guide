# SKDG v1.3.49 固縛力参考算出 UI統合

- 入力・確認状況バーを、スクロール時に共通ヘッダー直下へ追尾表示する方式へ補強。
- 旧4段階かんたん操作ガイド、旧 Part551 進捗表示を削除。
- `③ 不足項目を確認して参考算出` の旧見出しを非表示化。
- 6「参考算出を確認」の中へ、既存の `overall` / `metrics` / 方向別詳細結果を移動して統合。
- 下側の旧「3．算出結果」独立パネルを廃止。
- `quickCalcBtn`、`toggleAdvanced` 等の実操作ボタンは旧ガイド削除前に正規位置へ退避して保護。
- 計算式、算出関数、申請番号管理への登録形式、写真入力・AI補助は変更なし。
- 追尾処理は scroll/resize 時の requestAnimationFrame のみで、setInterval や画面全体 MutationObserver は追加しない。
