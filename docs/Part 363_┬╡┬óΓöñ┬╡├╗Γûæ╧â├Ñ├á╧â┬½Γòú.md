# Part 363 更新内容

## 実装内容
- システム起動時および保護対象URLへの直接アクセス時に、未認証であればログイン画面へ強制転送する認証ブートストラップを追加しました。
- ホーム、危険物検索、危険物詳細、関連法令、関連資料を含む業務画面は、API接続設定の有無にかかわらず未認証では表示しません。
- ログイン、アカウント有効化、パスワード再設定、初回のクラウド接続設定のみ公開画面として扱います。
- 権限別の検証用アカウント7件を初期データへ追加しました。IDは苗字を想定したローマ字です。
- システム設定内の利用者管理から、ログインID、表示名、権限、所属事業所、パスワードを変更できるようにしました。
- 権限変更時はトークン世代を更新し、既存セッションに旧権限が残り続けないようにしました。
