# SKDG v1.3.15 Hotfix

## 1. 申請番号管理カード
- カード上部の「申請書・依頼書取込」や品名を主見出しにする表示を非表示化。
- 代わりに「登録内容」を表示し、案件ごとに次の登録状態を明示する。
  - 申請確認・許容容量／質量 登録済み
  - 固縛力参考算出 登録済み
  - 写真 n枚
  - 資料 n件
- カード上の「固縛力参考算出」直接ボタンは非表示。
- 確認導線は「詳細を開く」に統一。

## 2. 詳細画面
- 申請番号管理の「詳細を開く」から、同じ案件に登録された内容を確認できる。
- 「申請確認・許容容量／質量」タブでは、ユーザーが登録した申請確認結果を表示。
- 「固縛力参考算出」タブでは、ユーザーが登録した算出条件・MSL・方向別結果・判定を表示。
- 写真・添付、登録・更新履歴も同じ詳細画面で確認可能。

## 3. 案件ごと削除
- 登録済み案件カードに「案件を削除」を追加。
- 案件本体と、その案件に紐づく申請確認・固縛力参考算出のリンク結果を削除。
- 関連写真は既存の削除履歴を残す方式で削除状態へ変更。
- 添付資料は既存の取消履歴を残す方式で取消。
- 削除権限は既存の `canDeleteOperationalData()` を維持。

## 4. 固縛力参考算出の登録できない問題
- これまで登録前確認が未完了の場合、「申請番号管理へ登録」ボタン自体が disabled になっており、押しても理由を確認できなかった。
- v1.3.15ではボタンを常に押せる状態にし、未確認の場合は次に必要な操作を画面上で明示する。
- ただし安全確認条件は緩和しない。
  - 「入力値・強度根拠・算出結果を確認しました」のチェック
  - 確認者
  は引き続き登録前に必要。

## 5. 維持事項
- v1.3.14までのCTU Code / CSS Code原典ジャンプ修正を維持。
- 写真AI・コンテナ寸法補助を維持。
- 表示バージョンは `Version 1.0 試作版` のまま。
- DBマイグレーションなし。
