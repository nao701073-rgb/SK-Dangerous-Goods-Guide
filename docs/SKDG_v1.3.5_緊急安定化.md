# SKDG v1.3.5 緊急安定化

## 修正対象

### 申請書取込・確認
- v1.3.4の軽量化で外れていた許容容量・許容質量の判定経路を復旧。
- `ISSApplicationAllowance.resolve()` と `ISSApplicationPackingReference` を正規経路として使用。
- 旧コードが `SKApplicationAllowanceResolver.resolveAllowance()` を呼んでも停止しない互換層を追加。
- 自動確認時に危険物ごとの包装要件・許容容量/質量を再評価し、入力欄へ反映。
- P200は標準容量または許可確認メッセージを表示。
- 自動スクロールはユーザー設定がONの時だけ実行。

### 固縛力参考算出
- Excel申請書から取得した貨物質量・貨物名・海域候補を「かんたん入力」へ同期。
- Excel読込・航路推定のたびに `calc()` を自動実行していた処理を廃止。
- 参考算出は利用者が「この条件で算出する」を押した時だけ実行。
- Excel取込完了/消去イベントを復旧し、写真AI・画面順序・確認状態との連携を安定化。
- 材質プルダウンが空の場合のフォールバックを維持。
- 算出後の自動スクロールはユーザー設定がONの時だけ実行。

## データ・計算式
- DB変更なし。
- 危険物マスター、国内法令、IMDG、標札等のデータ変更なし。
- 固縛力の既存計算式そのものは変更せず、入力同期と実行タイミングを修正。
