# Part 564 申請書確認フィルター・確認状態復元

## 目的
危険物件数や要確認項目が多い申請で、確認対象を探す操作を減らし、誤操作や確認漏れを防ぐ。

## 確認対象一覧
状態で「未確認・要修正」「要修正」「人確認待ち」「確認済み」「すべて」を切り替えられる。さらに、P200・許可、IBC条件、ポータブルタンク条件、容量比較、原文確認、容器コード等の確認理由で絞り込める。

## セッション内復元
人による確認済み状態は、申請番号・申請者・危険物明細の確認キーが一致する場合だけ同一ブラウザセッション内で復元する。入力内容が変わると確認キーが変わるため、以前の確認済み状態はその危険物へ適用されない。

## 安全側の制御
規定量超過、包装要件不一致、国連番号不足等の要修正項目は引き続き確認済みにできない。法令判定・警告・原文案内は確認済み操作後も保持する。

## 非変更範囲
P/P200/IBC/T、許容容量・許容質量、少量危険物、申請番号管理への登録データ形式、固縛力参考算出の計算ロジックは変更しない。
