# Part 335 更新内容

## 固縛力参考算出アイコンの変更

- 「固縛力参考算出」のアイコンを、コンテナ外部の固定ではなく、**コンテナ内の貨物を固縛する状態**が分かる図柄へ変更しました。
- コンテナ内部の枠、パレット貨物、左右の固縛材を組み合わせています。
- 既存の主要機能アイコンと同じ、24px基準・白色線画・角丸の青色背景に適合するSVG形式としました。
- 小さい表示でも識別しやすいよう、細部を簡略化しています。

## 維持した仕様

- 「固縛力参考算出」は引き続き「将来実装」として表示します。
- 権限エラー画面の戻る導線は「ホームに戻る」を維持します。
- ログイン、権限制御、申請番号管理など既存機能は変更していません。
