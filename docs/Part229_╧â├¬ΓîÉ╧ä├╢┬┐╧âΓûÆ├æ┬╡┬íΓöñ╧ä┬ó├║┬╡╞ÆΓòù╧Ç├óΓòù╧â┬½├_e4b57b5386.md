# Part 229 利用履歴監査・定期レポート・保存整理要領

## 1. 基本方針
- 本システムの利用は任意です。
- 利用頻度の多寡を人事評価・業務評価に使用しません。
- 利用履歴は、不適切利用の確認、セキュリティ、障害調査、運用改善および正当な監査に限定して扱います。

## 2. 追加機能
1. 監査運用サマリー：未処理アラート、期限超過、承認待ちレビュー、整理申請、期限到来レポートを集約します。
2. 保存期間超過データの整理申請：事前確認後に申請・承認を記録します。この機能だけでは削除しません。
3. 定期監査レポート作成履歴：週次・月次の集計を作成時点のJSONとして保存します。
4. 管理者の閲覧・承認・出力操作は監査ログへ記録します。

## 3. 保存データ整理
- 保存期間を超えたことだけを理由に自動削除しません。
- 対象件数、基準日、理由を確認し、承認後に別途バックアップと復元可能性を確認します。
- 実際の削除処理は、本番クラウド環境の運用手順と職制承認を整備した後に実装します。

## 4. 定期レポート
- 週次または月次で作成します。
- 集計のみ、警告候補を含む、監査レビューを含む、の3範囲から選択します。
- 警告候補は不適切利用を断定するものではありません。
