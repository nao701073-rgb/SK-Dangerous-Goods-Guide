# Part 247 試作完成版リリースノート

## 1. 位置付け
Part 247は、配置先に依存しない画面、役割別権限、危険物・法令データ、申請番号・写真管理、認証API、利用履歴監査、運用保全および完成版文書を統合した試作完成版です。

## 2. 確定した役割
- ゲスト：危険物検索、関連法令、関連資料、ユーザー設定
- 事業所利用者：所属事業所の申請番号・写真を利用
- 事業所管理者：所属事業所の管理機能を利用
- 安全環境室長：全事業所の申請番号・写真を閲覧・登録・編集可能、削除不可。限定システム設定を利用
- 安全環境室職員：全事業所の申請番号・写真を閲覧可能
- システム管理者：全事業所・全管理機能を利用

## 3. 設定画面
ユーザー設定とシステム設定を分離しました。ユーザー設定は全利用者に表示し、システム設定は権限保有者だけに表示します。ユーザー設定画面内に重複する案内カードは表示しません。

## 4. データ品質
危険物データ2,725件について、重複SP、分類・SP分離、BK2のB欄分離を実施済みです。公開判定は自動検査で確認します。

## 5. 現時点で実装しない機能
- 透かし表示
- スクリーンショット検知・追跡
- 画面の自動保存

## 6. 配置先決定後の作業
- クラウド配置先、専用URL、HTTPS、CORS
- 認証・招待・パスワード再設定メールの実送信
- 初期利用者約50名の登録
- 50名・150名想定の性能試験
- PostgreSQLおよび写真保存領域のバックアップ・復元試験
- PC・スマートフォンでの実端末確認
- 職制承認と利用者周知

## 7. 運用方針
本システムの利用は任意です。
