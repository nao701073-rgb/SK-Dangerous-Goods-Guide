# SKDG v1.3.53 CTU AI・申請書連携検証

- Excel申請書：入力欄反映後の `sk:ctu-excel-imported` を進捗へ連携。
- 写真読込：`sk:ctu-photo-loaded` は写真取得だけを示し、入力完了にはしない。
- 写真AI自動候補：`sk:ctu-photo-ai-requested` 後に v142 が反映した値を進捗へ取り込む。
- AI候補の手動採用：`sk:ctu-ai-applied` 後に反映値を進捗へ取り込む。
- `input/change` のプログラムイベントを利用者手入力とは扱わず、専用イベントで出所を区別する。
- AIで確定できない貨物質量・MSL・取付点MSL等は、従来どおり不足／確認必要として残す。
- 写真を読み込んだだけで登録可能にならないよう、写真読込イベント後にも進捗側で登録ボタン状態を再評価する。
