# Part 334 更新内容

## 権限エラー画面の戻り先変更

- 権限エラー画面の戻る操作を「設定画面へ戻る」から「ホームに戻る」へ変更しました。
- リンク先を設定画面ではなくホーム画面（`index.html`）へ統一しました。
- `pages` 配下の画面からは `../index.html`、ルート画面からは `index.html` を使用します。
- 利用可能な権限の案内を先に表示し、その直後に「ホームに戻る」を配置する順番を維持しました。
- 画面タイトル、スクリーンリーダー通知、見出しフォーカス、44px以上の操作領域、スマートフォン対応を維持しています。

## 表示例

この画面は 事業所管理者、事業所利用者、安全環境室長、安全環境室職員、システム管理者 のみ利用できます。
