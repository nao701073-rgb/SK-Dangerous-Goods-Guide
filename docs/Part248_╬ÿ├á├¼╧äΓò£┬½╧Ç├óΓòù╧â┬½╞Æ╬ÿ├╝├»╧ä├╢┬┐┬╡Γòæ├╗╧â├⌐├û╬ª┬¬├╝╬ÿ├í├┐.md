# Part 248 配置・実運用準備要領

## 目的
試作完成版を実環境へ配置する際に必要な作業を、配置先、認証、利用者、性能、保全、端末確認、承認・周知の観点から漏れなく管理する。

## 実施順序
1. 配置環境、公開URL、API URLを確定する。
2. PostgreSQL、写真保存領域、秘密情報を設定する。
3. 招待、MFA、パスワード再設定メールを試験する。
4. 初期利用者約50名を登録し、所属と役割を確認する。
5. 役割別アクセス制御を通しで確認する。
6. 50名、将来150名を想定した性能試験を行う。
7. バックアップと復元試験を実施する。
8. PC・スマートフォンで主要機能を確認する。
9. 職制承認、利用者周知、問い合わせ窓口を確定する。

## 留意事項
本システムの利用は任意です。利用頻度の多寡は評価対象としない。透かし表示、スクリーンショット検知・追跡、画面自動保存は現時点では実装しない。
