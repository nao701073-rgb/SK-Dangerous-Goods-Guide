# part493 全危険物の判定基準・コード詳細表示順の統一

## 対象

UN1203のみの個別対応ではなく、危険物データに登録されている全2,725行（2,248国連番号）を対象とする。

## 判定基準の国内法令

- 9分類すべてについて、危告示又は放告示の判定条文と危規則第2条の対応箇所を設定する。
- 未設定分類へ一般条文を自動的に割り当てる処理は廃止する。
- 未設定が生じた場合は誤った条文を表示せず、開発者コンソールへ明示的なエラーを出す。
- 現行データ2,725行について、分類と判定条文の対応を全件自動検証する。

## コード詳細の表示順

すべてのコード詳細を次の順序へ統一する。

1. 許容容量・許容質量、IBC最大内容積、Tコード要件等の整理情報
2. 国内法令の適用条件・規定内容、注記、追加規定
3. 国内法令の原文リンク
4. ページ最下部のIMDG Code原文リンク

対象系列は、P、LP、IBC、T、TP、BK、PP、B、VV、CV、V、SW、S、SPを含む。

## 国内法令本文中のコード

- 国内法令の「適用条件・規定内容」「注記」「追加規定」に現れるPP、B、T等は通常文字で表示する。
- 国内法令本文中にはIMDG Codeへの個別リンクを置かない。
- 選択中のコード自身に検証済みのIMDG Codeページがある場合、画面最下部へ独立した原文リンクを表示する。
- IMDG Code PDF内で確認できない国内独自コードには、推定ページを設定しない。

## 原文ページの追加確認

- P112：IMDG Code PDF 173ページ（P112(a)、P112(b)。P112(c)は174ページへ継続）
- PP89：IMDG Code PDF 197ページ
- PP97：IMDG Code PDF 197ページ

## デザイン

既存の色、フォント、文字サイズ、罫線、角丸、余白は変更しない。表示内容とリンク配置のみを整理する。

## 自動検証

`tools/verify-part493-all-dangerous-goods-and-code-order.mjs` により、以下を確認する。

- 危険物データ2,725行すべての判定基準分類対応
- 使用コード483件すべての国内法令原文・掲載ページ
- 使用コード478件の検証済みIMDG Codeページ
- 国内法令本文中のコードリンク抑止
- 国内法令リンクの後にIMDG Codeリンクを配置
- part493のキャッシュ識別子

検証結果は `docs/part493-all-dangerous-goods-and-code-order-audit.json` に保存する。
