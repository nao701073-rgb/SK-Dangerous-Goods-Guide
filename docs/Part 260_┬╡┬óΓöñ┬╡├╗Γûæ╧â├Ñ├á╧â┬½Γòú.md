# Part 260 更新内容

## 等級検索の全体統一

- 利用者向け表示は「主等級」ではなく「等級」に統一しました。
- 等級プルダウンは、火薬類 `1.1～1.6`、高圧ガス `2.1～2.3` を個別に選択できます。
- 次の類別を一括検索項目として維持しました。
  - `4 可燃性物質類`：4.1、4.2、4.3
  - `5 酸化性物質類`：5.1、5.2
  - `6 毒物類`：6.1、6.2
- 個別区分も引き続き選択できます。
- 副次危険性等級は `1 / 2.1 / 3 / 4.1 / 4.2 / 4.3 / 5.1 / 6.1 / 8` のみに限定しています。
- 火薬類の副次危険性標札は、区分にかかわらず共通の数字「1」を使用します。
