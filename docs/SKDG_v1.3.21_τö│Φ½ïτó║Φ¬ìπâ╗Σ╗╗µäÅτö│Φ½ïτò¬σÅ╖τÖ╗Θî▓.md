# SKDG v1.3.21 申請確認・任意申請番号登録

## 目的
申請書確認の結果を申請番号管理へ登録する際、固縛力参考算出と同様に、登録直前の画面で申請年度・申請番号を入力または変更できるようにしました。

## 変更内容
- 「4．申請番号管理へ登録」に以下の入力欄を追加しました。
  - 申請年度
  - 申請番号（4桁または5桁）
  - 案件名（任意）
- 申請書から読み取れた年度・申請番号・案件名は、登録欄へ候補として反映します。
- 登録欄の値は利用者が自由に変更できます。
- 登録欄で変更した年度・申請番号を、実際の申請番号管理への登録先として使用します。
- 同じ年度・申請番号がすでに登録済みの場合は、新しいカードを作らず既存案件へ「申請確認・許容容量／質量」の結果を追加します。
- 同じ案件カードに「固縛力参考算出」が登録済みの場合も、そのカードを共用します。
- 案件名は任意で、空欄でも登録番号の判定には影響しません。

## 既存仕様の維持
- 原本照合者は任意のままです。
- 原本照合者が空欄でも登録できます。
- 申請確認結果と固縛力参考算出結果は別結果として保存し、申請詳細で個別に確認できます。
- DBマイグレーションはありません。
- 画面表示バージョンは「Version 1.0 試作版」のままです。
