# SKDG v1.3.100 COMPLETE VERIFIED SYSTEM — 完成版検証報告

## 1. 基準と変更範囲

v1.3.98完全版を正式基準として、固縛力参考算出の画面全体を再整理した完成版です。CTU Code / CSS Code の計算コア、方向別必要抵抗力、摩擦、MSL、壁抵抗、支保・直接固縛の重複制限は変更していません。変更対象は、7段階ワークフロー、カード共通化、見出し帯と本体境界、余白・色・枠線、1列/2列表示制御、算出状態同期です。

正式な流れは次の7段階です。

1. 申請書・航路から入力する
2. 写真を撮影・アップロードする
3. 輸送条件と貨物を確認
4. 貨物底面とCTU床面を確認
5. 固縛・支保条件を確認
6. 壁面の隙間・壁抵抗利用を確認
7. 参考算出を確認

## 2. カード表示の最終整理

- 主要カードの外枠は上下左右すべて1pxで統一しました。
- Step 5の固縛材／支保・あて材の内側カードも上下左右1pxで統一しました。
- 旧CSSの `border:0!important`、左側だけの太線、`inset 3px 0 0`、結果カードの `border-left:4px` 等が再び勝たないよう、最終カスケードガードを追加しました。
- 壁抵抗カードは未選択時1px四辺、選択時2px四辺で統一し、左だけ強調される状態をなくしました。
- 結果メトリクスと総合判定も四辺1px、box-shadowなしです。
- 見出し帯は margin 0、paddingを共通化し、角丸や枠が本体と二重にならないよう整理しました。
- 見出し下端と本文上端のgapは0px、overlapはfalseです。
