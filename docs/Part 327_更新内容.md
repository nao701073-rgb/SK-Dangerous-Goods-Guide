# Part 327 更新内容

## ログイン導線・再認証時の操作性強化

- 認証済みの利用者がログイン画面を開いた場合、ログイン画面を一瞬表示せず、適切な画面へ自動移動するようにしました。
- 認証前に開こうとしていた画面を `next` パラメータで安全に保持し、ログイン成功後に元の画面へ戻れるようにしました。
- 外部サイトや本システム外のパスを `next` に指定しても移動しないよう、同一オリジン・システム配下だけを許可します。
- 初回パスワード変更が必要な利用者は、指定先より先にパスワード変更画面へ移動します。
- ログインIDの前後空白を自動除去し、スマートフォンの自動大文字化・スペル補正を無効化しました。
- 認証失敗時はパスワード欄へ戻り、再入力しやすくしました。
- ログイン成功演出中の二重処理を防止し、クリック・Enter・Escapeで演出を早めに終了できるようにしました。
- 自動ログアウト後にログイン画面へ戻った場合、理由を分かりやすく表示します。

## 維持した仕様

- 時間帯別ログイン画面（06:00～10:00、10:00～16:00、16:00～19:00、19:00～06:00）
- 控えめなSKロゴ成功演出
- ログイン後の白・青基調の画面
- MFA、初回パスワード変更、権限制御
- ゲスト権限での申請番号管理非表示・直接アクセス拒否
