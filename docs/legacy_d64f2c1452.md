# Part 306 更新内容

## 関連資料の確認期限・緊急度表示

- 確認期限の絞り込みに「3日以内」「14日以内」を追加しました。
- 並び順に「期限の緊急度順」を追加し、期限超過、本日期限、7日以内、将来期限、確認済み、期限未設定の順で確認できるようにしました。
- 資料カードに「残り○日」「○日超過」を表示し、確認期限までの状況を把握しやすくしました。
- 件数カードに「本日期限」「7日以内」を追加し、該当資料へ直接絞り込めるようにしました。
- 日付判定を日単位へ統一し、本日期限の判定精度を改善しました。
- 既存の確認手続き、期限、お気に入り、要確認、メモ、閲覧履歴との互換性を維持しています。
