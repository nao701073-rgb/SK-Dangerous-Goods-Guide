# part480 固縛力参考算出：Excel申請書直接取込み・航路推定

## 変更内容

- 固縛力参考算出画面へ `.xls` / `.xlsx` の直接アップロードを追加。
- 申請書から、船積港、陸揚港、申請番号、貨物名、国連番号、個数、コンテナ番号、貨物質量、貨物寸法を可能な範囲で抽出。
- 抽出した情報を固縛力参考算出の入力欄へ反映し、取得できない項目は手入力で補完可能。
- 「申請書確認」で読み込んだ結果やブラウザ保存値の引継ぎは行わない。
- 船積港、陸揚港、想定出港月から一般的な航海ルートを簡易推定し、海域A・B・Cの初期候補へ反映。
- 日本沿岸、東アジア域内、北太平洋、北大西洋、スエズ運河経由、喜望峰周辺などの一般的なルートを判定対象に追加。
- 算出結果を申請番号管理へ保存する際、Excel取込み情報、船積港、陸揚港、想定出港月、航路推定結果も保存。

## 安全上の扱い

航路・海域の判定は、港名と一般的な航路に基づく簡易推定であり、実際の配船・寄港地・迂回・季節・気象海象を保証しない。船社の予定航路、Cargo Securing Manual、気象・海象情報を確認し、必要な場合は利用者がより厳しい海域へ変更する。

Excel申請書から取得したG/WまたはN/Wの合計は、申請書の様式・記載単位によって意味が異なる場合があるため、原本と照合してから算出に使用する。
