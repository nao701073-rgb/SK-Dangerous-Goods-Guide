# part50: 品名・国連番号表示ガイド / N.O.S.補足 改修

## 対応内容
- 「別表第一」表記を「別表第1」に統一
- 品名・国連番号表示ガイドに「※一例」を表示
- スマホ画面での実寸比較を、正式輸送品名と国連番号の両方に対応
- 実寸比較で 12mm / 6mm を切替可能に変更
- N.O.S.（技術名／Technical Name）の補足を、SDS由来の候補表示のみに限定
- 想像・推測ベースの候補表示を廃止
- 備考・特別規定の表示を、該当条文コードに応じて併記

## 補足
- SDSアップロードはテキスト形式を直接読込可能
- PDF等で文字抽出できない場合は、SDSの成分情報欄を貼り付けて使用
