# SKDG v1.3.29 Performance Hotfix — 累積軽量化

v1.3.24〜v1.3.29で行った軽量化を1つにまとめた累積Hotfixです。

## 対象
- v1.3.23〜v1.3.28
- v1.3.28適用済み環境へ上書きしても問題ありません。

## 主な軽量化
1. 申請番号管理
   - 案件・写真・資料・結果のストレージ読込を画面更新ごとにまとめて実行。
   - 案件ID別索引を作成し、カードごとの全件filterを削減。
   - 検索入力時はデータ変更がなければキャッシュを再利用。
   - 簡易メモ欄の案件選択でも案件一覧キャッシュを再利用。
   - 案件削除時も写真・資料を案件ID索引から取得。

2. 申請書確認
   - Excel解析用SheetJSを必要時のみ読み込む方式へ変更。
   - CSV確認時にはExcelライブラリを読み込まない。

3. 固縛力参考算出
   - 不要な全DOM再走査を削減。
   - 案件一覧をキャッシュ。
   - 取付点MSL台帳等の補助処理を必要時に初期化。
   - 初回計算・補助一覧処理を初期描画後へ分離。
   - 旧互換・拡張スクリプトをdefer実行へ変更。
   - 全材質比較表は「全材質の比較表を表示」を開いた時だけ生成。

## 維持事項
- 固縛力計算式、MSL/STF候補、危険物判定ロジックは変更なし。
- 申請番号・写真・添付・確認結果の保存形式は変更なし。
- 権限、DB構造、表示版「Version 1.0 試作版」は変更なし。
- DBマイグレーションなし。
