# SKDG v1.3.10 写真AI候補・全項目訂正

- 申請書取込、写真AI候補、登録済み案件から反映した入力値は、反映後も各入力欄で直接訂正可能。
- 訂正後は「参考算出する」を再実行して結果を更新する。
- 写真から画像で判断できる範囲をローカル補助解析し、以下を候補表示する。
  - 固縛材（ベルト・ウェビング系）
  - 写真で見える固縛本数
  - 暗色直線からの参考鉛直角
  - 木製支保・当て材の有無候補
  - 汎用コンテナの外観候補
- AI候補は自動確定せず、利用者が選択して反映する。
- 写真だけでは確定できない輸送海域、貨物質量、貨物名、MSL、貨物側取付部MSL、CTU側取付点MSL、支保力、接触面の正確な状態は推測しない。
- MSLは刻印・銘板・メーカー仕様・証明書・試験成績などの確認を優先する。
- 常時 `MutationObserver` 監視は使用せず、写真選択・解析ボタン等の明示イベント時だけ解析するため、v1.3.9の動作安定化を維持する。
- 表示バージョンは `Version 1.0 試作版` を維持。
- DB移行なし。

## 写真測定欄の訂正
- 「写真で確認・推定した鉛直角（°）」を数値入力欄として追加。
- 「写真で確認・測定した長さ（m）」を数値入力欄として追加。
- 「写真で確認した固縛本数」と合わせて、AI候補・写真測定後に直接数値を訂正してから「写真入力をかんたん入力へ反映」を実行できる。
