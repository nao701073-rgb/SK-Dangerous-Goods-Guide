# Part558 固縛力前回結果再利用・入力ミス防止

## 目的
登録済み申請の固縛力算出を繰り返す際の再入力を減らし、簡易入力での入力漏れを早い段階で発見する。

## 変更点
1. 申請案件選択時に、同一申請の固縛力算出最新版を検索する。
2. 最新版が存在する場合は、判定・登録日時・貨物質量・固縛方法・本数・最厳方向を表示する。
3. 「最新版の条件を読み込んで再計算」から resultKey 付き再計算画面へ移動し、Part550以降の復元機能を利用する。
4. 新しい条件で算出する場合は「新しい条件で続ける」で再利用案内を閉じる。
5. 簡易入力では貨物質量、本数、MSL/STFに加え、直接固縛時の貨物側MSL・CTU側MSL・鉛直角、固縛＋支保併用時の支保個数・支保力を確認する。
6. 入力不足は警告のみとし、既存の計算式や自動判定条件は変更しない。
7. 申請詳細の最新版操作パネルに「次にすること」を追加する。

## 非変更範囲
- CTU/CSS計算式
- 摩擦係数の計算処理
- MSL最小値判定
- 方向別必要抵抗力
- 固縛・支保併用の計算ロジック
- 申請番号管理の保存データ構造
