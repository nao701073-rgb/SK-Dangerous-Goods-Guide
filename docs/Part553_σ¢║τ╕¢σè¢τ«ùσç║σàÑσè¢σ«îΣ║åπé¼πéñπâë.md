# Part 553 固縛力参考算出・入力完了ガイド

## 目的
Part 552の簡易モードを維持し、利用者が「何を入力済みか」「次に何をすればよいか」を迷わず確認できるようにする。

## 変更内容
- 貨物質量、材質、本数・個数、確認済みMSLの入力状況を4項目で常時表示。
- 未入力項目を黄色、入力済みを完了表示とし、「不足項目を確認」で最初の不足欄へ移動。
- 基本入力完了後は「算出して登録確認へ進む」へ案内。
- 入力→算出→確認→登録の4段階ガイドを表示。
- 申請番号管理から案件を選択した場合、自動入力されたことを明示。
- 登録済み固縛力結果を再計算する場合、復元時点から条件変更があるかを表示。
- スマートフォンでは画面下部に「次へ」ナビを固定表示し、不足項目・算出・確認・登録欄へ案内。

## 非変更範囲
- CTU/CSS計算式
- 加速度係数
- 摩擦抵抗計算
- 固縛材・貨物側・CTU側の最小MSL判定
- 支保・当て材併用ルール
- 方向別必要抵抗力、余裕・不足判定
- 申請番号管理への保存データ構造

DBマイグレーションはありません。
