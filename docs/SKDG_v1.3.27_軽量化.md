# SKDG v1.3.27 Performance Hotfix

## 目的
機能を削らず、固縛力参考算出画面の初期表示と案件データ参照の負荷をさらに下げる。

## 実施内容
- `ctuApplications()` に画面内キャッシュを追加し、同じ案件一覧のストレージ読込を繰り返さない。
- `iss:applications-changed` 発生時のみ案件キャッシュを無効化する。
- 取付点別MSL・根拠写真台帳は、MSL候補パネルを開くまで初期化しない。
- 案件一覧生成、レビュー更新、初回 `calc()` は `requestIdleCallback`（非対応環境は `setTimeout`）へ分離する。
- 大きな画面外パネルは `content-visibility:auto` により描画を遅延する。印刷時は解除する。

## 互換性
- DB移行なし。
- v1.3.26までの保存データをそのまま使用。
- 計算ロジック・保存ロジック・権限制御は変更しない。
