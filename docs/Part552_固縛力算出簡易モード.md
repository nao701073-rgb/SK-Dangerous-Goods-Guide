# Part 552 固縛力参考算出・簡易モード

## 目的
Part 551の3段階操作を維持しつつ、通常利用者が最初に見る入力項目をさらに絞り、詳細条件を必要時のみ展開する。

## 変更内容
- 「簡易モード」案内を追加。
- 基本入力は、輸送条件、CTU種類、貨物質量、貨物名、接触面、使用方法、固縛方法、材質、対象方向、本数、確認済みMSLを中心に表示。
- 摩擦係数μの数値入力は「摩擦係数の数値を確認」に折りたたみ。
- 貨物側取付部MSL、CTU側固縛点MSL、鉛直角、強度根拠は「取付点MSL・角度・強度根拠を確認」に集約。
- 材質・サイズからのMSL候補、写真、取付点台帳は従来どおり必要時のみ展開。
- 現在の基本固縛条件を1行で要約表示。
- 「次へ」操作時に不足項目があれば、その入力欄へ移動して案内。
- 「算出して登録確認へ進む」を追加し、算出後に登録前確認へ自動移動。
- 登録前確認欄に、登録までの残作業を表示。

## 非変更範囲
- CTU/CSS計算式
- 加速度係数
- 摩擦抵抗計算
- 固縛材・貨物側・CTU側の最小MSL判定
- 支保・当て材併用ルール
- 方向別必要抵抗力、余裕・不足判定
- 申請番号管理への保存データ構造

DBマイグレーションはありません。
