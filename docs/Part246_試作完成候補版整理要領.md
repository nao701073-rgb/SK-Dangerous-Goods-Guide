# Part 246 試作完成候補版整理要領

## 1. 目的
Part 246は、配置先に依存しない画面、権限、データ、運用機能、監査機能および完成版文書を統合し、試作完成候補版として確認するための版である。

## 2. 完成候補版に含む範囲
- ユーザー設定とシステム設定の分離
- 6役割のアクセス制御
- 危険物検索、関連法令、関連資料、申請番号・写真管理
- 法令・データ更新、品質監査、公開判定
- ログイン、MFA、利用者一括登録、権限管理
- 利用履歴、監査、日次・週次・月次集計
- バックアップ、復元、障害、是正、受入・定期点検
- Part 243完成版文書

## 3. 配置先決定後に実施する事項
クラウド配置先、専用URL、HTTPS、CORS、認証メール、初期利用者登録、50名・150名性能試験、写真・DB復元試験、実端末確認、職制承認および利用者周知は、配置先決定後に実施する。

## 4. 確定方針
- 本システムの利用は任意とする。
- 安全環境室長は全事業所の申請番号・写真を閲覧、登録、編集できるが、削除できない。
- 安全環境室職員は全事業所の申請番号・写真を閲覧できる。
- 透かし、スクリーンショット検知・追跡、画面自動保存は現時点では実装しない。
