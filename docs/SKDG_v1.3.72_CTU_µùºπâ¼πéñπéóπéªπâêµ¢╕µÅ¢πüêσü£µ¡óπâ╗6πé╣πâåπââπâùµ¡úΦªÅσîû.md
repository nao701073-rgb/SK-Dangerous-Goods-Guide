# SKDG v1.3.72

## 目的
固縛力参考算出で、旧PART・初期v1系JavaScriptが後からStep見出しや配置を書き換える問題を根本停止する。

## 修正
- 6ステップを入力フィールドIDから特定し、①申請書 → ②写真 → ③輸送・貨物 → ④接触面 → ⑤固縛・支保 → ⑥参考算出 の順序を正規化。
- `v1-ctu-simple.js`、`v13-ctu.js`、`v136-ctu-flow.js`、`v1355/56/57`の旧レイアウト変更ファイルを互換no-op化。
- `v1349-ctu-ui-unification.js` のCTU画面読込を停止（Step 6見出し書換えを廃止）。
- 6ステップ見出しだけを監視する限定MutationObserverを追加。旧キャッシュ等による遅延書換えが発生しても正規表示へ戻す。
- 上部追跡表示の外側の丸角・影・外枠を完全に廃止し、平坦な追跡帯へ統一。
- Step 5の内側カード外枠を廃止。
- 固縛方法は引張系/併用時に「直接固縛」「トップオーバー」の2択を保持。支保のみの場合だけ無効化。

## 計算
計算コア `ctu-securing-calculator-core-v1371.js` は変更していない。
