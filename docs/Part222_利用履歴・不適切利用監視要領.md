# Part 222 利用履歴・不適切利用監視要領

## 目的
情報漏えい、不正利用、業務上必要な範囲を超えた大量閲覧を抑止・調査する。一般的な人事評価や私的監視には使用しない。

## 記録対象
ログイン・認証、危険物検索・詳細、関連法令、関連資料、申請番号、写真、ユーザー設定、システム設定、管理操作。

## 管理者機能
システム管理者のみ利用者を選択して履歴を確認できる。履歴確認操作自体も監査ログへ記録する。JSONレポートを証跡として出力可能。

## 異常利用候補
短時間の大量閲覧を候補として表示する。警告だけで利用者を断定・処分せず、業務理由、担当案件、誤操作等を確認する。

## 未実装方針
透かし表示およびOSスクリーンショットの追跡は現時点では実装しない。将来必要になった際に別途追加する。
