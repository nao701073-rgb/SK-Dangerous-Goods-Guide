# Part 214 クラウド試験運用実施要領

## 1. 対象
初期50名（安全環境室長1名、安全環境室職員5名、事業所利用者等44名）を基本とし、将来150名までの拡張確認を行う。

## 2. 実施順序
1. `npm run pilot:users-template` で登録CSVを生成する。
2. 氏名、メール、所属、役割を入力し、`npm run users:import -- data/users.csv --dry-run` で検証する。
3. 安全環境室長1名、職員5名が全事業所閲覧・編集不可であることを確認する。
4. 招待、初回パスワード変更、MFA、再設定メールを確認する。
5. `npm run pilot:roles` で役割マトリクスを検証する。
6. `VIRTUAL_USERS=50 npm run pilot:load` と `VIRTUAL_USERS=150 npm run pilot:load` を実施する。
7. DB・写真のバックアップと復元を確認する。
8. 管理画面「クラウド試験運用パッケージ」に証跡を登録する。

## 3. 開始条件
安全環境室6名の登録、MFA必須対象の設定、権限試験、50名性能試験、メール試験、バックアップ・復元試験が合格していること。150名試験は正式拡張前に合格させる。
