# Part 585 重点確認・優先キュー・ライン根拠統合アップデート

## まとめ対象
Part 581〜585相当をPart 585として一括反映する。ベースはPart 580。

## 申請書確認
- 前回登録内容との差分を重要差分とその他差分に分ける。
- 国連番号、品名、等級、容器等級、容器コード、個数、重量、包装要件、コンテナ番号等を重要差分として優先する。
- 重要差分を順番に直接確認できる。
- 利用者の明示操作で「現在内容を確認基準」に設定し、その後の変更を同一タブ内で検知する。
- 確認基準はsessionStorageの作業補助のみで、reviewEvidence、確認済み判定、登録可否、申請データへ保存しない。

## 申請番号管理
- 検査予定日・実施日と申請書/MSL確認状態を組み合わせた優先キューを追加する。
- 期限超過、本日、3日以内、7日以内を優先度へ反映する。
- 申請書確認記録なし、要確認あり、MSL未確認を合わせて優先順位を表示する。
- 最優先案件を1操作で選択でき、一覧を明示操作でコピーできる。
- 優先度は表示・選択補助であり、案件の正式な進捗状態は変更しない。

## 固縛力参考算出
- 取付点台帳の固縛ライン指定から、ライン別MSLカバレッジを表示する。
- 固縛材、貨物側、CTU側、採用MSL、制限要因、取付点確認状況をライン単位で表示する。
- 不足ラインを優先し、成立済みの場合は最弱ラインを表示する。
- 最後の算出日時・算出後条件変更の有無を「算出鮮度」として表示する。
- 現場引継ぎ要点を明示操作でコピーできる。
- 既存のmslLineRows、採用MSL計算、取付点確認、登録可否を変更しない。

## 維持事項
- 危険物判定、許容容量・許容質量判定を変更しない。
- reviewEvidence形式を変更しない。
- 海上輸送海域B初期値を変更しない。
- 直接固縛の最小MSL、引張系＋支保材併用計算を変更しない。
- MSL写真・取付点台帳・履歴・保存形式を変更しない。
- DBマイグレーションなし。
