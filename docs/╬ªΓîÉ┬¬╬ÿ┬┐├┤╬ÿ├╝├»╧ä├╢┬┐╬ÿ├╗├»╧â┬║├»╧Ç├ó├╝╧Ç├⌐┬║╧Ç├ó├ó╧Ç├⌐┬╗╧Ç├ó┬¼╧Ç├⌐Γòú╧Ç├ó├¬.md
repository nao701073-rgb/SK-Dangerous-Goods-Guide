# 試験運用開始チェックリスト

## 1. 体制
- [ ] 試験運用責任者を決定した
- [ ] 川崎事業所の事業所管理者を決定した
- [ ] 管理者と代行者を決定した
- [ ] 問い合わせ・障害連絡先を周知した

## 2. アカウント・権限
- [ ] 利用者ごとに個別ログインIDを発行した
- [ ] 初期パスワード変更を確認した
- [ ] メール認証コードの送受信を確認した
- [ ] 利用者・事業所管理者・管理者の表示範囲を確認した
- [ ] 自己承認ができないことを確認した

## 3. 法令データ
- [ ] 危規則の版・施行日・原本PDFを確認した
- [ ] 危告示の版・施行日・原本PDFを確認した
- [ ] IMDG Codeの版・適用日・原本PDFを確認した
- [ ] その他対象法令の版を確認した
- [ ] 検索結果と原文をサンプル照合した
- [ ] 改正時の更新・承認・公開手順を確認した

## 4. 申請番号・写真
- [ ] 申請番号の登録・編集・検索を確認した
- [ ] スマートフォン撮影写真の自動圧縮を確認した
- [ ] 写真の縦横向き、容量、重複検出を確認した
- [ ] GPS保存の初期設定と社内方針を確認した
- [ ] 削除、復元、保全指定、完全削除承認を確認した

## 5. サーバー・通信
- [ ] 社内APIへHTTPS接続できる
- [ ] PostgreSQLマイグレーションを適用した
- [ ] 複数端末間の同期を確認した
- [ ] オフライン時の継続利用と復帰後同期を確認した
- [ ] メール認証・パスワード再設定を確認した

## 6. 保守・復旧
- [ ] バックアップを取得した
- [ ] 復元前検査と復元訓練を実施した
- [ ] 障害記録と連絡手順を確認した
- [ ] 定期点検の担当者と周期を設定した
- [ ] ログ・証明書・監査履歴の保存方針を確認した

## 7. 受入判定
- [ ] 静的QAが合格した
- [ ] 主要ブラウザ・スマートフォンで表示を確認した
- [ ] テストケースを実施し重大不具合がない
- [ ] 残課題と暫定対応を記録した
- [ ] 事業所管理者または管理者が試験運用開始を承認した
