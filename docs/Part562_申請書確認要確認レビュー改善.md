# Part562 申請書確認かんたん操作・要確認レビュー改善

## 目的
Part561の4段階ガイドを維持しつつ、「要確認を見たが警告が残り続けるため、未確認か確認済みか分からない」状態を解消する。

## 変更
- 自動確認の要確認事項を「未確認」「人が確認済み」「入力修正が必要」に分離。
- P200許可、原文確認、容量比較など、人による照合で完了できる要確認に「内容を確認済みにする」を追加。
- 確認済みにしても、P200・IBC・T等の法令上の警告表示・原文参照は消さない。
- 規定量超過、包装要件不一致、国連番号不足、容器コード不足等は確認済み化できず、入力修正を案内。
- 「前の要確認」「次の要確認」を追加し、現在の要確認番号と理由を表示。
- 確認済み警告件数と未確認・要修正件数を上部に分けて表示。
- ログイン利用者名を原本照合者の候補として自動入力し、必要に応じて変更可能。
- 登録時、確認済みにした危険物No.を確認メモへ短く自動追記。
- 危険物の入力値を変更した場合は確認キーが変わるため、旧確認状態を自動的に引き継がない。

## 維持する仕様
- P包装、P200、IBC、ポータブルタンクの既存判定・許容値。
- P200「x」の許可案内。
- 少量危険物、同一単位の規定量超過、L/kg異単位±20%注意喚起。
- 申請番号管理への新規登録／既存更新／登録後詳細確認。
- 固縛力参考算出の計算式・保存データ。

## データ移行
DBマイグレーションなし。
