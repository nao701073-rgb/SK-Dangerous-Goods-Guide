# Part 311 更新内容

## 本番認証・パスワード管理の強化

- ユーザー設定から、ログイン中の利用者が本人確認のうえパスワードを変更できる導線を追加した。
- 初回強制変更と任意変更で、説明文・ボタン・戻り操作を切り替えるようにした。
- パスワード変更後は、当該利用者のトークンバージョンを更新し、既存セッションをすべて無効化する。
- 変更後はログイン画面へ戻し、新しいパスワードによる再ログインを求める。
- パスワード再設定時も既存セッションを無効化する。
- ログイン画面に変更完了メッセージを表示する。

## 互換性

- 初回ログイン時の強制パスワード変更、MFA、アカウントロック、ログイン成功時のSK演出を維持する。
- ログイン後の表示テーマおよび既存データの保存形式は変更しない。
