# 第102回 法令適用日・旧版参照管理

## 目的
法令PDFを改正ごとに追加する運用で、施行前・施行後・過去時点の判定根拠を正しく選択できるようにする。

## 追加仕様
- 各改正版に適用開始日と適用終了日を設定する。
- 同一法令の承認済み・公開版で適用期間が重複する場合は公開をブロックする。
- 基準日を指定して、その日時点で適用される版を一意に解決する。
- 旧版と公開時データスナップショットを保持し、過去案件の再確認に使用する。
- 将来施行版は現行版と併存させ、施行日までは検索結果へ反映しない。
- 訂正・遡及適用は通常改正と区別し、理由と承認記録を残す。

## 公開時の原則
新しい版の開始日を設定した際は、原則として直前版の終了日を前日に設定する。期間の空白または重複は警告対象とし、重複は公開不可とする。
