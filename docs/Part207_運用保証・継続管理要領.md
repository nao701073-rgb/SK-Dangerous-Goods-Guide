# Part 207 運用保証・継続管理要領

本機能は、約50名の試験運用から将来150名程度の正式運用を継続するため、利用者の異動・退職、障害、復元訓練、運用指標を一元管理する。

## 利用者ライフサイクル
異動、権限変更、利用停止、再開、退職を適用日付きで登録する。実際のアカウント変更は、承認後に利用者管理画面で実施し、監査履歴を残す。

## 障害管理
重大度、発生日時、影響範囲、事象内容を記録する。重大障害は利用停止や注意表示を含む暫定措置を検討し、原因・是正措置・復旧確認を記録する。

## 復元訓練
データベース、写真、全体システムを対象に定期訓練を行う。復旧時間、証跡、問題点、是正措置を保存する。

## 運用指標
有効利用者数、ログイン成功・失敗、ロック、未解決障害、期限超過タスク、バックアップ確認を日次スナップショットとして保存する。
