# SKDG v1.3.30 権限メニュー統一

## 対象
- オーバーパック表示用作成
- システム設定

## 許可する権限
- 安全環境室長 (`safety-environment-director`)
- 安全環境室職員 (`safety-environment-staff`)
- 検証者 (`validator`)
- システム管理者 (`safety-environment-admin`)

## 表示・アクセス
上記4区分だけ、メインメニューおよび各画面のサブメニューに対象機能を表示します。
権限外利用者はメニューを非表示とし、直接URLアクセスも許可しません。

オーバーパック表示用作成は、上記4区分の場合、所属事業所による従来の横浜大黒向け制限より権限判定を優先します。

## 維持事項
v1.3.29までの性能改善、申請番号管理、申請書確認、固縛力参考算出、保存形式、計算式、DB構造は変更しません。
