# Part 59: 参照表示の重複整理とIMDG原文の条件表示

- 国内法令の参照表示は、危規則・危告示の条文と、コードを含む別表第1の具体的な欄名を1回だけ表示。
- 「危告示 別表第1 小型容器包装要件欄」「同欄（P001）」等の重複を削除。
- IMDG Code参照先は、危告示原文に明記されたIMDG Codeの具体的な参照番号だけを表示。
- 一般的な章見出しや重複する参照先は表示しない。
- IMDG Code原文英語は、危告示の国内法令原文にIMDG Code参照番号が明記されているコードに限って表示。
- 危告示原文にIMDG Code参照がないコードでは、IMDG Code参照先・原文英語の欄を表示しない。
