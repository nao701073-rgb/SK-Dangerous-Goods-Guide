# Part 240 総合動作確認要領

## 1. 目的
完成版統合フェーズにおいて、ソース一式の基本的な整合性を同じ手順で繰り返し確認するための要領です。

## 2. 自動検査
`server`フォルダで次を実行します。

```powershell
npm run verify:integrated
```

検査対象は次のとおりです。

- HTML・JavaScript・JSON・リンクの静的参照
- ゲストからシステム管理者までの役割別権限
- 危険物データの公開判定
- 主要画面・構成ファイルの存在
- 画面側およびNode.js側JavaScriptの構文

結果は`docs/Part240_総合検証レポート.json`へ保存されます。

## 3. 画面での確認

`システム設定 → 開始・受入・定着 → 総合自動検査`から最新レポートを確認します。

## 4. 自動化できない確認

次の項目は配置先が決定した後に実施します。

- クラウドAPIへの実接続
- 認証・招待・パスワード再設定メール
- 50名・150名を想定した負荷試験
- 写真保存領域のバックアップ・復元
- PC・スマートフォン実端末表示
- 初期利用者、所属、役割の実データ

## 5. 判定
自動検査に不合格がある場合は公開候補にしません。すべて合格した場合でも、上記の実環境確認が完了するまでは試作完成候補として扱います。

- 透かし表示は未実装です。
