# Part 381 更新内容

## 改正検証フロー
- 新規ロール「改正検証者」を追加。
- 初期アカウント `revision-validator` を追加。
- 更新候補として保存した構造化データを、改正検証者の画面だけに反映。
- 通常利用者・本番データには未反映のまま保持。
- 危険物検索、法令、国内法令・IMDG対照、関連資料、オーバーパック表示を先行確認可能。
- 検証結果を「検証合格」「要修正」「検証待ち」で記録。
- 検証合格が記録されるまで承認済みデータの本番反映を禁止。
- 本番反映後は対象のプレビュー候補と検証記録を解除。

## 初期アカウント
- ログインID: `revision-validator`
- 表示名: 改正検証者用アカウント
- 権限: 改正検証者
- 初期パスワード: `TempPass!2026`
