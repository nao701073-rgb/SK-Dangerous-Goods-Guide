# Part 213 運用開始・定着管理要領

## 目的
初期利用者約50名での試験運用開始から90日後までを一つの画面で管理し、将来150名規模への拡張判断に必要な証跡を残す。

## 管理段階
1. 開始前：CSV登録、権限、データ品質、バックアップ、周知を確認する。
2. 開始日：ログイン、MFA、申請番号・写真、監査ログを確認する。
3. 7日後：未ログイン、ロック、問い合わせ、バックアップを確認する。
4. 30日後：権限棚卸し、性能、法令更新手順、復元確認を行う。
5. 90日後：不要アカウント、150名拡張課題、監査・障害対応、管理者移管計画を確認する。

## 権限
本画面はシステム管理者が利用する。将来、安全環境室長へ管理者権限を移行した後は、安全環境室長が管理する。

## 保存
準備版ではブラウザ内に保存し、JSONレポートを出力できる。クラウドAPI稼働後はSQL 068のテーブルへ保存する。
