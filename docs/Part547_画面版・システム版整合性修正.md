# Part 547 画面版・システム版の整合性修正

## 1. 修正対象
ホーム画面等の上部に表示される「画面版とシステム版が一致していません」の警告を修正する。

## 2. 原因
Part 546では全73 HTMLのうち、`index.html`、`pages/applications.html`、`pages/application-verification.html` の3ファイルだけ `sk-build` がPart545のまま残っていた。
一方、`data/build-manifest.js` はPart546であったため、版チェックが実不整合として警告していた。

## 3. Part 547の対応
- 全HTML 73ファイルの `sk-build` をPart547へ統一。
- 全HTMLの `build-manifest.js` のキャッシュキーを `v=547` へ統一。
- 全HTMLの `version-guard.js` のキャッシュキーを `v=547` へ統一。
- `data/build-manifest.js` のシステム版をPart547へ更新。
- 更新直後にHTMLだけがブラウザキャッシュへ残った場合、版チェックが一度だけキャッシュ回避付き再読込を実施。
- 一度再読込しても版不一致が残る場合だけ、実際の更新漏れとして警告を表示。
- 版が一致した後はキャッシュ回避用パラメータをURLから除去。

## 4. 方針
警告を単純に非表示にはしない。実際の更新漏れを検出する安全機能は維持し、通常の更新時に発生する一時的なキャッシュ不整合のみ自動回復する。

## 5. DB
DBマイグレーションなし。
