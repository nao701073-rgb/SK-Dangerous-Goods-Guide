# SKDG v1.3.17 申請確認・同一申請番号登録統一

## 1. 申請書確認の登録UIを固縛力参考算出と統一
- 申請書取込・確認画面の登録部を、登録先を明示して1つの青い登録ボタンで保存する形式へ整理しました。
- 登録ボタンは「この確認結果を申請番号管理へ登録」です。
- 同じ年度・申請番号が既に存在する場合は、新しい案件カードを作成せず、既存案件へ申請確認結果を追加します。
- 旧追従バー `v134IntakeActionBar` はv1.3.17画面では表示しません。

## 2. 原本照合者を任意化
- 表示を「原本照合者（任意）」へ変更しました。
- 原本照合者が空欄でも申請番号管理へ登録できます。
- 入力されている場合だけ、登録履歴・確認情報へ値を残します。

## 3. 申請確認結果を独立した登録結果として保存
- 申請確認・許容容量／質量の確認結果を `dangerous-goods-verification` として案件へ保存します。
- 危険物明細、許容容量・許容質量、確認結果、確認メモ、取込情報を登録結果として保持します。
- 原本ファイル自体は保存しません。

## 4. 固縛力参考算出と同じ申請番号を共用
- 申請確認と固縛力参考算出は同じ正式申請番号を使用できます。
- 同じ申請番号を固縛力参考算出側から入力した場合も、既存案件を検出して同じ案件IDを再利用します。
- 申請確認と固縛力参考算出の結果は互いに上書きせず、同じ案件カードに別結果として保存します。

## 5. 申請番号管理・詳細画面
- カード上部に「申請確認・許容容量／質量 ○件」「固縛力参考算出 ○件」を表示します。
- 詳細画面では「申請確認・許容容量／質量」と「固縛力参考算出」を別タブで確認できます。
- 申請確認タブにも登録件数を表示します。

## 6. 互換性
- 表示バージョンは `Version 1.0 試作版` のままです。
- DBマイグレーションはありません。
- v1.3.16で実施した固縛力参考算出の登録チェック廃止、画面整理、申請番号管理カード整理は維持します。

## 7. ログイン画面の以前のイラストを復元
- Part 529で使用していた時間帯別の港湾・コンテナターミナル背景を、そのまま再使用します。
- 06:00-10:00 朝、10:00-16:00 昼、16:00-19:00 夕方、19:00-06:00 夜の4種類を維持します。
- 背景CSSの時間帯連動指定が後続版で欠落していたため復元しました。
- `login-production.css` のキャッシュ識別子を v1.3.17 に更新し、旧CSSキャッシュで背景が消え続けないようにしました。
- 背景画像ファイルもHotfixへ同梱し、既存環境で画像が欠落している場合も復元します。
