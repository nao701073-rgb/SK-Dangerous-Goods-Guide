# Part446 更新内容

- ホーム画面の対象機能を次の順序に変更。
  1. 危険物申請書確認
  2. 固縛力参考算出
  3. AI画像解析（管理者のみ表示）
  4. 申請番号管理
  5. オーバーパック表示用作成
  6. 関連資料
- 左側メニューも、危険物申請書確認、固縛力参考算出、申請番号管理、オーバーパック表示用作成、関連資料の順に整理。
- 危険物申請書確認結果を申請番号管理へ登録できる機能を維持・確認。
- 固縛力参考算出結果を申請番号管理へ登録できる機能を維持・確認。
- 「固縛力参考算出」はCTUコードに基づく参考値である旨を表示。
- Excel申請書機能の説明文を「Excel申請書をドラッグまたはドロップし、対象危険物の許容容量と許容質量を一覧化します。」とする。
- AI画像解析は事業所管理者およびシステム管理者のみに表示し、非管理者には表示しない。
