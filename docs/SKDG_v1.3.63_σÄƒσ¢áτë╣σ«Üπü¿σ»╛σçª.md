# SKDG v1.3.63 原因特定と対処

## 特定した原因
CTU算出画面の見た目を制御する CSS が、v1348, v1349, v1356, v1357, v1358, v1359, v1360, v1361, v1362 と多数重なっており、
同じセレクタ（例：.ctu-step-card__head, #ctuExcelRoutePanel, #photoInputPanel, .ctu-status-chip, #ctuStep5Panels など）に対して複数の上書きが競合していました。
そのため、一部の修正が見た目に十分反映されず、直っていないように見える状態になっていました。

## 対処内容
- 競合していた v1348〜v1362 の CTUページ専用上書きCSSを、CTUページから読み込まない構成へ変更
- 代わりに、CTU算出画面用の単一スタイル `v1363-ctu-canonical-layout.css` を新設
- Step 1〜6 のカード、上部の入力状況、Step 5 の内側2カードを、この単一CSSで再定義
- これにより、画面全体の外枠・ヘッダー・余白・ステップ表示の競合を解消
