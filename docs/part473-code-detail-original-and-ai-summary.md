# Part 473 コード詳細原文表示・長文条文AI要約

- SP・E・SW・P・PP・SG・SGG・IBC・T・TP等、コード詳細画面の共通表示を見直しました。
- 「コード原文」と「国内法令原文」は、原文の文言を言い換えずそのまま表示します。
- 原文テキストは淡い青系、AI要約は淡い緑系とし、両者を明確に区別します。
- 「国内法令原文テキストAI要約」は、文字数・項目数・複数ページ等から長文と判定した条文だけに表示します。
- AI要約は原文中の文を項目別に抜き出す方式とし、固有名詞、法令用語、容器名、コード名を変更しません。
- P200は、現在開いている危険物の国連番号に該当する原文だけを表示します。
- PC・スマートフォンともに文字列が1文字ずつ崩れないよう、改行・折返し・余白を共通調整しました。
