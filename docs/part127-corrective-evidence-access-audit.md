# Part 127 証拠資料アクセス監査

## 目的
証拠資料へのアクセス履歴から、不適切または通常と異なる操作を抽出し、管理者が確認結果を記録できるようにします。

## 検出対象
- 閲覧権限がない資料へのアクセス試行
- ダウンロード理由必須資料に対する理由未入力の取得試行
- 同一操作者による10分以内5件以上の資料ダウンロード

10分以内10件以上の場合は高優先度として扱います。

## 操作権限
監査所見の確認・完了処理は、事業所管理者または管理者のみ実行できます。
事業所管理者は所属事業所内、管理者は全事業所を対象とします。

## 処理手順
1. 「直近24時間を監査」を実行
2. 未処理所見を確認
3. 関係するアクセス履歴、利用者、資料を確認
4. 確認結果・対応内容を記録
5. 処理済みに変更

## 留意事項
本機能の検出結果だけで不正と断定しません。業務上の一括確認や正当な大量取得の場合もあるため、管理者が事実確認を行います。
