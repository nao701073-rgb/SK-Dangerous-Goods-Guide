# Part 436 更新内容

## 申請数量の1容器当たり判定

- N/W（kg）は申請行全体の総正味質量として扱います。
- 「1容器当たり質量 = N/W ÷ 個数」を算出します。
- 固体は1容器当たり質量（kg）を許容質量と比較します。
- 液体は1容器当たり質量を登録密度で除し、1容器当たり換算容量（L）を算出します。
- 気体・高圧ガスは社内申請上の取扱いとして、N/W総量を個数で除した数値を1容器当たりのLとして扱います。
- 個数が未取得または0の場合は自動判定せず「要確認」と表示します。

例：UN1133、個数3、N/W 416 kg の場合、1容器当たり質量は 138.667 kg です。液体の場合は、この値を密度で除して1容器当たり容量を求めます。
