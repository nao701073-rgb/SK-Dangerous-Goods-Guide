# SKDG v1.3.7 Hotfix — 固縛力かんたん操作・根拠表示

## 利用者向け表示
- 公開前のため、画面上の版表示は **Version 1.0 試作版** に統一。
- 内部技術ビルドは v1.3.7 とし、更新履歴・不具合追跡だけに使用。

## 対応内容
- 「写真から登録」が開かない事象に対し、既存パネル／画像入力へ確実に接続する補助ハンドラを追加。写真入力自体は初期表示を維持。
- 「登録済み案件から入力する（必要な場合）」を初期折りたたみ。取付点MSL詳細台帳、現場貨物ユニット、不足説明など補助系も初期折りたたみ。
- 新規の案件名・貨物名は空欄。CTU種別は「汎用コンテナ」を初期値。
- ③から摩擦係数入力を除き、④「貨物底面とCTU床面」でCTU Code Appendix 2の組合せから参考値を設定。
- 直接固縛では既存計算式どおり静止摩擦係数の75%を使用。
- 固縛材の材質・製品プロファイルから1本当たりMSL候補を表示。本数変更時はMSL合計表示を追従。1本当たりMSL自体は本数で変化させない。
- 固縛材MSL、貨物側取付部MSL、CTU側取付点MSLを別値として保持し、単純なミラー入力を停止。
- CSS Code Annex 13のMSL係数と製品公称強度／刻印・証明値を根拠として表示。
- TY-GARDの一般選択肢を鉄道専用扱いしない。海上輸送でも選択可能。鉄道専用8 ton参考プロファイルだけは鉄道用途のまま残し、一般の手動確認プロファイルを海上でも利用可能にした。
- 参考算出後に使用根拠の要約を表示し、詳細は「算出根拠を開く」で別ウィンドウ表示。CTU Code／CSS Codeの原典導線も配置。
- バージョン不一致警告の根本原因を修正。同じ内部技術系列（v1.3.x）のパッチ差だけでは警告を出さず、本当に系列が異なる場合だけ警告する。

## 維持事項
- 既存の固縛力計算式は変更しない。
- MSL・摩擦係数等の候補は最終確定値ではない。刻印、メーカー仕様、証明書、試験成績、承認済みCargo Securing Manual等を優先する。
- DBマイグレーションなし。
