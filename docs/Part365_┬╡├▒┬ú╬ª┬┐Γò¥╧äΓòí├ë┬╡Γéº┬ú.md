# Part 365 検証結果

## 認証
- ローカル検証用12アカウントについて、IDと共通仮パスワードによる認証処理を実行し、全件で認証トークンと利用者情報が生成されることを確認しました。
- 監査履歴の保存値が `null` の場合でも、空配列へ復旧してログインできることを確認しました。
- システム管理者で利用者一覧を取得し、初期アカウントが12件であることを確認しました。
- 保護対象のHTML 52画面すべてに、未認証アクセスをログイン画面へ転送する `auth-bootstrap.js` が読み込まれていることを確認しました。
