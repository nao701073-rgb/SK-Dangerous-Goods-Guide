# SKDG v1.3.12 写真AI・UI・原典ジャンプ修正

## 写真AI
- 写真AIの大型・重複表示を廃止し、候補を「かんたん入力」の各編集可能欄へ直接表示します。
- 添付確認写真の黒色の細い平帯は **帯鉄（スチールバンド）候補** として判定する回帰確認を追加しました。アスラッシュ等の商品名は写真だけで確定しません。
- 帯鉄／ウェビング、本数、画像上の角度、木製枠・当て材を候補化します。取付点が写真で確認できない場合、直接固縛とは自動判定しません。
- MSL、貨物側取付部MSL、CTU側固縛点MSL、支保力、貨物質量は外観だけで確定せず、刻印・仕様書・証明書・試験成績等の確認を促します。

## コンテナと貨物寸法
- 汎用コンテナの初期値を **20FTドライコンテナ** とします。
- 入力者が 20FTドライ／40FTドライ／20FTリーファー／40FTリーファーを選択できます。
- CTU構造区分が汎用コンテナ以外の場合、コンテナサイズ・種類欄を表示しません。
- 写真AIは入力者が選択したコンテナを上書きしません。
- 選択コンテナの参考内寸と写真上の外形比から、貨物の **長さ・幅・高さ** を低確度のAI候補として表示します。単眼写真のため概算で、すべて直接訂正できます。

## UI整理
- 大きな「写真をAI解析」表示、重複した写真AI候補パネル、大型の収納確認カード、重複した「写真から入力する」バーを表示しません。
- 写真測定欄の見出しを「鉛直角（AI・写真測定）」「写真測定長さ」「固縛本数（AI・目視）」へ簡潔化しました。
- 収納可否はコンテナ選択欄の下に1行だけ表示します。

## 案件名
- 新規案件の「案件名（任意）」は空欄を維持します。Excel取込後も貨物名を案件名へ自動転記しません。登録済み案件を開いた場合だけ保存済み案件名を使用します。

## 原典ページへジャンプ
- CTU Codeはローカル原典PDFの実該当ページへ接続します（MSL page 85、ベルト page 86、固縛原則 page 93、直接固縛 page 98、配置評価 page 101、摩擦係数 page 109、摩擦例外 page 110）。
- CSS CodeはPart478で照合した **MSC.1/Circ.1623 Annex 13** の節・表対応を使用し、別ウィンドウの「原典ページへジャンプ」から該当PDFページへ直接接続します。ローカルのPart478照合索引も残します。

## 互換性
- 表示版は **Version 1.0 試作版** のままです。
- DBマイグレーションはありません。
- v1.3.9で実施した常時監視廃止を維持し、MutationObserverは追加していません。
