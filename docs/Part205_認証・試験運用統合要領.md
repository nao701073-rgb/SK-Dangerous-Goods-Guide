# Part 205 認証・試験運用統合要領

## 1. 目的

約50名で開始する試験運用を安全に実施し、将来150名程度へ拡張できるよう、利用者認証、アカウント点検、監査、バックアップおよび運用開始判定を一元管理する。

## 2. 管理画面

設定画面から「認証・試験運用管理」を開く。利用できる役割はシステム管理者とする。

## 3. 試験運用開始前の確認

1. 一般利用者、事業所管理者、安全環境室長、安全環境室職員、システム管理者のログインを確認する。
2. 事業所利用者は所属事業所のみ、安全環境室は全事業所を閲覧できることを確認する。
3. 安全環境室長・安全環境室職員が申請番号・写真を編集できないことを確認する。
4. 管理対象役割のMFA、パスワード再設定、ロック、強制ログアウトを確認する。
5. ログインおよび管理操作が監査ログへ記録されることを確認する。
6. データベースと写真保存領域のバックアップおよび復元手順を確認する。
7. 初期50名分のCSVをドライラン後に登録する。

## 4. アカウント棚卸し

月1回を目安に、未ログイン、ロック中、MFA未設定、90日以上未使用、有効期限切れを確認する。所見と是正対応をシステムへ保存する。

## 5. 150名への拡張判定

利用者一覧、申請番号検索、写真一覧、監査ログの応答時間を確認する。性能低下がある場合は、データベース索引、ページング、写真配信およびAPI実行環境の容量を見直す。

## 6. 注意事項

運用開始チェックを「確認済み」にする場合は、証跡または確認内容を記載する。実際に確認していない項目を形式的に完了させない。
