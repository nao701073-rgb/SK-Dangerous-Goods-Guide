# Part557 固縛力算出・最新版操作パネル統合

## 目的
申請番号詳細の「固縛力算出」タブで、Part555・556までに追加した操作カードと確認カードが上下に分散していたため、最新版の状態確認と次の操作を1か所へ集約する。

## 変更
- 最新版の判定、最厳方向の余裕・不足、確認事項数、確認者、登録日時を1枚のパネルへ表示。
- 要確認時は「確認事項を確認」を主操作として表示。
- 充足時は「最新版の条件で再計算」を主操作として表示。
- 新しい算出、過去履歴、最新版詳細は「その他の操作」へ整理。
- Part555の操作バーとPart556の確認状況カードは新パネル表示後に非表示とし、重複を解消。
- 最新版と前回結果の比較、過去履歴、再計算条件復元は維持。
- 固縛力の計算式、MSL最小値判定、摩擦、方向別計算、支保併用、保存データ構造は変更しない。
