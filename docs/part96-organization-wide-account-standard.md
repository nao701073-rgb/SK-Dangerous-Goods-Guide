# Part 96 全事業所共通アカウント標準

## 基本方針
- すべての事業所で、検査員一人ひとりに個別のログインIDとパスワードを発行する。
- 共通アカウント、部署共用アカウント、引継ぎ用共通IDは使用しない。
- 申請番号、写真、更新、削除、同期等の操作履歴は利用者単位で監査ログへ記録する。
- 事業所管理者アカウントは各事業所長本人が使用する。
- 有効な事業所管理者は原則として1事業所につき1アカウントとする。
- 事業所長交代時は、旧管理者アカウントを無効化後、新管理者アカウントを登録する。
- 事業所管理者は所属事業所の検査員と所属事業所データのみ管理する。
- 安全環境室管理者は全ブロック・全事業所を横断して管理する。

## 第一ブロックへの適用
首都圏サーベイセンター、川崎事業所、横浜事業所、横浜大黒事業所へ同一仕様を適用する。将来追加される他ブロック・他事業所にも同じ標準を継承する。

## 実装
- 利用者管理画面に個人専用IDと事業所長管理者の注意表示を追加。
- 事業所管理者の表示名を「事業所管理者（事業所長）」へ統一。
- サーバーAPIとPostgreSQLの双方で、1事業所につき有効な事業所管理者を1名に制限。
- 第一ブロック4拠点の利用者CSV雛形を追加。
