# Part 155 放告示の公的原典リンク対応

## 対応内容

- 「船舶による放射性物質等の運送基準の細目等を定める告示（放告示）」を、関連法令画面で**公的原典登録済み**として表示します。
- 放告示カードに「公的原典を開く」リンクを表示します。
- リンク先は同梱済みの次のPDFです。
  - `references/originals/radioactive-materials-notification.pdf`
- 法令レジストリと関連資料レジストリの名称・ファイル名・状態を統一しました。

## 対象ファイル

- `data/regulation-registry.js`
- `database/regulations/registry.json`
- `database/references/documents.json`
