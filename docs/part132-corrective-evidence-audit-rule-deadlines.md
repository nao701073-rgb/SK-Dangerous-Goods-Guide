# Part 132 監査ルール変更申請の期限・通知管理

## 追加内容
- 変更申請作成から7日後を承認期限として設定
- 承認後の適用期限を記録
  - 即時適用: 承認から1日
  - 予約適用: 予約日時から1日
- 承認待ち、予約適用待ち、期限超過、未確認通知を集計表示
- 申請一覧を状態別に絞り込み
- 通知確認者・確認日時を記録
- 期限超過でも自動承認・自動取消は行わない

## 権限
通知確認、承認、差戻し、適用は事業所管理者または管理者のみ実行できます。自己承認禁止は継続します。

## 運用
期限超過は処理漏れを示す警告です。内容を再確認し、承認、差戻し、適用または取消を実施してください。
