# Part 83 組織拡張・権限管理仕様

## 1. 初期対象
- 第一ブロック
  - 首都圏サーベイセンター
  - 川崎事業所
  - 横浜事業所
  - 横浜大黒事業所
- 統括部署：本部 安全環境室

## 2. 拡張方式
組織情報を `data/organization-master.js` に分離しました。
今後はブロックと事業所を組織マスタへ追加することで、検索・申請番号・写真のデータ構造を変更せずに対象事業所を拡張できます。

## 3. 権限
### 事業所利用者
- 所属事業所の申請番号・写真を登録、閲覧、削除
- 他事業所の申請番号・写真は表示しない

### 安全環境室
- 全ブロック・全事業所の申請番号・写真を横断閲覧
- 事業所による絞り込み
- 各事業所の申請番号件数・写真件数を一覧表示
- 任意の事業所を指定して申請番号を登録

## 4. データ識別子
申請番号・写真には以下を保存します。
- `blockId`
- `blockName`
- `officeId`
- `office`
- `createdByRole`

申請番号の重複判定は「事業所ID＋申請番号」で行います。

## 5. 実運用時の注意
現在の開発版はブラウザの localStorage を使用するため、別のPC・別の事業所間でデータは自動共有されません。
全事業所の実データを安全環境室が閲覧する本番運用には、社内サーバー、認証基盤、中央データベース、通信暗号化、監査ログ、バックアップが必要です。
この版では、本番実装前の画面、組織マスタ、データ項目、閲覧範囲、権限判定を先行実装しています。
