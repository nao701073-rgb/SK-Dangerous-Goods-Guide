# Part 107 写真登録の操作性向上

## 概要
写真登録機能について、現場で使いやすいように、写真選択方法、圧縮結果の可視化、重複登録防止、写真閲覧性を改善しました。

## 追加機能

### 1. 写真の取り込み方法
- ファイル選択
- ドラッグ＆ドロップ
- クリップボード貼り付け

### 2. 圧縮結果の表示
写真選択後に以下を表示します。
- 元画像の容量と形式
- 保存画像の容量、寸法、保存形式
- 削減率
- 1枚あたりの容量上限判定
- 同一申請番号への重複候補の有無

### 3. 重複登録防止
原則として、同じ申請番号に対して同一画像の再登録を防止します。
優先判定は以下です。
1. 画像ファイルの SHA-256 指紋
2. 指紋が取得できない場合は、ファイル名＋元画像容量

### 4. 拡大表示
登録済み写真から「拡大表示」を選択すると、写真本体とメタ情報を確認できます。

## 保存項目
写真データには以下を保持します。
- fingerprint
- originalFileSize
- fileSize
- imageWidth / imageHeight
- compressionMode

## 備考
- この開発版ではブラウザ内保存のため、データ容量が大きくなる場合があります。
- 本番運用では、写真本体はサーバーストレージ、DBにはメタ情報を保持する構成を推奨します。
