# Part 329 更新内容

## ログイン・多要素認証の通信安定性強化

- オフライン状態で認証要求を送信せず、接続確認メッセージを表示
- 認証中は確認コード欄、再送、戻る操作を一時的に無効化し、二重操作を防止
- 古い確認コードの照合・再送応答が、新しい認証状態を上書きしないよう制御
- 確認コードの期限切れ後はタイマーを停止
- 画面離脱時にMFA用タイマーを確実に解放
- ネットワーク切断・回復時の案内を追加
- ログイン画面の重要仕様を自動確認する回帰検証を追加

## 維持する仕様

- 4種類の時間帯別ログイン画面
- ログイン成功時のみ再生する控えめなSKロゴ演出
- 6桁の多要素認証コード、有効期限、再送待機時間、送信先の伏せ字表示
- ログイン後の白・青基調と既存の権限制御
- ゲスト・検証者の申請番号管理非表示および直接アクセス拒否
