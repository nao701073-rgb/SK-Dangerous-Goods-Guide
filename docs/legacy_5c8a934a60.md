# Part 330 更新内容

## 認証通信のタイムアウト・再試行案内

- ログイン、確認コード照合、確認コード再送、パスワード再設定受付に20秒の通信タイムアウトを追加
- サーバー応答が長時間戻らない場合、通信状態を確認して再試行するよう明確に案内
- タイムアウト後はボタンと入力欄を通常状態へ戻し、画面再読込なしで再試行可能
- パスワード再設定受付中はボタンを一時的に無効化し、二重送信を防止
- 通信完了後または失敗後に、パスワード再設定ボタンの表示と操作状態を確実に復元
- ログイン仕様回帰検証に、通信タイムアウトと再設定二重送信防止の確認項目を追加

## 維持する仕様

- 4種類の時間帯別ログイン画面
- ログイン成功時のみ再生する控えめなSKロゴ演出
- 6桁の多要素認証コード、有効期限、再送待機時間、送信先の伏せ字表示
- オフライン時の認証抑止、古い認証応答の無効化、MFAタイマー解放
- ログイン後の白・青基調と既存の権限制御
- ゲスト・検証者の申請番号管理非表示および直接アクセス拒否
