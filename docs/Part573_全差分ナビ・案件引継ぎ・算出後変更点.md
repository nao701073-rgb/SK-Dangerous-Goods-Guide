# Part 573 更新仕様

## 1. 申請書確認：全差分ナビ
Part 572の「今回の差分」を補助し、前回登録内容と今回入力中の主要差分を省略せず1件ずつ前後移動できるようにする。

- 基本情報の変更
- 危険物明細の変更
- 今回追加された明細
- 前回登録にあるが今回取込に見当たらない明細

「差分チェック済み」は画面内の確認進捗メモであり、申請書確認の `reviewEvidence`、確認済み判定、登録可否には使わない。進捗は同一タブセッション内のみ保持する。

## 2. 申請番号管理：案件引継ぎ要点
選択中案件の主要項目をテキストとして1か所に集約する。利用者が「要点をコピー」を押した場合のみクリップボードへコピーする。

対象例：申請番号、案件名、船名、コンテナ番号、検査予定・実施日、危険物件数、申請書確認状況、MSL取付点確認状況、次の確認、簡易メモ。

## 3. 固縛力参考算出：算出後変更項目の明示
最後に「この条件で算出する」を実行した時点の主要入力値を画面内に保持し、その後の入力変更を項目名付きで表示する。

- 変更前 → 現在を表示
- 最初の変更項目へ直接移動
- 「不足」という算出結果は従来どおり正常な参考算出結果として扱う
- 計算式、計算結果、登録可否、保存形式には介入しない

## 4. 互換性
DBマイグレーションなし。Part 572までの既存JS/CSSと保存データ形式を維持する。
