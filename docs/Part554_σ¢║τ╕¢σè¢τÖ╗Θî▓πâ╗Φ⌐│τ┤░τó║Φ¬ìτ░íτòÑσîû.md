# Part 554 固縛力登録・詳細確認簡略化

## 1. 登録前サマリー
登録操作の直前に、登録先・貨物質量・固縛方法・材質・本数・確認済みMSL・現在の算出判定を表示する。

## 2. 1ボタン登録の明確化
登録済み申請を選択している場合、登録ボタンへ対象申請番号を表示し、申請番号の再入力が不要であることを明示する。

## 3. 登録済み詳細
固縛力算出タブは最新版の要点を先頭表示し、方向別結果・取付点・確認事項は折りたたむ。過去履歴も従来どおり必要時のみ展開する。

## 4. 計算ロジック
既存の計算式、MSL最小値判定、方向別必要抵抗力、支保・当て材併用ロジックには変更を加えない。
