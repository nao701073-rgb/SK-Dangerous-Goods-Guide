# SKDG v1.3.83 固縛併用時の表示はみ出し修正

## 対象
- 固縛力参考算出 > Step 5 固縛・支保条件を確認

## 症状
- 固縛材が1種類のみのときは正常表示されるが、
  「引張系固縛材＋支保・当て材（併用）」で 2種類表示になると、
  入力欄・採用MSL表示がカード幅を超えて横にはみ出す。

## 修正方針
- 併用時の 2カードを標準で縦積み表示とし、カード幅不足を回避。
- 併用時の固縛材入力グリッドは 2列にし、長いラベル・入力欄の圧縮を避ける。
- 採用MSL表示は折返し可能にし、カード内に収まるようにする。
- 超横長画面のみ、視認性を保てる条件で 2カード横並びを許可。

## 非対象
- CTU/CSS の計算ロジック
- v1.3.81 の三段階判定
- v1.3.82 の写真ドラッグ＆ドロップ表示修正
