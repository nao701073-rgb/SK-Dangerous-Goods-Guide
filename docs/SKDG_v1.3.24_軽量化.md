# SKDG v1.3.24 Performance Hotfix

## 目的
v1.3.23の機能・表示・判定結果を維持したまま、操作時の不要な再読込とDOM再走査を削減します。

## 主なボトルネックと対策
1. **申請番号管理**
   - 旧実装ではカードごとに `getApplications` / `getPhotos` / `getApplicationDocuments` / application results 読込が繰り返されていました。
   - v1.3.24では画面更新開始時にスナップショットを1回作成し、全カードで共有します。
2. **固縛力参考算出**
   - 旧UI除去用処理が起動後複数回と広範囲のユーザー操作後に走っていました。
   - 初期処理を最小化し、旧UIが実際に存在する場合だけ限定再実行します。
3. **申請書取込・確認**
   - Excel解析用SheetJSを初期表示で取得していました。
   - Excel取込を選択した時のみ動的読込します。CSVでは不要です。

## 互換性
DB移行なし。v1.3.23へ上書き適用するHotfixです。
