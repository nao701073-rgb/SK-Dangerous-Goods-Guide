# Part 231 監査レポート配布・証跡管理要領

## 1. 目的
承認済みの週次・月次監査レポートについて、配布先、配布目的、配布方法、配布日時および実施者を記録し、監査資料の取扱いを追跡可能にする。

## 2. 基本方針
- 本システムの利用は任意です。
- 利用頻度の多寡を人事評価・業務評価へ使用しない。
- 配布対象は承認済み監査レポートに限定する。
- 配布先は業務上必要な者に限定し、不要な個人情報を記載しない。
- レポート生成、承認、出力、配布記録の閲覧も監査ログへ記録する。

## 3. 操作手順
1. システム設定から「利用履歴・不適切利用監視」を開く。
2. 承認済みレポートを選択する。
3. 配布方法、配布先、配布目的を入力する。
4. 配布記録を保存する。
5. 監査証跡一覧で生成・承認・配布の一連の履歴を確認する。

## 4. 権限
本機能はシステム管理者のみ利用可能とする。一般利用者、事業所管理者、安全環境室長、安全環境室職員、ゲストには表示しない。

## 5. 未実装機能
透かし表示、スクリーンショット検知・追跡、画面自動保存は実装しない。必要性が認められた場合に別途検討する。
