# Part 377 更新内容

## 修正原因
前回セッションの `iss-last-activity` が端末内に残った状態で再ログインすると、画面遷移先で無操作監視が古い時刻を読み取り、ログイン直後でもタイムアウトと判定して認証情報を削除していました。

## 修正内容
- ログイン成功時に無操作時刻、セッション開始時刻、セッショントークン識別値を同時に初期化
- 新しいトークンを検出した場合は、画面遷移先でも無操作時刻を現在時刻へ補正
- 不正値、未来時刻、前回セッションの時刻を検出した場合も安全に補正
- ログアウト時は関連するセッション管理値をすべて削除
- 管理者、事業所管理者、事業所利用者、安全環境室長、安全環境室職員、検証者、ゲストの全権限へ適用

## 対象画面
ユーザー設定、システム設定を含む、ログイン後の全内部画面。
