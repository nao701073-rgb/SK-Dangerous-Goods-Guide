# part478 固縛力参考算出 CSS Code Annex 13 補強

## 参照資料

- IMO MSC.1/Circ.1623（2020年改正 CSS Code Annex 13）
- Annex 13 日本語参考資料（参照のみ。PDF原本は画面表示・成果物への同梱をしない）
- CTU Code 第5章・第6章・付属書7（既存のCTU参考算出）

## 追加した評価

1. CSS Code Annex 13の適用範囲確認。
2. 経験に基づく方法（左右各側のMSL合計と貨物重量を比較）。
3. 先進の計算方法（CS=MSL/1.5、表6のf=μsinα+cosα）。
4. 代替の方法（CS=MSL/1.35、鉛直角・水平角を考慮）。
5. 表2の基礎加速度を積載高さ区分・船長方向位置から自動取得。
6. 表3の船長・速力補正および表4のB/GM補正。
7. 表5の接触材料別摩擦係数（木材－木材、鋼－木材／鋼－ゴム、鋼－鋼乾燥、鋼－鋼湿潤）。
8. 制限区域で文書化された運航手順がある場合の有義波高低減係数fR。
9. 暴露甲板上の風圧力・波洗い力（1kN/m²）と、貨物全高に基づく自動投影面積、転倒モーメントの作用高さ。
10. CSS Code表1に基づく名目破断力からMSLへの換算。
11. 器具・貨物側・船側固縛点の最小MSLを採用。
12. 異なる弾性の固縛が混在する場合の保守的除外。
13. 頂部を越える固縛をCSS Code Annex 13の抵抗力に算入しない。

## 適用限界

本機能は参考算出であり、承認されたCargo Securing Manual、主管庁の指示、船体・甲板・溶接部の局部強度評価、検証済みの詳細工学計算に代わるものではない。新規・特殊用途や非常に重い／大型の貨物では、計算方法の検証記録が必要である。

## 検証

- インラインJavaScript構文検証。
- デスクトップ表示および幅390pxのスマートフォン表示を確認。
- CSS経験に基づく方法の縦方向対象外処理、鉛直角60°超の除外、有義波高低減の確認条件、表5摩擦係数上限を機能試験。
