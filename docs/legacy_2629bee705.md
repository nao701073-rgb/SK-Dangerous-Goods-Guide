# Part 332 更新内容

## 権限エラー画面の操作性・アクセシビリティ改善

- 指定済みの表示順を維持しました。
  1. 利用可能な権限の案内
  2. 「設定画面へ戻る」
- 権限エラー画面を開いた際、画面タイトルを「権限がありません」に切り替えるようにしました。
- スクリーンリーダーへ権限エラーを即時通知する `aria-live="assertive"` を追加しました。
- エラー画面表示後、見出しへフォーカスを移し、キーボード利用者が状況を把握しやすいようにしました。
- 「設定画面へ戻る」は従来どおり単独の操作導線として表示します。
- 「現在の権限：未認証」等の表示は追加していません。
