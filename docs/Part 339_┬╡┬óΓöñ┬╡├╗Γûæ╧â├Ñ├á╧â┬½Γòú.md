# Part 339 更新内容

- 「固縛力参考算定」と「AI画像解析」の将来実装カードを、見た目と支援技術の両面で明確化しました。
- 各カードの見出し、説明文、将来実装状態を `aria-labelledby` と `aria-describedby` で関連付けました。
- 将来実装バッジを控えめなピル型表示へ統一し、状態を示す小さな点を追加しました。
- 将来実装カードではホバー時の浮き上がりを無効化し、操作可能なカードとの違いを明確にしました。
- 動きを抑える端末設定ではカードのトランジションを停止します。
- 強制カラーモードでも将来実装状態を判別できる表示を維持します。
- 採用済みのコンテナ内貨物固縛アイコンと「ホームに戻る」導線は維持しています。
