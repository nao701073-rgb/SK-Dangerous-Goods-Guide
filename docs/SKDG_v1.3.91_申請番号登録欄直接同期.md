# SKDG v1.3.91 申請番号登録欄直接同期

## 実画面で確認された症状
Excel取込結果の「申請書から取得した情報」には申請番号1434が表示される一方、画面下部「申請番号管理へ登録」の申請番号欄が空欄のままになる。

## 原因
申請番号解析では取得できていたが、登録欄への反映を後段のイベント連携だけに依存していたため、実行順や読み込み状況によって登録欄側が更新されないことがあった。

## 修正
- Excel取込処理から登録欄へ直接同期するフォールバックを追加。
- 申請番号照合スクリプトを取込処理より前にロードし、イベント受信を保証。
- m/d/yy 形式の日付も西暦4桁へ正規化。
- 既存案件照合と登録直前の番号一致確認は維持。
