# Part 114 写真完全削除計画の期限・通知管理

## 目的
完全削除計画が承認待ちまたは実行待ちのまま放置されることを防ぐため、標準期限、担当者、期限超過表示を追加します。

## 標準期限
- 計画作成から承認まで: 初期値7日
- 承認から完全削除実行まで: 初期値3日
- 設定画面から各1～90日の範囲で変更可能

## 計画作成時
- 承認担当者を任意指定可能
- 作成日時から承認期限を自動計算
- 作成者と承認者の分離は従来どおり維持

## 承認時
- 承認日時から実行期限を自動計算
- 承認権限は事業所管理者または管理者のみ

## 画面表示
- 承認待ち件数
- 実行待ち件数
- 承認期限超過件数
- 実行期限超過件数
- 計画ごとの承認担当者と次回期限

期限超過は警告表示しますが、自動削除は行いません。内容を再確認したうえで、管理者が承認または実行します。

## データ項目
- assignedApprover
- approvalDueAt
- executionDueAt
- deadlineState（画面判定用）
