# SKDG v1.3 安定化・写真入力・容量整理

## 1. 申請書取込・確認
- 取込後の自動スクロールを廃止。
- MutationObserverによる連続した折りたたみ・再配置を廃止。
- 危険物明細はカード内部に収まり、スマートフォンでは従来のカード表示を維持。

## 2. 固縛力参考算出
- ページ上部の入力順を「申請書・航路 → 写真 → 輸送条件と貨物 → 接触面 → 固縛材/支保材 → 参考算出」とする。
- 固縛材と支保・あて材を別カードに分離。両方使用時のみ既存の併用計算へ渡す。
- 写真AIは固縛材、支保・あて材、MSL、角度等を候補表示し、検査員が採用した候補だけ反映する。
- 強度の根拠は簡単操作の必須項目から除外。既存保存値は削除しない。
- 取付点別MSL・角度・強度根拠の厳密パネルは標準の簡単操作では表示せず、上部の写真入力でMSL・角度候補を確認する。
- MSL・角度の写真候補は検査員が採用して初めて入力欄へ反映する。
- report HTML内のscript終端不具合を修正し、材質プルダウン初期化が最後まで実行されるようにする。

## 3. ホーム・法令・関連資料
- 重複する「よく使う機能」ブロックを削除。
- ホームと危険物検索の危険物検索例をUN1203/GASOLINE系に統一。
- 関連法令の「拡張基盤」導入カード、関連資料の「資料レジストリ」導入カードは表示しない。機能本体・原文・資料は維持。

## 4. 容量整理
- 全体容量の大半を占める法令、IMDG、標札画像/PDFは維持。
- 全体監査対象は1,869ファイル、318,171,573 bytes（約303.43 MiB）。
- exact duplicateは18グループ、理論上最大約10.04 MiB。SHA-256で完全一致し、かつ実ファイル参照がないものだけ削除できるPowerShellを同梱。
- 監査結果は `docs/SKDG_v1.3_容量監査.json` に保存。
- 自動的な画質低下圧縮や法令資産の削除は行わない。
