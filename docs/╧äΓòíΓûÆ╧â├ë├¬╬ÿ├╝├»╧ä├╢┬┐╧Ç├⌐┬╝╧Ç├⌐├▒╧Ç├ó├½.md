# 検査・検品業務サポートシステム 統合運用ガイド

## 利用者区分

| 区分 | 主な操作範囲 |
|---|---|
| 利用者 | 危険物検索、所属事業所の申請番号・写真の登録と閲覧 |
| 事業所管理者 | 所属事業所の利用者・申請・写真・運用記録の管理、承認 |
| 管理者 | 全事業所の管理、法令更新、監査、設定、横断承認 |

## 主要画面

- 危険物検索・解説
- 申請番号・写真管理
- 関連法令・国際規則
- 関連資料
- 設定・利用者管理
- 法令更新管理
- システム保守・バックアップ
- 本番導入判定
- 運用監視・障害対応

## 法令改正時

1. 原本PDFを登録
2. 構造化データを作成
3. 現行版との差分を確認
4. 原文照合と影響評価を実施
5. 別担当者が承認
6. 即時または予約公開
7. 公開後に整合性監査

## 写真登録

写真は登録時に自動圧縮され、不要なEXIF情報を除去します。位置情報は明示的に保存を選んだ場合だけ、画像とは別の管理項目として保持します。

## バックアップ

本番変更、データ復元、法令更新の前後にバックアップを取得し、復元前検査と復元後の整合性診断を実施してください。
