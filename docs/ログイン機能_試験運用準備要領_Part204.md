# ログイン機能 試験運用準備要領（Part 204）

## 対象規模
- 試験運用：約50名
- 将来運用：約150名
- 安全環境室長1名、安全環境室職員5名を含む

## 初期登録の流れ
1. 利用者CSVを作成する。
2. dry-runで重複、権限、所属、メール形式を確認する。
3. 一括登録を実行する。
4. アカウント安全管理で初回パスワード変更とMFA基準を適用する。
5. 初期認証情報は本人へ個別に配布し、配布後のCSVを安全に削除する。

## 標準セキュリティ基準
- 全利用者：初回ログイン時のパスワード変更を必須とする。
- システム管理者、安全環境室長、安全環境室職員、事業所管理者：メール登録済みの場合はMFA必須。
- ログイン失敗5回で30分間ロックする。
- パスワードは12文字以上、大文字・小文字・数字・記号を含める。
- 90日以上未使用のアカウントは点検対象とする。
- 異動・退職・利用終了時は速やかに無効化し、セッションを終了する。

## 試験運用開始前確認
- 管理者アカウントのMFA確認
- 安全環境室6名の全事業所閲覧・編集不可確認
- 事業所利用者の所属事業所限定確認
- 初回パスワード変更確認
- ロック・解除・パスワード再設定確認
- 監査ログ記録確認
- バックアップ取得・復元手順確認
