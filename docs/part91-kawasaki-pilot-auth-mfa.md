# Part 91 川崎事業所試験運用・ログインID・二段階認証

## 試験運用拠点

第一ブロック全体への展開前に、川崎事業所を先行試験運用拠点とする。

試験は、準備、限定運用、並行運用、評価の4段階で行う。安全環境室は検証結果、監査ログ、写真容量、バックアップ復元結果を横断確認する。

## ログイン方式

1. 利用者がログインIDと任意設定したパスワードを入力する。
2. サーバーは登録済みメールアドレスへ6桁のワンタイム認証コードを送信する。
3. 利用者が有効期限内にコードを入力する。
4. 認証成功後にJWTセッションを発行する。

メールアドレスはログインIDとして使用せず、二段階認証、利用開始案内、パスワード再設定に使用する。

## 利用開始

安全環境室管理者がログインID、社内メールアドレス、表示名、権限を登録する。利用者には利用開始リンクがメール送信され、本人が任意のパスワードを設定する。

## 権限

- 検査員: 所属事業所の申請番号・写真を登録、閲覧、更新する。
- 事業所管理者: 所属事業所の運用管理を行う。
- 安全環境室管理者: 全事業所横断閲覧、利用者、写真上限、監査、検証を管理する。
- ゲスト: 検査員以外の社内職員向け。危険物検索、関連法令、関連資料のみ閲覧できる。
- 検証者: 検査員以外の社内職員向け。閲覧と検証記録を行えるが、申請番号・写真の操作はできない。

## SMTP未設定時

検証環境でSMTPを設定していない場合、認証コードとメール本文はサーバーコンソールへ開発用表示される。本番では必ず社内SMTPを設定する。
