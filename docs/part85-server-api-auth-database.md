# Part 85 社内オンライン基盤

## 実装範囲
- Node.js / Expressによる社内API
- PostgreSQL中央データベース
- JWTログイン認証
- 事業所利用者、事業所管理者、安全環境室管理者の権限制御
- 安全環境室による全ブロック・全事業所の横断閲覧
- 申請番号API
- 写真アップロードAPI
- 写真枚数、ファイル容量、事業所総容量のサーバー側強制
- 操作監査ログ
- NginxによるHTTPS終端
- Docker Composeによる社内サーバー展開構成
- オフライン変更をオンラインへ送信する同期処理
- 接続確認、オンラインログイン、手動同期画面

## データ分離
通常の事業所利用者は、APIへ任意の事業所IDを送信しても所属事業所へ強制的に限定されます。安全環境室管理者だけが全事業所を指定して閲覧できます。

## 写真制限
写真制限はブラウザ側だけでなくAPI側でも確認します。複数端末が同時に登録した場合でも、中央データベース上の件数と容量から判定します。

## 本番導入前に必要な作業
- 社内DNS名とTLS証明書の発行
- DB、JWT、初期管理者パスワードの変更
- 社内ADまたはEntra IDとのSSO連携の検討
- バックアップ先と復旧手順の確定
- ウイルス・マルウェア検査の追加
- 脆弱性診断と負荷試験
- 操作ログの保管期間と閲覧権限の決定

現時点の実装は、社内検証環境へ配置して接続試験を開始できる構成です。社内ネットワーク、プロキシ、証明書、認証基盤の条件に応じた調整は必要です。
