# Part 136 監査ルール適用証明の是正処置管理

## 目的
監査ルール適用証明の月次照合で検出された不一致を、確認だけで終わらせず、原因調査、是正、別担当者による完了確認まで追跡します。

## 対象となる要確認事項
- 適用証明の検証不合格
- 対応する変更申請が見つからない
- 証明書IDの重複
- 変更申請IDに複数の適用証明が存在する

## 処理の流れ
1. 月次照合を実行
2. 要確認事項から是正処置を登録
3. 原因、是正内容、担当者、対応期限を記録
4. 担当者が対応結果を登録
5. 対応完了者とは別の担当者が完了確認
6. 完了として閉鎖

## 権限
登録、対応完了、完了確認は、事業所管理者または管理者のみ実行できます。対応完了者本人による自己確認は禁止します。

## 出力
是正処置台帳をCSVで出力できます。月次照合報告JSONには要確認事項の一覧が含まれます。
