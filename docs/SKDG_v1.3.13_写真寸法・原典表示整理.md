# SKDG v1.3.13 写真寸法・原典表示整理

## CTU表示
- 「汎用コンテナ（既定：20FTドライ）」は画面上では **「汎用コンテナ」** のみ表示します。
- 「汎用コンテナ＝20FTドライを初期値…」等の説明文は表示しません。内部初期値は20FTドライを維持します。
- コンテナサイズ・種類は汎用コンテナを選択した場合だけ表示し、20FT/40FTドライ、20FT/40FTリーファーを入力者が選択できます。

## 写真AI寸法補助
- 選択コンテナの **内幅** を写真縮尺の優先基準にします。内幅は写真内に収まることが多いため、20FT/40FTドライでは2.352m、20FTリーファーでは2.280m、40FTリーファーでは2.290mを参考候補として使用します。
- 写真読込後、「基準となる実寸(m)」へ選択コンテナの内幅候補を自動表示します。
- 写真外形比から貨物幅を推定し、「写真測定長さ(m)」にもAI候補を表示します。AIで内幅基準を使用した場合は、反映先を貨物幅とします。
- 貨物長さ・幅・高さのAI候補は引き続き直接訂正できます。単眼写真のため確定値ではなく、実測・図面・申請値を優先します。
- 「AI寸法補助：20FTドライコンテナに収納可能…」等の収納可否メッセージは画面に表示しません。

## 算出根拠・原典ジャンプ
- 「原典をまとめて確認」は削除しました。
- 原典ボタンは、法令・コードの直接根拠がある項目だけに表示します。
- 原典ジャンプを表示しない項目：CTU構造区分、コンテナサイズ・種類、メーカー例示内寸、貨物寸法、貨物質量、貨物名、固縛方法、本数、MSL合計表示、採用MSL。
- 海上輸送の輸送条件は **CSS Code Annex 13 Table 2-4** を参照します。海域A/B/Cはシステム入力区分であり、CSS Code表の区分と同一とは扱いません。
- 固縛材、1本当たりMSL、貨物側取付部MSL、CTU側固縛点MSLは **CSS Code Annex 13 Table 1** の確認導線を使用します。
- CSS Codeのページ対応はPart478でユーザー提供原典と照合した **MSC.1/Circ.1623 Annex 13** の対応を維持します。

## 互換性
- 表示版は **Version 1.0 試作版** のままです。
- DBマイグレーションはありません。
- v1.3.9以降の常時監視廃止を維持し、MutationObserverは追加していません。
