# Part 233 運用受入・定期点検要領

## 目的
正式運用前、大規模更新後、四半期・年次点検時の確認結果を共通形式で記録する。

## 画面
`システム設定 → 運用受入・定期点検`

## 確認分野
1. 利用者・権限
2. ログイン・認証
3. 申請番号・写真
4. 危険物・法令データ
5. 法令・データ更新
6. バックアップ・復元
7. 障害・セキュリティ
8. 性能・運用資料

## 判定
- 保留
- 条件付き受入
- 正式運用可

正式運用可は、全分野が合格の場合だけ選択する。

## 記録
試作版では端末内へ保存し、JSONを出力できる。本番クラウド環境では `operations_acceptance_reviews` に保存する設計とする。

## 基本方針
本システムの利用は任意です。利用頻度ではなく、システムの安全性、品質、復旧可能性および権限の適切性を点検する。
