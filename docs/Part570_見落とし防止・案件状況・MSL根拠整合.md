# Part 570 見落とし防止・案件状況・MSL根拠整合

## 1. 申請書取込・確認
- Part 568の「要確認だけ表示／前・次ナビ」とPart 569の「理由コンパクト表示」を維持する。
- 要確認の危険物を No.／UN番号／修正必須・要確認の区分で一覧表示する「確認インデックス」を追加する。
- 確認インデックスから対象行へ直接移動できるが、判定状態・確認状態は自動変更しない。
- 「登録前の最終確認」は、未確認危険物、原本照合者、全体確認事項の順に確認し、問題箇所へ移動するだけの補助とする。
- 既存の登録可否判定、`reviewEvidence`、確認理由保存ロジックは変更しない。

## 2. 申請番号管理
- 選択中案件の状況を1画面で把握できる「案件状況」サマリーを追加する。
- 表示対象は、申請書確認状態、MSL取付点確認進捗、簡易メモ有無、危険物件数、船名、コンテナ番号、検査予定・実施日、最終更新日時。
- 既存の案件検索、次操作ガイド、メモ保存、写真登録、案件コンテキスト引継ぎはそのまま使用する。
- 新規の保存項目や進捗状態は作らない。

## 3. 固縛力参考算出
- 直接固縛を使用する場合に、貨物側MSL／CTU側MSLについて「入力根拠確認」を表示する。
- 入力MSLと、写真・刻印・資料確認欄または確認済み取付点台帳のMSLを比較する。
- 確認済み取付点台帳が存在する場合は、同一区分の確認済み取付点の最小MSLを優先して比較する。
- 差異または根拠未確認がある場合、「差異・未確認へ移動」で対象入力欄へ移動できる。
- この機能は表示・移動のみで、MSL値、採用MSL、制限要因、必要固縛力、併用計算を自動変更しない。

## 4. 互換性
- DBマイグレーションなし。
- 新規永続フィールドなし。
- Part 569以前の案件データをそのまま使用する。
- Part 569以前の追加JS/CSSは変更せず維持する。
