# SKDG v1.3.54 CTU AI・申請書・写真補助 システム連携検証

## 修正した連携

- Excel申請書は、入力欄へ値を反映した後の `sk:ctu-excel-imported` を進捗の確定ソースとして扱う。
- 写真をアップロード／撮影しただけでは入力完了にしない。
- 写真AIの自動候補は `suggested` として保持し、追尾表示では「確認必要」とする。
- AI候補を利用者が採用した `sk:ctu-ai-applied` 後は、対象値を `accepted` として進捗へ反映する。
- 写真測定の「かんたん入力へ反映」、MSL候補反映、MSL写真確認、取付点台帳・固縛ライン反映は `sk:ctu-system-applied` / `sk:ctu-photo-applied` で進捗へ通知する。
- HTML初期値と同じ数値を利用者が確認・採用した場合でも、操作イベントを根拠に入力済みとして扱う。
- 参考算出を実行するまでは申請番号管理への登録ボタンを有効化しない。
- 算出後に入力・AI反映・写真補助反映・申請書反映が変わった場合は「再算出必要」に戻し、登録を無効化する。

## ブラウザ連携試験

次の状態遷移を Chromium で確認した。

1. 初期状態 → 案件・貨物「未入力」／固縛条件「未入力」／算出・登録「未算出」、登録不可。
2. Excel取込イベント → 貨物情報だけ入力済み。
3. 写真AI自動候補 → 候補値は進捗に現れるが「確認必要」のまま。
4. AI候補の明示採用 → 対象項目を入力済みとして扱う。
5. 写真・MSL補助で確認した値 → 対象項目を入力済みとして扱う。
6. 必要項目確認後 → 「入力項目はそろっています」、登録はまだ不可。
7. 参考算出実行 → 「算出済み」、登録可能。
8. 算出後に条件変更 → 「再算出必要」、登録不可へ戻る。
9. スクロール時 → 追尾ステータスは共通ヘッダー直下（約58px）に保持。

## 安全側の扱い

写真だけでは貨物質量、MSL/STF、貨物側取付部MSL、CTU側固縛点MSL、支保力根拠等を確定しない。写真AIは入力候補・確認補助であり、刻印、仕様書、証明書、現場確認値等を優先する。

## 検証範囲

本検証は、アップロード後のコード経路、候補生成後の入力欄反映、進捗イベント、算出・再算出・登録可否の連携を対象とする。実写真ごとの画像認識精度そのものは、撮影条件・画角・対象物に依存するため、現場写真での最終確認が必要。
