# Part 125 証拠資料の版管理・差し替え履歴・原本性確認

## 概要
是正処置および再発防止策に登録する証拠資料について、差し替え時に旧版を残し、現行版・旧版・差し替え理由・原本性確認を追跡できるようにしました。

## 版管理
- 新規登録は v1 として登録
- 差し替え時は v2、v3 のように版番号を自動採番
- 差し替え元は旧版として保持
- 現行版と旧版を画面上で区別
- 旧版も開いて確認可能
- 差し替え者、差し替え日時、差し替え理由を履歴へ保存

## 原本性確認
現行版資料について、登録者とは別の担当者が以下を確認します。
- 原本または正式な発行元資料との一致
- ファイル名、内容、版、発行元
- SHA-256指紋

確認者、確認日時、確認内容を記録します。

## 完了条件
以下の処理では、単に資料が確認済みであるだけでなく、現行版かつ原本性確認済みであることを必須とします。
- 是正処置の完了確認
- 再発防止策の効果確認

## 権限
資料の登録、差し替え、確認、原本性確認は事業所管理者または管理者のみ実行できます。資料登録者本人は資料確認者および原本性確認者になれません。

## データベース
`server/sql/032_corrective_evidence_version_control.sql` に、版番号、現行版フラグ、差し替え関係、原本性確認項目を追加しています。
