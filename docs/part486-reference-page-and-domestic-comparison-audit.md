# part486 関連条文・AI要約の参照先再点検

## 対象
- 危険物コンテナ収納検査関連条文 19件
- 理解しづらい規定のAI要約 33件

## 実施内容
- IMDG Code 42-24のPDF実ページを条番号から再検索
- CTU Code仮訳の章・付属書開始ページを再検索
- 誤っていた代表例を訂正（4.1.1: 238→158、3.4: 762→785、危険物リスト18列: 556→577、CTU第11章: 36→37、CTU第12章: 38→39）
- 複数ページに続く規定は連続ページ又は関連開始ページを一つの抜粋PDFへ統合
- 各カードに国内法令とIMDG Code／CTU Codeの対比欄を追加
- 直接対応する国内条文を確定できない項目は「直接対応なし」と明示し、推測による条文付与を行わない

## 注意
対比欄は確認経路を示すものです。最終判断では国内法令原文、IMDG Code／CTU Code本文、表、図、脚注及び例外規定を確認してください。
