SKDG v1.3.59 Hotfix Update

適用元:
  SKDG v1.3.58

更新方法:
1. SKDGを開いているブラウザタブを閉じます。
2. 本ZIPを展開し、既存のSKDGフォルダへ上書きコピーします。
3. pages/ctu-securing-calculator.html を再度開きます。
4. 表示が古い場合のみ Ctrl+F5 で再読込してください。

主な修正:
- ①と②を含む①〜⑥カードを完全に独立した外枠へ統一。
- 旧カード／親デッキ由来の残存外枠・疑似枠を無効化。
- カード間余白とヘッダーの数字・文字バランスを再調整。
- 上部の入力状況を3区分から①〜⑥の6区分へ拡張。
- 完了時もステップ番号を残し、チェックマークは小さな補助表示へ変更。
- 入力不足／確認項目の説明へ該当ステップ番号を表示。

算出式変更: なし
DB移行: なし
