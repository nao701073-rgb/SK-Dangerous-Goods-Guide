SKDG v1.3.26 Performance Hotfix 更新手順

対象:
  SKDG v1.3.25 Performance Hotfix 適用済み環境

更新方法:
1. 現在のSKDGフォルダをバックアップしてください。
2. SKDGを開いているブラウザタブを閉じてください。
3. 本ZIPを展開し、フォルダ構成を維持したまま既存SKDGフォルダへ上書きしてください。
4. index.html から再度起動してください。
5. 表示が古い場合のみ Ctrl+F5 を1回実行してください。

主な確認ポイント:
- 申請番号管理で検索文字を連続入力しても操作が重くなりにくいこと。
- 案件の追加・削除・結果登録後に登録内容バッジが更新されること。
- 固縛力参考算出画面の初期表示が従来より軽いこと。
- Excel申請書取込、写真入力、固縛力算出、案件登録が従来どおり動作すること。
- 印刷時に画面下部の内容が欠落しないこと。

DBマイグレーション: なし
画面表示バージョン: Version 1.0 試作版
内部技術ビルド: v1.3.26
