SKDG v1.3.11 Hotfix Update
============================
対象ベース: v1.3.10
表示バージョン: Version 1.0 試作版（変更なし）
DB移行: なし

適用方法
1. 現在の SKDG v1.3.10 フォルダをバックアップしてください。
2. SKDG_v1.3.11_Hotfix_Update.zip を展開してください。
3. 展開した内容を SKDG のルートフォルダへ、フォルダ構成を維持したまま上書きしてください。
4. SKDGを開いているChromeタブをすべて閉じ、再度 index.html を開いてください。
5. 必要に応じて Ctrl+F5 で再読み込みしてください。

今回の確認ポイント
A. 固縛力参考算出 → 写真をアップロード
   - HEIC/HEIFでも変換完了後に「写真AI候補」が自動表示されること。
   - 「写真をAI解析」を押して再解析できること。
   - 写真で確認・推定した鉛直角、固縛本数に候補値が入ること。
   - 候補値は手入力で訂正できること。

B. ③ 不足項目を確認して参考算出
   - 「コンテナサイズ・種類」に以下4種類があること。
     20FT ドライコンテナ
     40FT ドライコンテナ
     20FT リーファーコンテナ
     40FT リーファーコンテナ
   - 貨物長さ・幅・高さを入力して「AI収納確認」が動作すること。
   - 内寸、扉開口、90°向き変更を考慮した候補結果が表示されること。

C. 写真測定
   - 「選択コンテナの内幅を写真基準へ」等で、選択したコンテナの参考内寸を基準寸法へ設定できること。
   - 実際のコンテナ寸法は製造者・型式で差があるため、実機表示・仕様書を優先してください。

D. 算出根拠
   - 「算出根拠を開く」の別ウィンドウにコンテナサイズ・参考内寸・貨物寸法が追加されること。
   - コンテナ参考寸法についても「原典ページへジャンプ」が表示されること。

主な技術修正
- HEIC/HEIF変換の220ms後にAIを走らせる旧タイミング依存を廃止。
- canvasの読込完了を有限回ポーリングしてから端末内画像解析を実施。
- 長い暗色帯の方向・連続性を評価して固縛本数と画像上の傾きを候補化。
- MutationObserverによる常時監視は使用しません。
