SKDG v1.3.36 Application Header First-Paint Stability Hotfix

1. v1.3.35までを適用済みの環境へ本パッケージを上書きしてください。
2. 申請番号管理のヘッダーは初回描画から上部(top:0)へ固定されます。
3. 旧CSSによるbottom/fixed位置の一時適用をインラインcritical CSSで遮断しています。
4. 申請番号管理を開く際のブラウザscrollRestorationを無効化し、ハッシュ指定がない場合は先頭位置から表示します。
5. サブメニューは従来どおり必要時のみ生成・表示します。
6. 適用後はSKDGのタブをすべて閉じ、再度開いてください。古いCSSが残る場合はCtrl+F5を1回実行してください。
