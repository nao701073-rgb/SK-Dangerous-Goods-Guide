SKDG v1.3.31 Hotfix 更新手順
==============================

対象
----
v1.3.30 Permission Hotfixを適用済みのSKDGフォルダーへ上書きするHotfixです。
DBマイグレーションはありません。画面上の表示版は「Version 1.0 試作版」のままです。

更新内容
--------
1. 危険物検索・危険物詳細の右上「利用者」をログイン中の表示名へ変更。
2. 表示名の丸アイコンは氏名の先頭文字を表示。
3. 右上の利用者表示を選択すると「ユーザー設定」へ移動。
4. app-headerを使用する申請番号管理、申請書取込・確認等にも同じ利用者ボタンを追加。
5. v1.3.30のオーバーパック表示作成／システム設定の権限制御は維持。

適用後
------
ブラウザーのSKDGタブをすべて閉じて開き直してください。古い表示が残る場合はCtrl+F5を1回実行してください。
