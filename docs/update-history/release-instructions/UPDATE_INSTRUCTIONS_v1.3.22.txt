SKDG v1.3.22 Hotfix Update

対象:
  SKDG v1.3.21 適用済み環境

適用方法:
1. SKDGを開いているブラウザタブを閉じてください。
2. SKDG_v1.3.22_Hotfix_Update.zip を展開してください。
3. 展開した内容を、現在のSKDGフォルダ直下へ上書きしてください。
4. index.html から起動してください。
5. 必要に応じて Ctrl+F5 で再読み込みしてください。

今回の主な変更:
- 申請番号管理カードの空欄になっていた詳細ボタンを「詳細を開く」と必ず表示。
- 申請書確認の申請番号登録画面を、固縛力参考算出と同じ簡潔な様式へ統一。
- 「登録先」→「未登録の案件として申請番号を入力」→年度・番号・案件名→登録ボタンの順に整理。
- 旧非表示ボタンが白い空欄四角として表示される不具合を修正。
- 同じ年度・申請番号は従来どおり同じ案件カードへ追加登録。

DBマイグレーション: なし
表示バージョン: Version 1.0 試作版
