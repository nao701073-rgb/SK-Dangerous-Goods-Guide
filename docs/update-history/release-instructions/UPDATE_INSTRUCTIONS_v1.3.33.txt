SKDG v1.3.33 Feature Header Polish Hotfix 適用手順

1. 本ZIPを展開します。
2. 展開された stage フォルダ配下の内容で既存環境の同名ファイルを上書きしてください。
3. 主な修正
   - 申請番号管理を基準に主要機能のヘッダーを統一
   - 危険物検索・危険物詳細へ同一ホームアイコンを静的配置
   - 申請書取込・確認の戻る矢印を共通ホームアイコンへ変更
   - 固縛力参考算出に共通ヘッダーを静的追加し、画面内の重複「← ホーム」を削除
   - 改善要望・検索履歴のホームアイコンを同じSVG・サイズ・角丸へ統一
   - 関連法令・関連資料・オーバーパック表示作成・ユーザー設定等も共通ヘッダールール対象
   - 右上のログイン利用者名表示とユーザー設定へのリンクを維持
   - v1.3.30の権限制御を維持
4. 適用後は開いているSKDGタブを閉じ、再度開いてください。
5. 古い表示が残る場合は Ctrl+F5 を1回実行してください。
