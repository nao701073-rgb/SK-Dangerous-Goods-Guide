SKDG v1.3.34 Submenu / Performance / Header Hotfix 適用手順

1. ZIPを展開し、stage配下を既存環境へ上書きしてください。
2. 適用後、SKDGを開いているタブをすべて閉じて開き直してください。
3. 古い表示が残る場合は Ctrl+F5 を1回実行してください。

主な確認項目
- サブメニューがページ表示直後には閉じていること
- 左上のメニューボタンを押した場合だけサブメニューが開くこと
- ヘッダーが従来の申請番号管理と同様に、メニュー→ホーム→機能名→右端利用者名の順であること
- 右上利用者名を押すとユーザー設定へ移動すること
- 一般利用者ではオーバーパック表示用作成／システム設定が表示されないこと
- 安全環境室長・安全環境室職員・検証者・システム管理者では上記機能が利用できること
- 危険物検索、固縛力参考算出等の画面操作がv1.3.33より軽くなっていること
