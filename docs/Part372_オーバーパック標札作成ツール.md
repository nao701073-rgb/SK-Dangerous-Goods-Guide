# Part 372 オーバーパック標札・表示作成ツール

## 追加機能
- 複数国連番号の一括入力・照合
- 危険物データベースから主標札・副標札・英語正式品名を取得
- 標札マスターIDによる重複排除
- `or` による品名候補の分割
- 丸括弧・角括弧の括弧外／括弧内候補の選択
- 括弧外候補を初期選択として優先
- 選択品名の `and` 以降を印刷対象から除外
- 日本語品名は確認画面のみに表示し、印刷しない
- N.O.S.品名では英語技術名を必須入力
- OVERPACK、海洋汚染物質、少量危険物マークの追加
- A4横向きの実寸プレビュー、印刷、ブラウザのPDF保存
- 印刷履歴を端末内に直近20件保存
- 危険物詳細から「オーバーパック印刷に追加」

## 印刷上の注意
標札は試作設定として90mm角で出力します。正式運用前に、適用法令、社内基準、使用プリンターの余白および100%印刷時の実寸を確認してください。
