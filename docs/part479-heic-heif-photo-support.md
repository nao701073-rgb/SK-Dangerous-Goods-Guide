# part479 HEIC／HEIF写真対応

- 固縛力参考算出の「カメラで撮影」「写真をアップロード」で `.heic`／`.heif` を選択可能にしました。
- 申請番号管理の写真登録でもHEIC／HEIFを選択可能にしました。
- HEIC／HEIFはブラウザ内でJPEGへ変換し、画像データを外部の変換サービスへ送信しません。
- 拡張子、MIMEタイプおよびファイルヘッダーを確認してHEIC／HEIFを判定します。
- 変換後も、固縛角度・基準寸法・長さ測定の機能を使用できます。
- 変換ライブラリが読み込めない場合は、ブラウザの標準HEIC表示を試し、利用できない場合は明確なエラーを表示します。

変換処理には `heic-to 1.5.2` を使用します。写真そのものは端末内で処理されます。
