# Part 331 更新内容

## 権限エラー画面の表示順統一

- 「現在の権限」の表示を削除しました。
- 利用可能な権限を最初に表示し、その直後に「設定画面へ戻る」を配置しました。
- 申請番号管理画面では、許可権限を次の順番で表示します。
  1. 事業所管理者
  2. 事業所利用者
  3. 安全環境室長
  4. 安全環境室職員
  5. システム管理者
- 権限エラー領域に `role="alert"` を付与し、支援技術へエラー内容が伝わるようにしました。
- 権限エラー画面の文言・順番を確認する自動回帰検証を追加しました。

この画面は 事業所管理者、事業所利用者、安全環境室長、安全環境室職員、システム管理者 のみ利用できます。
