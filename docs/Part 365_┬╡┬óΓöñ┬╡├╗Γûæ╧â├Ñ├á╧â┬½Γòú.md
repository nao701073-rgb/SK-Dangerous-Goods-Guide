# Part 365 更新内容

## ログイン画面
- 説明文を「ログインIDとパスワードを入力してください。」へ統一しました。
- パスワード再設定案内を「パスワードを忘れた場合は、システム管理者に再設定を依頼してください。」へ変更しました。
- ローカル／クラウド接続に関する内部的な案内をログイン画面から削除しました。
- 朝・昼・夕方・夜の4K背景画像から中央の縦帯を除去し、各時間帯を個別に再調整しました。
- `?theme=morning`、`?theme=day`、`?theme=evening`、`?theme=night` で時間帯別表示を検証できます。

## ローカル認証
- 認証監査履歴が `null` の場合に発生していた `Cannot read properties of null (reading 'unshift')` を修正しました。
- ローカル認証データはPart 365用の保存領域で初期化します。
- 未認証時は保護画面への直接アクセスを拒否します。
