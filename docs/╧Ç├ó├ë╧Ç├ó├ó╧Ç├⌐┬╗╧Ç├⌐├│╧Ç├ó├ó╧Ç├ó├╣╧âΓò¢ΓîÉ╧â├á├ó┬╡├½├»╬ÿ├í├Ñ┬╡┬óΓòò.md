# バックアップ・復元手順書

## バックアップ
`server/scripts/backup.sh` を定期実行します。データベースと写真を同一バックアップ単位として管理してください。

## 復元
1. 対象システムへの書込みを停止します。
2. 復元前の現状バックアップを取得します。
3. `scripts/restore.sh <database.sql.gz> <photos.tar.gz>` を実行します。
4. `scripts/integrity-check.sh` を実行します。
5. 申請番号件数、写真件数、欠損ファイル、孤立データを確認します。
6. 主要画面と権限を確認後、利用を再開します。

## 復元試験
本番データを直接上書きせず、隔離した検証環境へ復元します。復元時間、件数、欠損、ログイン、写真表示を記録します。
