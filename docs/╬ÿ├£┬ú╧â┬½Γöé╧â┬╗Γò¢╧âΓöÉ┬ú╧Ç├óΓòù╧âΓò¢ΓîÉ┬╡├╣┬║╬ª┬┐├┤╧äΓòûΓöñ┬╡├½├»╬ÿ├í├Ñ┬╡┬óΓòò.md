# 障害対応・復旧訓練手順書

## 障害発生時
1. 障害記録を登録し、重要度・影響範囲・対応期限を設定する。
2. 暫定対応により業務継続の可否を判断する。
3. 調査担当者が原因と恒久対応を記録する。
4. 対応完了者とは別の事業所管理者または管理者が完了確認する。
5. 重大障害はバックアップ、同期キュー、API、認証、法令データの状態も確認する。

## 復旧訓練
1. 対象シナリオと復旧目標を定める。
2. 本番データを直接操作せず、検証環境または承認済み手順で実施する。
3. 所要時間、成功可否、課題を記録する。
4. 実施者とは別の担当者が結果を確認する。
5. 課題がある場合は障害・不具合記録または改善案件として登録する。

## 定期点検
- 月次：バックアップ、同期キュー、保存容量、期限超過案件
- 四半期：復元訓練、権限棚卸し、法令データ監査
- 半期：端末交換・オフライン継続運用訓練
- 年次：本番設定、手順書、連絡体制、全体復旧計画
