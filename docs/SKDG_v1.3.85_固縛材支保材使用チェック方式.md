# SKDG v1.3.85 固縛材／支保・あて材 使用チェック方式

## UI
Step 5 は「固縛材」と「支保・あて材」の2カードを常時、縦並びで表示します。
各カードの右上に「計算に使用する」チェックを設け、初期状態は両方ONです。

チェックOFFのカードも入力内容は消さずに表示を残します。再度ONにすると入力内容をそのまま利用できます。

## 計算への反映
- 固縛材ON：固縛材の本数、MSL/STF、貨物側MSL、CTU側MSL、角度等を評価対象とする。
- 支保・あて材ON：支保材の対象方向、個数、支保力または支保経路能力を評価対象とする。
- 両方ON：併用状態として扱う。ただしv1.3.80の重複防止ルールを維持し、同一滑動経路へ単純加算しない。
- 両方OFF：算出しない。

## 保存・復元
新規結果には `useTensile` / `useSupport` を保存します。
旧結果は従来の `category` 値からチェック状態を推定して復元します。

## 変更しない範囲
CTU Code / CSS Codeの方向別作用力、摩擦、支保経路、最弱MSL、三段階参考判定の基本ロジックは変更しません。
