## 実ブラウザ

- Chrome 144.0.7559.96を使用
- PC幅1365pxでサブメニューを開き、ホームと同じ12項目および「危険物検索」の選択状態を確認
- 国連番号0004で「判定基準の国内法令」を開き、全画面表示、収録内容、結合PDFリンクを確認
- スマートフォン幅390pxではPDF iframeを非表示とし、同内容の縦長画像が表示されることを確認
- スマートフォン幅で横方向のオーバーフローがないことを確認
- 国連番号2814で、備考2以外の該当原文がタブ切替なしで連続表示されることを確認
