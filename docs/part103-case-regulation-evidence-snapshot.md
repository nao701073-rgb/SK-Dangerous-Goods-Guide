# 第103回：案件判定根拠スナップショット

## 目的
法令改正後も、過去案件で使用した法令版、PDF原本、構造化データ及び判定根拠を再現できるようにする。

## 保存項目
- 案件番号、判定基準日、対象UN番号・品名
- 採用した法令ID、改正版ID、版表示、適用期間
- 原本PDFのファイル名、保存先、SHA-256
- 公開データセットの対象キー、スキーマ版、件数、ハッシュ
- 判定内容、参照条文・別表・ページ
- 記録者、確認者、作成日時、スナップショットSHA-256

## 統制
- 承認済み・公開済み・旧版のうち、基準日に一意に適用される版だけを採用する。
- 適用期間が重複している場合は作成を拒否する。
- 承認後の記録は上書きせず、訂正時は新しいスナップショットを作成して旧記録を取消扱いにする。
- PDFやデータが更新されても、保存済みスナップショットの内容は変更しない。

## サーバー側確認例
```bash
npm run snapshot:regulation -- registry.json international-imdg 2026-07-26 KAW-2026-0001
```
