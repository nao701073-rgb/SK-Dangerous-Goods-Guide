- 背景画像は `assets/images/login-business-background.svg` の差し替えで後から変更できます。
- SKロゴは既存の `sk-brand-logo-square-v348.png` / `sk-brand-logo-square-2x-v357.png` を維持し、変更していません。
- ログイン画面から管理者向けの「クラウド接続設定」リンクを削除しました。
- 案内文を「ログインIDとパスワードを入力してください。」に統一しました。
- パスワード案内を「パスワードを忘れた場合は、システム管理者に再設定を依頼してください。」に統一しました。
