# Part 109 写真メタデータの安全管理

## 目的
スマートフォンやデジタルカメラの写真には、撮影場所、端末情報、撮影条件などのEXIF情報が含まれることがあります。本機能では、業務上不要な情報を保存画像から除去し、位置情報は明示的な選択がある場合だけ保存します。

## 保存画像の処理
- 選択した画像をブラウザのCanvasで再生成
- 保存画像には元ファイルのEXIF領域を引き継がない
- 自動圧縮、長辺1600px、長辺2048px、元サイズ相当の全モードで適用
- EXIF Orientationは表示補正のために読み取るが、保存画像自体は補正済みの向きで再生成

## GPSの取扱い
- 初期状態は「保存しない」
- 「写真の位置情報を業務記録として保存する」にチェックした場合のみ保存
- GPSは保存画像へ埋め戻さず、写真レコードの管理項目として保存
- チェックしない場合、元画像にGPSがあっても写真レコードには保存しない

## 証跡項目
- metadataSanitized
- gpsRetentionConsent
- gps
- capturedAtSource
- exifOrientation

## 運用上の注意
位置情報は現場、施設、設備の所在地を推測できる情報です。保存が必要な案件だけを対象とし、閲覧権限、保存期間、外部提供の可否を社内規程に沿って管理してください。
