# Part 321 更新内容

## 申請番号管理の方針

社内既存システムを正式な申請番号管理元とし、本システムは関連写真、簡易メモ、添付資料を補完する簡易機能として維持します。

## 権限別機能

- 事業所利用者：所属事業所の補完情報を登録・更新
- 事業所管理者：所属事業所の補完情報を登録・更新し、事業所内の登録状況を確認
- 安全環境室長：全事業所の補完情報を参照・登録・更新
- 安全環境室職員：全事業所の補完情報を閲覧専用で確認
- システム管理者：全事業所の補完情報および運用設定を管理
- ゲスト・検証者：申請番号管理は利用不可

## 画面改善

ログイン中の権限、対象範囲、利用できる操作を申請番号管理画面に表示します。閲覧専用権限では、メモ保存、写真・資料登録、新規登録の操作を表示しません。
