# Part 145 全体整合性診断・バックアップ・運用引継ぎ

## 目的
これまで追加した法令更新、写真管理、監査、是正処置、案件再開の各機能を、安全に継続運用するための共通保守機能です。

## 全体整合性診断
ブラウザ保存データについて、次を確認します。

- JSON構文
- 配列レコードのID重複
- 写真と申請番号などの参照関係
- ブラウザ保存容量
- 運用方式と社内API接続先

診断結果はJSONまたはCSVで保存できます。診断結果JSONにはSHA-256検証ハッシュを付与します。

## バックアップ
業務データと設定をJSONへまとめます。通常はログインセッション、認証コード、パスワード関連の一時情報を除外します。

バックアップには次を記録します。

- バックアップID
- 作成者・作成日時
- 対象事業所
- 保存項目別件数
- payloadハッシュ
- バックアップ全体の検証ハッシュ

## 復元
復元前に、形式・ハッシュ・対象事業所を検査します。検査合格後も事業所管理者または管理者だけが復元できます。

復元直前には、現在の端末データを緊急バックアップとして自動出力します。復元後は全体整合性診断を実施してから業務利用を再開してください。

## 本番運用上の注意
ブラウザ内バックアップは開発・試験運用向けです。本番運用では以下を別々に保全してください。

- PostgreSQLデータベース
- 写真・PDF・証拠資料のファイルストレージ
- 法令原本PDFと更新マニフェスト
- サーバー設定、秘密情報、証明書

バックアップは取得だけでなく、定期的な復元試験まで実施してください。

## 権限
復元は以下のみ実行できます。

- 事業所管理者：所属事業所のバックアップ
- 管理者：全事業所のバックアップ
