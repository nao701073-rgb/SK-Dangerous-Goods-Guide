## 5. 壁抵抗確認の配置と考え方

壁抵抗確認は **Step 5 と Step 6 の間**に「5B 壁面の隙間・壁抵抗利用を確認」として配置した。

前・後・左・右を個別に確認し、AI/写真判定だけでは壁抵抗を自動採用しない。検査員が「その方向で貨物・適切な緩衝材・支保材から壁へ有効に荷重伝達できる」と確認してチェックした方向だけ壁抵抗を計算へ入れる。

15 cm は CTU Code Annex 7 2.3.6 に基づき、**ある1か所の隙間ではなく、任意の水平方向の隙間合計**の候補判定基準として扱う。写真から尺度が取れない場合は「判定不能」とし、検査員確認を優先する。

## 6. 計算ロジック再監査

参照基準: IMO/ILO/UNECE CTU Code, MSC.1/Circ.1497。

- Chapter 5: 前後方向と側面方向を独立した荷重ケースとして評価。貨物質量を40%/60%に分割しない。
- Chapter 6.2.4: 汎用貨物コンテナは側壁 60%P、前壁・ドア端 40%P。ただし関連壁面へ均等に荷重が伝達される条件。
- Annex 7 2.2.2.2: 直接固縛時の摩擦は適用静止摩擦係数の75%。
- Annex 7 2.3.6: 水平方向の隙間合計は15 cmを超えない。
- Annex 7 4.1.6: 荷重－変形特性が異なる直接固定装置を、同じ滑動防止目的で無条件に並列加算しない。
- Annex 7 4.2.3: 強い境界のタイトストウェージでは壁抵抗と摩擦の釣合いを評価。
- Annex 7 4.2.5: 定義されたドア端抵抗は、衝撃荷重と開扉時落下を避ける積付けで強い境界として扱える。
- Annex 7 4.2.7: 弱い境界では、定義された壁抵抗に加え、条件に応じた追加固定力を評価できる。
- Annex 7 4.3.2.1 の考え方に沿い、直接固縛は固縛材・貨物側取付部・CTU側固縛点のうち確認済みの最弱MSLを上限とする。

### 同一方向の複合抵抗について

この「参考算出」は、CTU境界/硬い支保と伸びを伴う直接固縛の**変形適合性や独立荷重経路を簡易入力だけでは証明できない**。そのため同一滑動方向では無条件に足し合わせず、保守的に剛性経路側を優先する。詳細設計で独立した追加固定力を採用する場合は、別途根拠資料で評価する。

これは「壁＋直接固縛をCTU Codeが常に禁止している」という意味ではなく、簡易参考算出で安全側に誤判定しないための制限である。

### 算出後に左壁ON

左壁のチェックを実際にクリックし、自動再算出が発生することを確認した。

- 総合: **参考上十分**
- 重点確認方向: **後方**
- 後方必要抵抗力: 25.2 kN
- 後方摩擦: 6.3 kN（直接固縛のため計算μ=0.150）
- 後方直接固縛: 38.3 kN
- 後方壁抵抗: 0.0 kN（未算入）
- 後方評価抵抗力: 44.5 kN
- 余裕: 19.4 kN

独立計算:

- 前後作用力 = 8.559 × 9.81 × 0.30 = 25.189 kN → 25.2 kN
- 側面作用力 = 8.559 × 9.81 × 0.50 = 41.982 kN → 42.0 kN
- 後方摩擦 = 8.559 × 9.81 × 0.50 × (0.20 × 0.75) = 6.297 kN → 6.3 kN
- 後方直接固縛 = 4 × 10 × cos(17°) = 38.252 kN → 38.3 kN
- 後方合計 = 44.549 kN → 44.5 kN
- 余裕 = 44.549 − 25.189 = 19.360 kN → 19.4 kN
- 前/ドア端壁抵抗候補 = 28 × 9.81 × 0.4 = 109.872 kN
- 側壁抵抗候補 = 28 × 9.81 × 0.6 = 164.808 kN

このケースでは、前・左・右の有効な壁荷重伝達を検査員確認した後、**壁を採用していない後方向が重点確認方向になる**ことを実画面で再現した。

## 8. 算出結果の見やすさ

入力中は「何を確定すれば次へ進めるか」が追いやすいよう、カード見出し・入力順・不足表示を工程順にそろえた。Step 5では固縛材と支保・あて材のON/OFFを明示し、壁抵抗では確認済み方向を選択状態として強調する。Step 6では計算条件と結論を先に出し、詳細表はその後に確認できる構成とした。

Step 6 は次の順で読む構成にした。

1. 参考算出の短い結論
2. 抵抗力内訳
3. 「現在の算出条件」チップ
4. 3段階判定（現在の判定のみ強調）
5. 総合判定
6. **重点確認方向（余裕/不足量が最も小さい方向）**
7. 必要抵抗力 / 評価抵抗力 / 余裕・不足
8. 方向別詳細

左右同率なら「側面方向（左・右同率）」、前後同率なら「前後方向（前・後同率）」、全方向同率なら「前後・側面方向（全方向同率）」と表示する。5パターンの自動検証は 5/5 PASS。

## 10. 実画面検証方法と限界

検証環境のブラウザポリシーによりローカル `file://` と localhost を通常ナビゲーションできないため、テスト時は**本番の `ctu-securing-calculator.html` DOM と実際に読み込むCSS/JavaScriptをそのまま一つのテストHTMLへ展開**し、認証・外部通信だけをテスト用に切り離して Chromium 144 へ投入した。

したがって、今回「実画面確認済み」としている範囲は、固縛力画面の production DOM / CSS / JavaScript のレンダリング、ボタン操作、計算、再計算、レスポンシブ表示である。実運用URLの認証、メール、クラウドAPI、Windows上の最終ブラウザ受入は配置後の受入試験対象である。
