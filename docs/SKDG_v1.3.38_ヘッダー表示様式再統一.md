# SKDG v1.3.38 ヘッダー表示様式再統一

- 添付UIの濃紺系色調と文字の見え方を基準化。
- 機能画面32ページを同一の静的ヘッダー構造へ変更。
- ヘッダーは「メニュー / ホーム / 機能名 / 利用者名」のみ。
- 「検査・検品業務サポートシステム」という補助表示は機能ヘッダーから削除。
- 利用者表示はログイン中の表示名に更新し、ユーザー設定へのリンクとして維持。
- 旧ヘッダーCSS/JS（v1.3.33、v1.3.34、v1.3.37）を累積パッチから除去。
- 旧 `app-header` / `system-topbar` のヘッダーHTMLを対象機能画面から除去。
- サブメニューの遅延生成と軽量化方針を維持。
