# Part 212 正式運用最終確認要領

## 目的
ログイン機能付きデータベースの試験運用・正式運用開始前に、認証、権限、法令データ、申請番号・写真、バックアップ、監査、障害対応を横断して確認する。

## 操作
1. 設定から「正式運用最終確認」を開く。
2. 自動判定と分野別判定を確認する。
3. 12項目の確認を実施し、証跡を別途保存する。
4. 対象版、想定利用者数、判定、理由を入力する。
5. 判定を保存し、履歴とJSON出力を保管する。

## 正式運用開始可の条件
- 12項目がすべて完了している。
- 未解決の重大障害がない。
- 法令更新データに検証不合格がない。
- バックアップと復元確認の証跡がある。
- 職制承認と利用者周知が完了している。

## 権限
判定の閲覧・登録はシステム管理者権限で行う。将来的な管理者権限の移行先は安全環境室長に限定する。
