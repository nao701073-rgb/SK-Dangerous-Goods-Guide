# SKDG v1.3.71

## 方針
- v1.3.65 の入力内容・文言を表示基準として維持。
- v1.3.69 で正常化した①〜⑥の固定順序、JavaScript外部化、追跡表示を維持。
- 過去PART由来の外側ラッパー・空カード・二重カードを現行CTU画面の読み込み経路から外す。

## 修正
1. 上部追跡表示の外側の丸角カード枠・影を廃止し、追跡機能だけを残したフラット表示へ変更。
2. Step 5 の「固縛材／支保・あて材」は外側Stepカード内の小見出しとして表示し、カード内カードの二重枠を廃止。
3. 固縛方法は引張系固縛材・併用時に「直接固縛」「トップオーバー」の2択を必ず生成し、選択可能にする。
4. 登録済み結果復元時は、使用方法→固縛方法→表示更新の順に復元し、トップオーバーが直接固縛へ戻る経路を修正。
5. Step 1/2 の間などに旧ランタイムが残した内容のない直下シェルを削除。
6. Part551の案件復元機能は残すが、画面をdetails/cardで包み直すDOM変更処理は廃止。

- 支保・あて材併用ロジック
