# Part 218 安全環境室長・ゲスト権限変更要領

## 1. 安全環境室長

- 全事業所の申請番号を閲覧・登録・編集できます。
- 全事業所の関連写真を閲覧・登録・編集できます。
- 申請番号および写真の削除はできません。
- 削除は事業所管理者またはシステム管理者が実施します。
- 限定されたシステム設定を閲覧できます。
- クラウド接続、法令更新等の全体設定変更は、管理者権限移行完了まではできません。

## 2. ゲスト

利用可能:
- 危険物検索・詳細
- 関連法令
- 関連資料
- ユーザー設定
- 自分のアカウント確認、パスワード変更・再設定
- 表示・実寸補正、オフライン端末設定

利用不可:
- 申請番号管理
- 写真
- 検索履歴・お気に入り
- システム設定
- 各種管理画面

## 3. 削除制御

画面上で削除ボタンを非表示にするだけでなく、API側でも安全環境室長からの削除要求を拒否します。
