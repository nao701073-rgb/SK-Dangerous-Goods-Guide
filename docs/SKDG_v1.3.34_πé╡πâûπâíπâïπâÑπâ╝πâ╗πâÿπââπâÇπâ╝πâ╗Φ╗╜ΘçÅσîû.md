# SKDG v1.3.34

## サブメニュー
初期状態では閉じます。左上のメニューボタンを選択した場合のみ開き、背景選択・Escで閉じます。

## ヘッダー
従来の申請番号管理画面を基準に、左からメニューボタン、ホームボタン、機能名、右端にログイン利用者名を配置します。

## 軽量化
- v1-role-visibility.js の全DOM MutationObserverを廃止
- 250ms間隔の権限・ヘッダー再適用ループを廃止
- 主要機能で旧 unified-submenu.js の重複実行を停止
- サブメニューDOMは初めて開く時に生成
- 権限ゲートは初期表示とpageshow時だけ実行

既存の計算式、申請データ、DB構造、権限制御は変更しません。
