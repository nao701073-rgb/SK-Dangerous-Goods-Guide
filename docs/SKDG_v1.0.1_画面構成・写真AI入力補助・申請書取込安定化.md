# SKDG v1.0.1 画面構成・写真AI入力補助・申請書取込安定化

## 1. 方針
v1.0の「初版はシンプルで使いやすく」を維持し、機能を増やすよりも入力順・画面幅・スマートフォン操作を整えます。

危険物検索、危険物詳細、関連法令、原文参照、関連資料、P/LP/IBC/T/TP/BK/PP/B/VV/CV/V/SW/S/SP等の既存コード画面は削除しません。

## 2. 固縛力参考算出
標準操作順を次のように統一します。

1. 申請書を読み込む
2. 輸送条件と貨物を確認する
3. 写真を撮影／選択する
4. AI候補を確認し、検査員が採用する候補だけ選ぶ
5. 材質・接触状態から参考摩擦係数を表示する
6. 不足項目だけ補う
7. 参考算出する

既存の申請書読取・船積港／陸揚港からの航路推定を再利用し、申請書読取後は海域候補の確認を続けて実行します。

写真読取は自動確定ではありません。既存の写真読取結果を候補カードとして整理し、チェックした候補だけ既存入力欄へ反映します。MSL・安全性は写真だけで確定しません。

貨物・パレット材質は木、プラスチック、金属、ゴム等、床側は金属、木、プラスチック、ゴム等、状態は乾燥、濡れ、霜・氷・雪、油・グリース等から選択でき、参考摩擦係数候補を表示します。

## 3. 申請書取込・確認
取込後に危険物明細や長い品名が画面全体を押し広げないようにしました。

- PC：危険物明細の横幅はカード内に閉じ込め、必要な場合だけ表内をスクロール
- スマートフォン：1危険物を1カードとして縦に表示
- 入力欄・品名・確認表示は折返し
- 動的行追加後もページ全体の横スクロールを抑止

取込、事前確認、登録等の既存判定ロジックは変更しません。

## 4. 申請番号管理
v1.0の簡素化を維持し、案件一覧、案件情報・簡易メモ、添付資料、関連写真を中心にします。優先キューや進捗管理を標準画面へ戻しません。

## 5. ユーザー設定
高度機能のON/OFFは追加せず、日常操作に直接関係する次の3項目だけ追加します。

- 文字サイズ：標準／大きめ
- 操作ボタン・入力欄を大きくする
- 画面の動きを少なくする

設定は端末内に保存し、各画面へ共通適用します。

## 6. システム状態
「システム状態」ブロックはシステム管理者（`safety-environment-admin`）だけ表示します。他の全権限では非表示です。

## 7. 非変更事項
危険物マスター、許容容量・許容質量判定、関連法令・原文参照、固縛力の既存計算式、海域B初期値、併用条件、既存保存処理は変更していません。DBマイグレーションはありません。
