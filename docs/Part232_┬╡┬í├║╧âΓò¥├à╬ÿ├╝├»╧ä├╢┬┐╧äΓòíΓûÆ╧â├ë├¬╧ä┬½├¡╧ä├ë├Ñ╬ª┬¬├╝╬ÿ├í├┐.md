# Part 232 正式運用統合管理要領

## 1. 目的
正式運用前および大規模更新後に、利用者・権限、認証、法令データ、バックアップ、障害対応、監査を横断して確認するための統合画面を追加した。

## 2. 確認場所
`システム設定 → 正式運用統合管理`

本画面はシステム管理者のみ利用できる。

## 3. 主な機能
- 既存管理画面を6分野に分類して表示
- 正式運用確認12項目の記録
- 総合判定、確認所見、次回確認日の保存
- 確認結果のJSON出力

## 4. 保存方式
Part 232では、確認途中の状態をブラウザーのローカルストレージへ保存する。正式な承認証跡として使用する場合は、JSON出力を所定の文書管理先へ保存し、既存の正式運用最終確認画面で承認記録を残す。

## 5. 運用上の注意
- 本システムの利用は任意である。
- 利用履歴はセキュリティ確認、不適切利用の調査、障害調査および運用改善に限定して取り扱う。
- 透かし表示、スクリーンショット検知・追跡および画面自動保存は未実装である。
