# 第2回実装仕様

## 対象
危険物検索・解説

## 実装済み
1. UN番号検索
2. Proper Shipping Name検索
3. 日本語品名検索
4. 検索候補
5. 等級・容器等級・副次危険性等級フィルター
6. ページネーション
7. ブラウザ内お気に入り
8. 危険物詳細画面
9. 標札表示確認チェック欄
10. 包装要件・特別規定・積付・隔離表示

## データ形式
`data/un-data.js` に `window.UN_DATABASE` として格納しています。

file:// での直接起動時にも読み込めるよう、JSONのfetchではなく
JavaScriptデータファイル方式を採用しています。

## 制約
- EmSの独立データは未収録
- IMDG Code英語原文は未収録
- 標札画像は未紐付け
- お気に入りは端末単位のlocalStorage保存
