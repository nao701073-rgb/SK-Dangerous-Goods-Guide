# Part 234 運用受入承認・是正管理要領

## 1. 目的
運用受入・定期点検の結果について、承認、差戻し、指摘事項の是正、次回点検日を一連で管理します。

## 2. 主な機能
- 保存済み点検記録の承認・差戻し
- 承認・差戻し理由の記録
- 不合格、条件付き受入、未完了事項の是正管理
- 優先度、期限、進捗、完了証跡の記録
- 次回点検予定と期限超過の表示
- 承認結果と是正対応を含むJSONレポート出力

## 3. 運用上の留意事項
- 全分野合格時のみ「正式運用可」を保存できます。
- 差戻し後は証跡を補い、再点検記録を保存してください。
- 緊急または期限超過の是正対応は、担当者と完了条件を明確にしてください。
- 本システムの利用は任意です。

## 4. クラウド運用時
`server/sql/083_operations_acceptance_governance.sql`を適用し、承認履歴と是正対応をPostgreSQLへ保存します。
