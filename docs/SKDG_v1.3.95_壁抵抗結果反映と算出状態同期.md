# SKDG v1.3.95 壁抵抗結果反映と算出状態同期

## 修正した不具合
v1.3.94では、方向別の「壁抵抗を使用」にチェックしても、既に表示されている算出結果が自動更新されず、CTU境界抵抗0 kNの古い結果が残る場合がありました。
また、「不足内容・現場説明サポート」のバッジが算出後も「算出待ち」のまま残っていました。

## v1.3.95
- 既に算出済みの状態で壁抵抗チェックを変更すると自動再算出。
- 壁抵抗使用方向の変更、確認隙間、CTU条件、P値の変更を結果へ再反映。
- 現場説明サポートを三段階判定と同期。
- 初回入力時は従来どおり「この条件で算出する」を押す方式を維持。

## 判定について
壁抵抗を使用した方向が充足しても、別方向のMSL・支保根拠等に未確認項目があれば、総合判定は「要確認」のままになる場合があります。これは「固縛不良」の確定ではなく、未確認条件が残っていることを示します。
