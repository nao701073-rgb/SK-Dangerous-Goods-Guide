# Part 376 更新内容

## 認証継続不具合の根本修正

- ユーザー設定、システム設定、管理画面、通常機能へ移動した際にログイン画面へ戻る問題を修正しました。
- 認証ブリッジの旧形式（V1/V2）と新形式（V3）を同時に読み取れるよう統一しました。
- ローカルファイル運用でも、内部リンクへ認証情報を付与して次画面で復元します。
- ページ読込後に追加されるリンクも自動的に認証付きリンクへ更新します。
- ログイン完了後の移動にも同じ認証ブリッジを使用します。
- ログアウト時は、すべての認証ブリッジ形式を削除します。
- 事業所利用者、事業所管理者、ゲスト、安全環境室長、安全環境室職員、システム管理者、検証者の全権限を対象とします。
