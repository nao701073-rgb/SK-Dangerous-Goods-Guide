# Part 236 改善計画・年度総括管理要領

## 1. 目的
運用受入・定期点検の承認後に残った改善事項を、責任者・期限・証跡とともに追跡し、年度単位で次年度へ確実に引き継ぐ。

## 2. 改善計画
- 関連点検記録、区分、責任者、期限、状態、改善内容を登録する。
- 状態は「計画」「対応中」「完了」「次期へ引継ぎ」とする。
- 完了時は証跡を記録する。期限超過は管理画面で確認する。

## 3. 年度総括
- 年度内の点検件数、承認済み件数、未完了是正、改善計画を集計する。
- 総合判定、年度総括、次年度への引継事項、次年度初回点検日を保存する。
- JSON出力を年度の管理記録として保管できる。

## 4. 基本方針
本システムの利用は任意です。利用頻度ではなく、権限、データ品質、セキュリティ、バックアップ、障害対応等の運用品質を確認する。
