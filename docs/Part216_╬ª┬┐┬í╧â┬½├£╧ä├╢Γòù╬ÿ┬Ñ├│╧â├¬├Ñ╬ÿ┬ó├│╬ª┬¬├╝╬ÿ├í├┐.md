# Part 216 設定画面分離要領

## ユーザー設定
全利用者が使用します。表示形式、IMDG参照表示、実寸補正、アカウント情報、オフライン優先設定を管理します。

## システム設定
事業所管理者またはシステム管理者が使用します。所属・権限、クラウドAPI、写真保存、法令更新、監査、バックアップ、運用管理を扱います。

## 権限制御
- 事業所利用者、安全環境室長、安全環境室職員：ユーザー設定のみ
- 事業所管理者：所属事業所に関する管理項目
- システム管理者：全システム設定

一般的な「設定」リンクはユーザー設定へ移動し、各管理画面の「設定へ戻る」はシステム設定へ移動します。
