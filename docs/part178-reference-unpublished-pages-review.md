# Part 178 関連資料 未掲載ページ追加・重複整理

## 対応内容

- 添付された元資料129ページを再精査しました。
- 同一ページを「ページ全体」「拡大詳細」の2カードで重複表示する方式を廃止しました。
- 1つのPDFページは1カードで表示し、画像クリックで拡大確認する方式へ統一しました。
- 従来未掲載だった、検査・検品業務に有用なページを各分野へ追加しました。
- 分類、容器包装、表示、書類、積載、隔離、CTU、CSC、緊急対応、港湾対応を横断して収録しています。

## 表示方針

- 各カードにページ番号、概要、現場で確認する点を表示します。
- 図・写真・表の細部は、画像をクリックして拡大確認します。
- AI要約だけで判断せず、元資料画像、国内法令、IMDG Code最新版を照合してください。
