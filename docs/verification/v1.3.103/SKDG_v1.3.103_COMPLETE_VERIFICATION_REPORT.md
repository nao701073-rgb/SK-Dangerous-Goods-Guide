# SKDG v1.3.103 COMPLETE VERIFIED SYSTEM - 検証報告

## 1. 基準と変更範囲

v1.3.102完全版を基準に、CTU固縛力参考算出の次の2点を追加しました。

1. 「要確認」時に不足項目／確認待ち項目を分離し、該当入力欄へ直接移動・フォーカスできる案内。
2. 固縛材・支保材について、材質だけで数値を決めず、規格・径・表示LC/MSL、または支保材の寸法・自由長まで選択した場合に、根拠のあるMSL／参考支保力候補を自動反映する機能。

必要抵抗力、摩擦、直接固縛、壁抵抗、弱点MSL、方向別判定等のCTU/CSS計算式そのものは変更していません。

## 2. 固縛材MSL候補の方針

- MSL/LCの実物表示、メーカー仕様、証明値がある場合はそれを優先します。
- 材質名だけでは一律MSLを確定しません。
- 自動反映した値は「参考候補」として扱い、実物の規格・表示・使用条件確認を残します。
- ウェブラッシングは材質名からの一般推定式を使用せず、表示LC/MSL候補または手入力とします。
- PET/ポリエステル帯状バンド、FRP等は材質名だけで能力を作らず、メーカー・試験・設計確認値の入力を求めます。

### CTU Codeに直接基づく主な候補

- Grade 8・13 mmチェーン: MSL 100 kN
- 海上輸送・一方向使用ワイヤ: 認証MSLがない場合の参考式 MSL = 40*d^2 [kN]（d: cm）
- PPロープ: メーカーMSLがない場合の参考式 MSL = 4*d^2 [kN]（d: cm）
- MSL/BL比: ウェビング使い捨て75%、再使用50%、ワイヤ使い捨て80%、再使用30%、帯鉄70%（CTU Code注記では50%推奨）、チェーン50%

帯鉄の具体的な31.75x0.80 mm、31.75x1.45 mm候補やA-SLASH等の製品値は、既存比較資料等の破断強度／製品資料に依存するため参考候補のままとし、実物確認なしでは確定扱いにしません。

## 3. 支保材の方針

支保材については「MSL」ではなく「支保力」として扱います。

木材横木は CTU Code Annex 7 Appendix 4 の式

`F = n*w^2*h/(28*L) [kN]`

を使用し、n=1として1本当たりの参考支保力を候補表示します。wは厚さ、hは高さ、Lは自由長であるため、プルダウンにもw/h/Lを明記しました。同じ断面寸法でも向きを曖昧にしません。

FRPその他は、メーカー許容荷重、試験成績、施工図、設計計算等の確認値を入力する仕様です。

Chromium 144で本番ページDOM/CSS/JavaScriptを読み込む検証ハーネスを使用し、認証・外部通信のみ切り離して確認しました。

- 材質／規格・支保仕様の選択と自動反映: 25/25 PASS

- 従来1列／2列／スマホ／計算回帰: 53/53 PASS
- ページJavaScriptエラー: 0

主な実画面確認:

- 帯鉄 31.75x0.80 mm CTU Code推奨50%候補 -> 8.7 kN
- Grade 8チェーン 13 mm -> 100.0 kN
- 一方向使用ワイヤ 16 mm -> 102.4 kN
- PPロープ 16 mm -> 10.2 kN
- ウェビング 表示LC/MSL 25 kN -> 25.0 kN（実物確認待ち）

自動反映候補は進捗判定上「確認待ち」となり、確認なしに確定値へ昇格しません。

## 8. 安全上の扱い

本機能は「参考算出」です。規格選択で自動反映した数値は、実物の刻印・ラベル・証明書・メーカー仕様・劣化状態・端部／曲げ条件・接続金具・施工状態・荷重経路等の確認に代わるものではありません。直接固縛では引き続き固縛材、貨物側取付部、CTU側固縛点の最弱値を上限として評価します。
