# SKDG v1.3.58 固縛力参考算出 全体再点検

## 全海域対応
- 海域A / 海域B / 海域C の3区分をすべて明示的に扱う。
- 日本・東アジア・東南アジア・南アジア・中東・北欧・地中海・北米西岸/東岸・メキシコ湾/カリブ・南米東岸/西岸・オセアニア・南部/東西アフリカ・高緯度域を航路推定対象とする。
- 登録港にない港名でも、国・地域名ヒントがあれば地域候補を判定する。
- 港・地域を特定できない場合は処理を停止せず、海域Bを初期候補とし「要確認」とする。
- 長距離外洋、喜望峰周辺、高緯度冬季などは海域Cを保守的候補とする。
- 域内の比較的短い航海は海域A候補、それ以外の一般国際航海は海域B候補とする。

## 連携
Excel申請書の船積港・陸揚港・出港月 → 航路推定 → quickTransport / transportPreset → applyTransportPreset → 方向別加速度係数へ同期する。
