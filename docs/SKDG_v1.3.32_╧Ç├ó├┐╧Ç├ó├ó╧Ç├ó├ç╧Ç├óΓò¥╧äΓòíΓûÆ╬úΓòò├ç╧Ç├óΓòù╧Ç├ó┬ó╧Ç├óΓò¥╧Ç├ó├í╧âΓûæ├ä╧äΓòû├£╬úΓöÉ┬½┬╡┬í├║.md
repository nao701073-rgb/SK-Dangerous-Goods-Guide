# SKDG v1.3.32 ヘッダー統一・ホーム導線修正

## 対応内容
- 主要機能のヘッダー／ホームアイコンの見た目を統一
- 危険物検索・危険物詳細の `system-topbar` にホームアイコンを追加し、ヘッダー配色を統一
- 固縛力参考算出に共通ヘッダーを追加
- 申請書取込・確認のアイコンをホームアイコンへ統一
- 改善要望・検索履歴のホームアイコン差異を解消
- 右上の利用者表示を実表示名へ置換し、ユーザー設定への導線を維持
- オーバーパック表示用作成／システム設定の権限制御は維持

## 主変更ファイル
- `assets/js/v1-role-visibility.js`
- `pages/*.html`（`v1-role-visibility.js?v=1332` へ更新）
