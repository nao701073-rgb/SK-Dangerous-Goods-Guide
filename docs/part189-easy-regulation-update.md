# Part 189 法令・データかんたん更新モード

## 目的
最新版PDF、CSV／JSON、版情報を一つの画面から登録し、公開前の検証候補を作成します。

## 実装範囲
- 危規則、危告示、放告示、IMDG Code、CTU Code、MARPOL、CSCに対応
- PDFのSHA-256生成
- CSV／JSONの読み込み
- 識別キーの空欄・重複検査
- 旧版との追加・変更・削除件数比較
- 更新マニフェストJSONと検証結果JSONの出力
- 設定画面から更新管理画面への導線追加

## 安全方針
PDFから抽出した内容を無確認で本番公開しません。原文照合、担当者確認、承認後に構造化データを公開します。
