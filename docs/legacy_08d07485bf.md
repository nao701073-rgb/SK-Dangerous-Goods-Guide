# Part 319 更新内容

## 申請番号管理の補完機能化・簡素化

社内既存システムを正式な申請番号管理元とし、本システム側は不足機能の補完に集中する構成へ整理した。

### 主な変更

- 画面冒頭に、補完機能であることを明示
- 主目的を「関連写真・簡易メモ・添付資料の整理」に限定
- 上部メニューを「対象を選ぶ／メモ・基本情報／登録済み案件／添付資料／関連写真」に簡素化
- 通常入力では申請年度・申請番号・簡易メモを中心に表示
- 船名、航海番号、危険物情報、日付等は「詳細項目を表示」から任意入力
- 進捗件数ダッシュボードを通常表示から削除
- 写真の高度な保存期間・監査・完全削除計画等は通常画面から非表示
- 既存データ、写真、添付資料、権限制御との互換性を維持

## 運用方針

複雑な期限管理、優先順位、承認ワークフロー、詳細ダッシュボードは追加せず、簡単に使える補助機能として運用する。
