# SKDG v1.3.42 スマホ表示再検証

## 方針
PC表示はv1.3.41を維持し、680px以下だけを追加調整する。

## 再確認した主な機能
- ホーム
- 危険物検索
- 危険物詳細
- 申請番号管理
- 申請書取込・確認
- 固縛力参考算出
- 関連法令
- 関連資料
- オーバーパック表示用作成
- 検索履歴
- 改善要望
- ユーザー設定 / システム設定
- 共通ヘッダーを使用する管理・確認画面

## 追加補正
- ページ全体の意図しない横スクロールを防止
- 大型表/印刷プレビューだけ局所的な横スクロールを許可
- 520px以下で危険物検索の結果ファクトを4列から2列へ
- 520px以下で固縛ライン入力を1列へ
- 520px以下で申請番号管理のセクションナビを1列へ
- 共通ヘッダーの長い機能名と利用者表示を狭幅向けに調整
- 入力/select/textareaを16px以上に統一

## PCへの影響
新規CSSはすべて max-width:680px 以下のメディアクエリ内で適用するため、PCレイアウトには適用しない。
