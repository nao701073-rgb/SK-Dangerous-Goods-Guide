# Part 131 アクセス監査ルールの承認・適用・ロールバック

## 目的
監査ルールの閾値変更を即時上書きせず、シミュレーション、申請、別担当者承認、適用の順で管理します。

## 操作手順
1. 候補ルールを入力する。
2. 「変更前にシミュレーション」を実行する。
3. 変更理由と適用方法を指定して変更申請を作成する。
4. 申請作成者とは別の事業所管理者または管理者が承認する。
5. 即時適用または予約日時に適用する。

## 制御
- シミュレーション未実施では申請を作成できません。
- 変更理由は必須です。
- 申請作成者本人による自己承認は禁止します。
- 予約適用は承認後、指定日時以降に適用します。
- 差戻し・取消には理由が必要です。

## ロールバック
適用済み申請から、適用前ルールを候補とするロールバック申請を作成します。ロールバックも別担当者の承認を必要とし、直接上書きしません。

## 権限
承認・適用・差戻しは、事業所管理者または管理者のみ実行可能です。
