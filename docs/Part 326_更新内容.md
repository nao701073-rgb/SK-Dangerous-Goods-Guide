# Part 326 更新内容

## ログイン成功時のSKロゴ演出を控えめに調整

- 演出は認証成功時のみ再生
- SKロゴの拡大率と発光量を抑制
- 左右へ広がる光を2pxの細い線へ変更
- 光の到達範囲を画面幅の約34%以内に制限
- 画面全体のフラッシュを弱め、業務画面への移行を自然化
- 演出時間を約1.1秒へ短縮
- `prefers-reduced-motion`環境では、強い動きを使用しない

## 維持する仕様

- 時間帯区分は06:00～10:00、10:00～16:00、16:00～19:00、19:00～翌06:00
- 時間帯による色調変更はログイン画面だけに適用
- 認証失敗時は演出を再生しない
- ログイン後は既存の白・青基調を維持
- ブラウザ版・スマートフォン版の双方に適用
