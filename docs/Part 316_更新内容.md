# Part 316 更新内容

## 権限別ホームの業務確認機能

- 権限別ダッシュボードに「優先確認」と「最近更新された案件」を追加。
- 検査予定日が超過、本日、3日以内の案件を優先順位付きで表示。
- 下書き・受付済みの案件も確認対象として表示。
- 事業所利用者・事業所管理者は所属事業所、管理系権限は全事業所を対象に集計。
- 案件番号、案件名、更新日、期限状況をホーム画面から確認可能。
- 各案件から申請番号管理へ直接移動し、該当案件を検索表示。
- 「最近更新された案件」から更新日の新しい順で一覧を開く導線を追加。
- ゲスト権限では案件情報を表示せず、利用対象外であることを明示。
- スマートフォンでは業務確認欄を1列表示に調整。

既存の申請番号データ、権限制御、ログイン機能、表示テーマの保存形式は変更していません。
