# SKDG v1.3.79 CTU MSL材質連動・CTU側主確認

## 目的
固縛材を変更したにもかかわらず、直前の1本当たりMSLが残り続ける状態を解消する。

## 変更内容
- 「固縛・支保条件」の固縛材選択と「材質・サイズからMSL候補を算出」の固縛材カードを連動。
- 登録済みの参考プロファイルがある場合、材質変更時にMSL候補を1本当たりMSLへ参考反映。
- 登録済み候補がない材質は旧値を残さず、確認値の入力を要求。
- MSL候補カード側の材質・サイズ変更でも、対応する主入力欄へ即時反映。
- 直接固縛の採用MSLを主画面に表示し、固縛材・貨物側取付部・CTU側固縛点の3値と制限要因を明示。
- CTU側固縛点が最小の場合は主確認箇所として強調表示。
- 同値の場合の表示上の制限要因はCTU側固縛点を優先。
- トップオーバー切替時はMSL値をSTFとして流用しない。

## 計算原則
直接固縛では、従来どおり `min(固縛材MSL, 貨物側取付部MSL, CTU側固縛点MSL)` を1本当たりの実効上限とする。CTU側固縛点は通常の主確認値として見やすくするが、他の要素がより小さい場合はその小さい値を採用する。

## 安全側の扱い
参考マスターから自動反映した値は確認済み値とは扱わず、メーカー仕様・刻印・証明書・試験成績等を優先する。施工条件依存の製品は参考値だけでは自動反映しない。
