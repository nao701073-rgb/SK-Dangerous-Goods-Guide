# Part 238 改善計画承認・変更・引継ぎ管理要領

## 1. 目的
改善計画の承認、担当者変更、期限変更、次年度への引継ぎ受領および差戻しを一連の記録として管理する。

## 2. 操作
1. システム設定から「運用受入・定期点検」を開く。
2. 「改善計画の承認・変更・引継ぎ受領」で対象計画を選択する。
3. 手続き、必要な変更内容、理由または引継ぎ内容を入力する。
4. 記録後、改善計画一覧と進捗レポートを確認する。

## 3. 管理原則
- 変更前後の担当者・期限を履歴として保持する。
- 引継ぎ受領後は原則として「対応中」に移行する。
- 差戻し時は理由を必須とする。
- 進捗レポートは監査・引継ぎ用に保存する。
- 本システムの利用は任意です。
