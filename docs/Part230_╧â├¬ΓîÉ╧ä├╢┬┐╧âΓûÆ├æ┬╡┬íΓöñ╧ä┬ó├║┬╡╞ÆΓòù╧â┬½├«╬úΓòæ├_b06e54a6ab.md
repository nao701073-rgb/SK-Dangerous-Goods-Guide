# Part 230 利用履歴監査完了・月次サマリー要領

## 1. 目的
利用履歴監査の確認から承認、対応完了、月次報告までを一連の記録として保存する。

## 2. 基本方針
- 本システムの利用は任意です。
- 利用回数や未使用を人事評価・業務評価に使用しない。
- 利用履歴は、不適切利用の確認、情報セキュリティ、障害調査、運用改善、正当な監査に限定する。
- 透かし表示、スクリーンショット検知・追跡、画面自動保存は現時点で実装しない。

## 3. 追加機能
1. 定期監査レポートの承認・差戻し
2. 承認済み保存整理申請の実施記録（実データ削除は行わない）
3. 月次運用責任者サマリーの生成・保存・承認
4. 各管理操作の監査ログ保存

## 4. 保存整理
整理実施記録には、承認番号・作業記録番号等と実施内容を記録する。本機能は削除コマンドを実行せず、実削除は別途承認済み手順で実施する。

## 5. 月次サマリー
対象月の総操作件数、利用者数、機能別件数、警告対応、監査レビュー、生成済みレポートを集計する。利用頻度の評価や順位付けには使用しない。
