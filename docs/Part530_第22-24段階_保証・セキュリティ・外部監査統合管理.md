# Part 530 第22～第24段階

## 対象
- 第22段階：運用ログ・監査証跡の保存期限、アーカイブ、法的保全、廃棄
- 第23段階：脆弱性、依存関係、セキュリティ更新、期限・リスク受容
- 第24段階：外部監査、証跡提出、指摘是正、終了承認

## 主要統制
法的保全中は廃棄不可。廃棄は作成・確認・実行・検証を分離します。重大度別の脆弱性期限は重大1日、高7日、中30日、低90日です。対応責任者・対応実施者本人は終了承認できません。監査証跡は保管参照番号とSHA-256だけを台帳化し、メールアドレス、パスワード、トークン、秘密鍵、証跡本文は保存しません。未解決の重大・高監査指摘がある場合、外部監査を承認できません。
