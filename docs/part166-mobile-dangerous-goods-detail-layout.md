# Part 166 危険物詳細のスマートフォン表示改善

## 対応内容

1. 基本情報を縦並びに変更
   - 標札画像を上部中央へ配置
   - 国連番号、日本語品名、英語名を画像の下へ配置
   - 等級、副次危険性等級、容器等級、海洋汚染物質を折り返し表示

2. 正標札・副標札を縦並びに変更
   - 1枚ずつ画面幅いっぱいに表示
   - 副標札がない場合は空枠を生成しない

3. 横スクロールの抑制
   - タブを横スクロール式から折り返し式へ変更
   - 長い品名、英文、コード、表、法令参照を画面内で折り返す
   - コードカードをスマートフォンでは1列表示

4. 下部メニューとの重なり解消
   - ページ下部に下部メニューとセーフエリア分の余白を追加

5. スマートフォン用の文字サイズ・余白調整
   - 見出し、ボタン、カード、タブのサイズと余白を縮小
