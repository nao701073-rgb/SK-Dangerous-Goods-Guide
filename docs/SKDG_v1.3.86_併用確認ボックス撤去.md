# SKDG v1.3.86 併用確認ボックス撤去

赤枠で指摘された Step 5 の大きな併用確認・説明ボックスを撤去しました。

## 維持するもの
- 固縛材 / 支保・あて材の「計算に使用する」チェック
- 両方を同時に使用する運用
- 同一滑動方向へ支保抵抗と直接固縛抵抗を単純加算しない二重計上防止
- CTU Code / CSS Code 計算ロジック
- v1.3.81 三段階判定

## 変更するもの
- 併用確認用チェックボックスを利用者操作から削除
- 併用確認チェックが未操作という理由だけで「要確認」にならないよう修正
- 進捗バーの確認項目から併用確認チェックを除外
