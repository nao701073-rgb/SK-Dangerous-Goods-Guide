# Part 134 監査ルール変更申請の処理台帳・適用証明

## 概要
監査ルール変更申請について、申請作成から承認、適用、差戻し、担当者変更、管理者引継ぎまでをイベント履歴として保存し、適用済み申請には適用証明を生成します。

## 処理イベント
以下の操作をイベントとして記録します。

- 申請作成
- 承認
- 適用
- 差戻し・取消
- 通知確認
- 担当者再割当
- 管理者引継ぎ

イベントには申請ID、操作種別、操作者、権限、日時、処理後状態、理由、補足情報を保存します。

## 適用証明
承認済み申請が適用された時点で、次の情報を含む証明を自動生成します。

- 証明書ID
- 変更申請ID
- 変更またはロールバックの区分
- 変更理由
- 適用前ルール
- 適用後ルール
- シミュレーション集計
- 申請者・申請日時
- 承認者・承認日時
- 適用者・適用日時
- 適用方式・予約日時
- 検証ハッシュ

## 検証
証明書本文から検証ハッシュを再計算し、変更申請の適用状態、適用日時、適用ルールと照合します。不一致がある場合は台帳上で要確認と表示します。

## 出力
- 変更申請処理台帳CSV
- 適用証明JSON
- 適用証明一括JSON

## 権限
承認・適用・差戻し等の操作権限は従来どおり、事業所管理者または管理者に限定します。自己承認禁止も維持します。
