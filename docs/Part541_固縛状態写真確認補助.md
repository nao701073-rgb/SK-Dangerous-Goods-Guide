# Part 541 固縛状態写真確認補助

## 1. 目的

写真からMSL文字を読み取ることではなく、現場写真を用いて固縛箇所、貨物側・CTU側取付点、固縛材・支保材の種類候補、本数、位置、方向、固縛ラインを確認しやすくする。

## 2. 写真上の指定

貨物側取付点、CTU側取付点、要確認箇所、損傷箇所は写真上を1回タップして登録する。固縛材と支保・当て材は始点と終点を順番に指定し、1本として登録する。

## 3. 材質候補

ワイヤーロープ、チェーン、繊維製ラッシング・ベルト、帯鉄、TY-GARD、PET・エステルバンド、ロープ、木材、鋼製支保材、その他、判別困難から選択する。写真のみで自動断定せず、利用者が現物確認後に確定する。

## 4. 集計・位置整理

指定した線の数から固縛材・支保材の本数候補を集計する。各指定について、画像内の左上・中央・右下等の位置と、ほぼ水平・垂直・右上がり・右下がりの向きを整理する。実際の前後左右・上下方向は利用者が選択する。

## 5. 入力反映

写真確認結果から、固縛材本数、支保材個数、使用方法、材質候補、固縛ライン、取付位置候補を入力欄へ反映できる。反映後も利用者が修正できる。

## 6. 保存・出力

写真上の指定内容は案件に紐づけて保存し、取付点・固縛状態写真台帳、報告書、JSON出力へ含める。

## 7. 制限

本機能は画像認識による自動判定ではない。写真上で利用者が指定した箇所を集計・整理する確認補助であり、材質、強度、MSL、使用可否は現物、刻印、仕様書、図面、承認資料、試験成績等で確定する。
