# Part 379 更新内容

## 利用者CSV一括登録

- システム設定の「利用者アカウントの簡易登録」にCSV一括登録機能を追加。
- CSVひな型をシステム設定からダウンロード可能。
- 登録前に列、ログインID、権限、所属事業所、メール形式、パスワード、重複を検証。
- エラーが1件でもある場合は登録を開始せず、行ごとの修正理由を表示。
- 空欄の初期パスワードは安全な16文字の仮パスワードを自動生成。
- 登録結果CSVをダウンロード可能。自動生成された初期パスワードも結果CSVに含む。
- 事業所管理者は自事業所の一般利用者のみ登録可能。
- システム管理者は全権限・全事業所を登録可能。
- スマートフォンでは操作ボタンを縦並び、プレビュー表は横スクロールに対応。
