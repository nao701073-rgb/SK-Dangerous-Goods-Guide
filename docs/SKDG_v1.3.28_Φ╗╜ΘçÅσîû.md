# SKDG v1.3.28 Performance Hotfix

## 目的
固縛力参考算出画面の初期表示時に、長期間の機能追加で蓄積した旧互換・拡張スクリプトがHTML解析を連続して止める時間を削減する。

## 変更
- ページ本体の主要ロジックより後ろに配置されている旧互換・拡張スクリプト29本へ `defer` を付与。
- `defer` 同士の実行順序はHTML記載順のまま維持。
- DOMContentLoadedより前に実行される性質も維持し、既存の初期化イベントとの互換性を確保。
- HEIC/HEIF変換ライブラリは、画像形式サポート側との依存関係を完全確認できるまで従来読み込みを維持。

## 非変更
- 固縛力計算式
- MSL/STF候補・警告
- 申請番号管理との連携
- 写真・資料・算出結果の保存仕様
- 権限
- DB
- 画面表示バージョン
