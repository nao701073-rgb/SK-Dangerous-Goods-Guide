# Part 291 更新内容

## 関連資料画面の操作改善

- 画面上部に、次の資料区分へ直接移動できるナビゲーションを追加しました。
  - 検査・検品業務資料 AI要約
  - IMDG関連条文
  - 規定のAI要約
  - 登録資料
- 登録資料の検索欄を登録資料一覧の直前へ配置しました。
- 資料名、ファイル名、タグを横断して検索できます。
- 分類に加え、日本語・英語による絞り込みを追加しました。
- 推奨順、資料名昇順、資料名降順、分類順を選択できます。
- 適用中の検索条件を画面上に表示します。
- 「条件をクリア」により、検索語、分類、言語、並び順をまとめて初期化できます。

## 互換性

関連資料データ、申請番号、関連写真、添付資料および検索データの保存形式は変更していません。
