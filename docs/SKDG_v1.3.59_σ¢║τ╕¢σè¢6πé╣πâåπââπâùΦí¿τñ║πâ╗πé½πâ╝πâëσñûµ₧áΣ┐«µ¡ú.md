# SKDG v1.3.59 固縛力6ステップ表示・カード外枠修正

- ①・②が一体に見える旧外枠、疑似要素、デッキ背景を最終CSSで無効化。
- ③〜⑥の親デッキ／quick-flowはレイアウト専用とし、外枠・背景・影を持たせない。
- ①〜⑥の各カードを同じ border / radius / header / gap で独立表示。
- 上部の入力状況を従来3区分から①〜⑥の6区分へ変更。
- 完了時も番号は常時表示し、チェックマークは状態文字の補助として小さく表示。
- 「入力不足」「確認項目」の詳細に該当ステップ番号を付加。
- ①申請書・航路、②写真は任意の入力補助として表示し、途中入力時のみ不足・確認を通知。
- ③輸送・貨物、④接触面、⑤固縛・支保、⑥算出・登録を個別に追尾。
- v1.3.58の全海域A/B/C推定および算出式は変更なし。
