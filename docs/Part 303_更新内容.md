# Part 303 更新内容

## 関連資料の確認期限管理

- 各登録資料の「確認期限」ボタンから、YYYY-MM-DD形式で期限を登録できます。
- 空欄で保存した場合は期限を解除します。
- 確認済み以外の資料について、期限超過を自動判定します。
- 期限超過、本日期限、7日以内、30日以内で絞り込めます。
- 件数カードに「期限超過」を追加しました。
- 並び順に「確認期限が近い順」を追加しました。
- CSV出力と個人設定JSONの読込・出力でも確認期限を保持します。

## 互換性

既存の関連資料設定、確認手続き、お気に入り、要確認、メモ、閲覧履歴の保存形式を維持しています。期限未設定の既存データはそのまま利用できます。
