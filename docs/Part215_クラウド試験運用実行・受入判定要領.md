# Part 215 クラウド試験運用実行・受入判定要領

## 1. 目的
初期50名のクラウド試験運用について、招待、初回ログイン、パスワード変更、MFA、権限確認、性能、バックアップ及び総合判定を一つの記録単位で管理する。

## 2. 実施順序
1. 試験運用バッチを登録する。
2. 利用者CSVを検証し、役割・所属・メールアドレスを確認する。
3. 招待を実施し、送信・到達・失敗・期限切れ件数を記録する。
4. 利用者進捗スナップショットを保存する。
5. 権限、メール、50名性能、150名性能、写真保存、バックアップ・復元の試験結果を登録する。
6. 未完了事項を解消し、受入判定を記録する。

## 3. 安全環境室
- 安全環境室長1名、安全環境室職員5名を想定する。
- 両役割は全事業所の申請番号及び関連写真を閲覧できる。
- 試験運用時点では閲覧専用とする。
- 将来のシステム管理者権限移行対象は安全環境室長に限定する。

## 4. 受入判定
- 保留：重大な未完了事項又は不合格試験がある。
- 試験継続：運用を継続し、要確認事項を解消する。
- 150名拡張可：50名試験が安定し、150名性能確認に重大問題がない。
- 正式運用準備可：必須確認項目が完了し、不合格試験がない。

正式運用準備可は、全必須チェック完了、重大な未解決課題0件、不合格試験0件を条件とする。

## 5. 証跡
招待結果、メール配信記録、ログイン確認、権限確認表、負荷試験結果、バックアップ・復元証跡及び受入判定理由を保存する。パスワード、MFA秘密情報等は記録しない。
