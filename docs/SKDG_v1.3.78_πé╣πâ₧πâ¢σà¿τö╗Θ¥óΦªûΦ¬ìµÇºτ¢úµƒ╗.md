# SKDG v1.3.78 スマホ全画面視認性監査

## 対応方針
v1.3.77を基準とし、計算ロジック・判定ロジック・権限制御は変更せず、680px以下のスマホ表示のみを補正した。

## 主な対応
- 固縛力参考算出：入力状況パネルをスマホでは追尾解除し、3列×2段（420px以下は2列）へ圧縮。入力欄を原則1列化。
- 申請書確認：確認表をスマホではカード形式とし、項目名を上段、値を下段に配置。
- 申請番号管理／申請詳細：操作・入力グリッドを1列化し、横幅不足を解消。
- 危険物検索／詳細：検索条件・結果概要の密集を緩和し、長い品名や法令名の折返しを強化。
- 関連法令／関連資料／設定：カード・フォームを1列化し、表だけ必要時に局所横スクロールを許可。
- 共通：入力欄16px、操作ボタン44px以上、safe-areaを考慮した下余白、ページ全体の横スクロール抑制。

## 非変更事項
- CTU Code / CSS Code の算出ロジック
- 支保荷重経路モデル
- 申請確認の判定ロジック
- 申請番号管理の保存・登録ロジック
- 権限・認証・データ構造
- PC表示
