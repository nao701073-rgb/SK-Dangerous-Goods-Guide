# Part 171 改善要望受付機能

## 追加機能

- ホームおよび危険物検索のメニューに「改善要望」を追加
- 利用者が次の要望を登録可能
  - 機能追加
  - 操作・表示の改善
  - 不具合
  - データ・法令内容の訂正
  - 速度・容量
  - その他
- 件名、問題点、希望内容、対象画面、所属、氏名、参考画像を登録
- 自分が送信した要望と対応状況を確認
- 事業所管理者・管理者は同じ画面で受付状況と回答を更新
- 管理者一覧をCSV出力
- ハイブリッド・オンライン運用時は同期キューへ登録

## 試験運用上の制約

現在の静的試験運用版では、要望データはブラウザのローカルストレージに保存されます。正式運用時には社内サーバーAPIへ保存し、全利用者の要望を管理者が一元管理する構成が必要です。
