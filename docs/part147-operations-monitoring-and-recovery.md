# Part 147 運用監視・障害対応・復旧訓練

## 目的
本番運用開始後の状態監視、障害対応、復旧訓練、定期点検を一つの画面で管理し、障害の放置、復旧手順の形骸化、点検漏れを防止します。

## 実装範囲

### 1. 運用状態チェック
以下を横断確認します。

- ブラウザ保存容量
- オフライン・ハイブリッド・オンラインの運用方式
- 社内API接続先の設定
- 同期キューの未完了件数
- バックアップ履歴
- 本番リリース判定履歴
- 未解決の重大障害

結果は「正常」「要確認」「要修正」で表示し、JSON・CSVへ出力できます。点検記録にはSHA-256検証ハッシュを付与します。

### 2. 障害・不具合管理
障害記録には次の情報を保持します。

- 件名、重要度、発生日時
- 対応期限、受付者、担当者
- 発生内容、影響範囲、再現手順
- 暫定対応、恒久対応、復旧結果
- 対応完了者、完了確認者
- 状態変更履歴

処理状態は「受付」「調査中」「復旧対応中」「完了確認待ち」「完了」です。対応完了者本人による自己完了確認を禁止します。

### 3. 復旧訓練
以下の訓練を記録できます。

- バックアップ復元
- 社内API停止
- 端末交換
- オフライン継続運用
- その他

実施者と確認者を分離し、シナリオ、復旧結果、課題を保存します。

### 4. 定期点検計画
月次、四半期、半期、年次、任意周期の点検計画を登録できます。期限超過、実施結果、次回期限を管理します。

### 5. 月次運用報告
当月の障害、復旧訓練、定期点検を一括した検証ハッシュ付きJSONを出力します。

## 権限
登録、状態変更、完了確認、訓練・点検記録の操作権限は以下に限定します。

- 事業所管理者
- 管理者

事業所管理者は所属事業所、管理者は全事業所を対象とします。

## 本番運用上の注意
ブラウザ内保存は試験・開発用途です。本番環境では、障害・訓練・点検記録を社内APIおよびPostgreSQLへ保存し、サーバー側でも権限制御と監査記録を実施してください。
