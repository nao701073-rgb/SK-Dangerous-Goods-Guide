# Part 225 任意利用・利用履歴取扱方針

## 1. 基本方針

本システムの利用は各利用者の任意判断による。利用の有無、利用回数または利用頻度そのものを、問題行動、警告対象、是正対象、人事評価または業務評価の根拠として扱わない。

## 2. 利用履歴を使用できる目的

- 情報漏えいその他の不適切利用の確認
- アカウント・認証・権限に関するセキュリティ確認
- 障害、不具合、同期不良等の調査
- 機能改善、操作性改善、システム容量計画等の運用改善
- 法令・社内規程に基づく監査

## 3. 禁止する取扱い

- 未使用または低頻度利用を理由とする警告、是正要求または利用者評価
- 利用回数による個人間の順位付け
- 利用頻度を勤務成績、人事評価または業務量の評価へ転用すること
- 正当な目的なく利用者別履歴を閲覧すること

## 4. 画面上の取扱い

期間内に利用記録がない利用者は、試験運用状況やシステム改善の参考情報としてのみ表示する。異常利用アラートには含めない。長期ログインなしの情報は、アカウント保全・権限棚卸しの参考として中立表示し、不適切利用とは判定しない。

## 5. 監査

システム管理者による利用履歴の検索・閲覧・出力も監査ログへ記録する。履歴確認時は、目的、対象範囲および必要性を明確にする。

## 6. 未実装機能

透かし表示、スクリーンショット検知、スクリーンショット追跡および画面の自動保存は、現時点では実装しない。将来追加する場合は、別途承認と運用ルールの整備を行う。
