# Part 322 更新内容

## ゲスト権限の申請番号管理メニュー非表示

- ゲストでログインした場合、ホーム画面、サイドメニュー、モバイルメニュー等にある「申請番号管理」へのリンクを非表示にしました。
- `applications.html` を参照する導線を全画面共通で判定するため、危険物検索・詳細・関連法令・関連資料などの画面でも表示されません。
- URLを直接指定した場合は、従来どおり権限制御によりアクセスを拒否します。
- 事業所利用者、事業所管理者、安全環境室長、安全環境室職員、システム管理者の申請番号管理機能は変更していません。
- 申請番号管理は、写真・簡易メモ・添付資料を補完する簡易機能として維持します。
