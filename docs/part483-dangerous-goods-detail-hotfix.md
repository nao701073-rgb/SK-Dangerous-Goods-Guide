# part483 危険物詳細表示ホットフィックス

## 修正内容

part482で追加した正式輸送品名の実寸比較候補抽出処理について、候補抽出関数を定義する前に呼び出していたため、危険物詳細画面のJavaScript実行が停止し、詳細本文が空白になる不具合が発生していました。

part483では候補抽出処理を関数宣言へ変更し、初期化順序に依存せず危険物詳細を描画できるよう修正しました。

## 維持するpart482の変更

- 国連番号は登録値をそのまま実寸表示
- 正式輸送品名は大文字候補を抽出
- `or`・括弧による複数候補を選択可能
- 包装原文表の外装容器列と許容容量・許容質量列を分離
- P002基準の配色・罫線・余白
