# Part 243 完成版文書更新・統合要領

## 更新内容

現在の機能、役割、権限、運用方針を反映し、以下の7文書を更新しました。

1. システム仕様書
2. 実施要領書
3. ゲスト用使用要領書
4. 事業所利用者用使用要領書
5. 事業所管理者用使用要領書
6. 安全環境室用使用要領書
7. システム管理者用使用要領書

## 主な反映事項

- 現状約50名、将来約150名の利用規模
- ゲスト、事業所利用者、事業所管理者、安全環境室職員、安全環境室長、システム管理者の権限
- 安全環境室長は全事業所の申請番号・写真を登録・編集可能、削除不可
- 将来のシステム管理者権限移行先は安全環境室長に限定
- ユーザー設定とシステム設定の分離
- 法令PDF・構造化データの差分確認、検証、承認、公開
- 利用履歴監査、日次・週次・月次集計、管理者操作の監査
- 本システムの利用は任意
- 透かし、スクリーンショット検知・追跡、画面自動保存は未実装

## 文書の確認場所

システム設定から「文書・リリース統合管理」を開き、Part 243完成版文書の各リンクを選択します。
