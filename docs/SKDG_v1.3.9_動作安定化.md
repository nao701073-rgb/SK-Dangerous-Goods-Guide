# SKDG v1.3.9 動作安定化 Hotfix

## 修正内容

- ホーム画面で「ページが応答しません」となる重大な動作不良を修正。
- 原因は `v137-prototype-ui.js` のバージョン表記正規化と `MutationObserver` の組合せでした。
  - `Version 1.0 試作版` を既に表示している場合でも `textContent` を再設定
  - その書換えが `childList` 変更として監視される
  - 監視処理が再度バージョン表記を書き換える
  - これが連続し、ブラウザのメインスレッドを占有
- v1.3.9では同値の場合はDOMを書き換えないようにしました。
- 写真入力ボタンは `MutationObserver` で探し続ける方式を廃止し、クリックのイベント委譲に変更。
  - 後から生成された「写真から入力する」ボタンも動作します。
  - 常時DOM全体を再走査しません。
- ホーム画面では写真入力補助スクリプトを読み込まないようにしました。
- 「写真から入力する」の開閉修正、算出根拠別ウィンドウの「原典ページへジャンプ」は維持しています。
- 表示バージョンは引き続き `Version 1.0 試作版` です。
- DB移行はありません。
