# SKDG v1.3.77 — CTU支保荷重経路モデル

## 目的
実際のコンテナ固縛で多い「貨物を壁側へ寄せ、木材・パレット・横木等を介してCTU壁／フレームへ支保する」状況を、ベルト本数だけで不足判定しないよう正式な荷重経路として扱う。

## 判定方針
- 支保材とCTU受け部は直列の一つの荷重経路として扱う。
- 採用支保能力 = min（支保材側能力, CTU受け部能力）。
- 同じ支保経路に含めたCTU壁抵抗を別途加算しない。
- 直接固縛と支保は、承認された独立荷重経路・剛性条件がない限り単純加算しない。
- 従来の確認済み支保能力手入力も残す。

## 木材横木フェンス
CTU Code Annex 7 Appendix 4 の横木フェンス参考式に対応。
入力：横木本数 n、厚さ w(cm)、高さ h(cm)、自由長 L(m)。
標準例 n=6, w=5cm, h=10cm, L=2.2m で 24.35kN（Code例の24kNと丸め一致）。

## CTU受け部
- 汎用コンテナ前壁へ広く荷重分散：確認済みPを用い0.4Pを上限として評価。
- 強いフレーム／コルゲーション：Appendix 4横木フェンスの成立条件を明示確認。
- その他フレーム／受け部：図面・メーカー・承認資料等の確認済み能力を手入力。

## 安全側の扱い
荷重伝達確認がない場合は支保経路を算入しない。局部過負荷、隙間による衝撃、横木端部の支持、施工保持を現場確認する。
