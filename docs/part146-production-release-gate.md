# Part 146 本番導入・リリース判定

## 目的
本番導入前に、端末、社内API、法令データ、写真管理、権限、バックアップ、運用体制をまとめて確認し、承認記録を固定保存します。

## 判定条件
リリース承認には、次のすべてが必要です。

1. 総合診断の必須項目がすべて合格
2. 運用開始チェックリストが全項目完了
3. 本番設定スナップショットを作成済み
4. 固定後に重要設定の変更がない
5. 作成者と承認者が別人
6. 承認者が事業所管理者または管理者
7. 運用開始予定日時が登録されている

## 設定固定の対象
- 運用方式
- 社内API接続先
- 事業所ID・事業所名
- 利用者権限
- 写真枚数・容量上限
- IMDG参照表示
- 包装要件表示レイアウト

## 出力
- 総合診断JSON
- 設定スナップショットJSON
- リリース判定書JSON
- 印刷用リリース判定書

## 権限制御
承認権限は次の2区分のみです。

- 事業所管理者
- 管理者

作成者本人による自己承認は禁止します。本番では同じ制約をサーバーAPIおよびデータベースでも検査してください。

## 運用上の注意
リリース承認後に重要設定を変更した場合、設定スナップショットとの不一致が表示されます。再診断と再承認を行ってから運用を開始してください。
