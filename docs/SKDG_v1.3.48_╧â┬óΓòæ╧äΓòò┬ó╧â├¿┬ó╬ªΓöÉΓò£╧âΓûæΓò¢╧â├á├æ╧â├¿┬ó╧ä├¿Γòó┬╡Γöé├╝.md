# SKDG v1.3.48 固縛力参考算出 UI整理

## 変更内容
- 「登録済み案件から入力する」をページ上部へ移動。
- 固定見出し「③ 不足項目を確認して参考算出」を削除。
- 静的な「3ステップで算出」案内を削除。
- ヘッダー直下へ追尾する入力・確認状況バーを追加。
  - 案件・貨物
  - 固縛条件
  - 算出・登録
- 入力不足と確認必要を分けて表示。
- 不足／確認ボタンから該当入力欄へ移動可能。
- 旧「かんたん操作ガイド」の除去ロジックを強化。

## 維持する機能
- 固縛力の計算式・係数・算出結果
- 申請番号管理への登録
- 写真撮影・アップロード・写真から入力
- 写真AI候補・MSL確認補助
- 詳細設定
- v1.3.47までの権限制御・ヘッダー・スマホ表示・軽量化

## 性能方針
- MutationObserverによる画面全体監視は追加しない。
- setIntervalによる定期監視は追加しない。
- 入力/changeイベントと必要なボタン操作時だけ追尾状況を更新する。
