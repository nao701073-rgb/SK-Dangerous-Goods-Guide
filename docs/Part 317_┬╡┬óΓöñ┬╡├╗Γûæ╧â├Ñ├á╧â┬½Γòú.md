# Part 317 更新内容

## 申請番号管理の位置付けを整理

- 申請番号の正式な管理元は、社内既存システムであることをホーム画面に明記しました。
- 本システム側の申請番号管理は、参照、最低限の案件情報、関連写真、添付資料の整理に限定しました。
- 権限別ホーム画面から、申請案件の件数集計、優先確認、最近更新された案件の表示を削除しました。
- 期限超過や優先順位など、社内既存システムと重複する業務進捗管理をホーム画面で行わない構成へ変更しました。
- 権限別ホーム画面では、危険物検索、関連法令、関連資料、利用者・権限管理、本番運用への導線を中心に整理しました。
- ログイン、権限制御、表示テーマ、申請番号管理画面の既存データ形式は変更していません。
