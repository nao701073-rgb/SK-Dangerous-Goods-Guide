# SKDG v1.3.23 申請番号登録欄・開閉機能削除

申請書取込・確認画面の「申請番号管理へ登録」にあった折りたたみ式の入力欄を固定表示へ変更しました。

## 修正内容

- `details / summary` を使用した開閉操作を廃止しました。
- 画面左端に「0.」のように表示されていた開閉マーカーを削除しました。
- 「申請年度」「申請番号」「案件名（任意）」は常に表示されます。
- 入力欄を閉じたり開いたりする操作はありません。
- 既存案件へ追加する処理、新しい申請番号へ登録する処理、申請確認結果の保存内容は変更していません。

## 互換性

- DB移行なし
- 表示バージョンは `Version 1.0 試作版` のまま
