# Part 328 更新内容

## 本番ログイン・多要素認証の操作性強化

- 確認コード入力をサーバー仕様に合わせて6桁へ統一しました。
- 全角数字や空白を含む入力を半角数字へ正規化します。
- 6桁入力完了時に自動照合し、Enterキーでも確認できます。
- 確認コードの送信先メールアドレスをマスク表示します。
- 確認コードの有効期限を分・秒で表示します。
- 確認コード再送までの待ち時間を表示し、連続再送を防止します。
- 再送後は古いコードを破棄し、新しいコードと有効期限へ更新します。
- 照合処理の二重実行を防止し、失敗時は入力欄へ戻します。
- ログイン成功時の控えめなSKロゴ演出、4つの時間帯表示、権限制御は変更していません。
