# SKDG v1.3.81 三段階参考判定

## 目的
固縛力参考算出は正式な適否判定そのものではないため、未確認入力がある状態を「固縛不良」と誤認させない。

## 判定区分
- **参考上十分**: 必要条件が確認済みで、評価対象方向の評価抵抗力が方向別作用力以上。
- **要確認**: MSL、CTU/船側固縛点、貨物側取付部、STF、CTU境界の密着・荷重伝達、摩擦係数根拠、CSS適用範囲等に未確認項目がある。未確認抵抗は数値に算入しない。
- **参考上不足**: 必要条件が確認済みで、評価抵抗力が方向別作用力未満、または追加固縛が必要な状態。

## 重要方針
「要確認」は固縛不良の確定判定ではない。確認済み抵抗だけでの差分は併記するが、確認完了後に再算出する。v1.3.80で再監査したCTU Code/CSS Codeの算出式は変更しない。
