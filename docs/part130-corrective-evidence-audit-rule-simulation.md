# Part 130 アクセス監査ルールの事前シミュレーション

## 目的
監査ルールを保存する前に、過去のアクセス履歴へ候補ルールを適用し、検出件数や重要度への影響を確認します。

## 確認できる内容
- 候補ルールによる総検出件数
- 高優先度・中優先度の件数
- 現行ルールと比べて追加される所見
- 現行ルールと比べて減少する所見
- 事業所別の検出件数
- 新たに検出される主な所見

## 操作手順
1. 監査ルール設定欄へ候補値を入力します。
2. 「変更前にシミュレーション」を選択します。
3. 検出件数と事業所別影響を確認します。
4. 必要に応じて閾値を調整し、再度シミュレーションします。
5. 変更理由を入力してルールを保存します。

## 安全設計
- シミュレーションでは監査所見を登録しません。
- 現行ルールも変更しません。
- 高優先度閾値が中優先度以下の場合は実行を停止します。
- 事業所管理者は所属事業所、管理者は全事業所のアクセス履歴を対象とします。
