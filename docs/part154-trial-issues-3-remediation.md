# Part 154 試験運用課題その3への対応

## 対応概要

1. **危険物詳細の各コード原文画像ビューア改善**
   - 全面表示した原文画像に対して、任意の**拡大**・**縮小**・**100%表示**・**全体表示**を追加しました。
   - 初期表示は、画像全体が画面内へ収まる**全体表示**で開くように変更しました。
   - 拡大後は、モーダル内で**横スクロール・縦スクロール**できるようにし、詳細確認をしやすくしました。

2. **主要機能画面ヘッダー改善**
   - ホームボタン（または戻るボタン）を左端へ配置し、
     その**隣に主要機能名**が表示されるレイアウトへ調整しました。
   - 対象は `app-header` を使用している主要画面全体です。

## 主な修正ファイル

- `assets/js/detail-dashboard.js`
- `assets/css/detail-dashboard.css`
- `assets/css/style.css`

## 備考

- 原文画像の初期表示は「全体表示」です。
- 画像上での任意ドラッグ移動ではなく、**モーダル内スクロール**で位置を確認する方式です。
- キャッシュ更新のため、主要な読み込みクエリを `v=171` へ更新しました。
