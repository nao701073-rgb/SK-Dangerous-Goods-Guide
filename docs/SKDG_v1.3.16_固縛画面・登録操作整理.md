# SKDG v1.3.16 固縛画面・登録操作整理

## 対象
固縛力参考算出画面の重複操作ガイドと、申請番号管理へ登録する際の確認チェックを整理したHotfixです。

## 変更内容

### 1. 「次へ：算出」を削除
固縛材・支保条件の下部に重複して表示されていた「次へ：算出」ボタンを表示しません。
算出操作は「参考算出する／この条件で算出する」系の既存算出ボタンへ統一します。

### 2. 「かんたん操作ガイド」を削除
「1 条件入力 → 2 算出 → 3 確認 → 4 登録」と表示される重複ナビゲーションを削除します。
旧ワークフロー補助が入力操作後に再生成する場合も、ユーザー操作のタイミングで軽量に除去します。
画面全体を常時監視するMutationObserverは使用しません。

### 3. 登録前チェックを廃止
以下の表示を削除しました。

- 「入力値・強度根拠・算出結果を確認しました」チェック
- 「未確認・登録できません」等の登録前確認状態表示
- 確認者入力を登録可否の条件とする処理

申請番号・算出条件等、登録処理そのものに必要な情報が揃っていれば、チェックなしで「この算出結果を申請番号管理へ登録」を実行できます。

### 4. 登録結果の監査用情報
確認チェックを必須としない代わりに、保存する算出結果の review 情報へ `registrationConfirmationRequired:false` を保持します。
MSL・写真・原典等の各入力値や根拠情報そのものは従来どおり保存対象です。

## 維持事項
- 固縛力算出式は変更しません。
- 写真AI補助、コンテナ寸法補助、原典ジャンプは変更しません。
- v1.3.15の申請番号管理カード・詳細確認・案件削除機能を維持します。
- DBマイグレーションはありません。
- 画面表示バージョンは「Version 1.0 試作版」のままです。
