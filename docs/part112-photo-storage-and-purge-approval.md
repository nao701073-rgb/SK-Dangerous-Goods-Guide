# Part 112 写真保存容量監視・完全削除承認

## 目的
写真の保存量を可視化し、保存期間を超えた削除済み写真について、誤削除を防ぎながら完全削除できるようにします。

## 保存容量ダッシュボード
以下を事業所単位で表示します。

- 総保存量と設定上限に対する使用率
- 使用中写真の件数・容量
- 論理削除済み写真の件数・容量
- 完全削除候補の件数・削減可能容量
- 保全指定中写真の件数・容量

## 完全削除の流れ

1. 「完全削除候補」から対象写真を選択
2. 完全削除理由を入力して削除計画を作成
3. 計画作成者とは異なる管理者が承認
4. 承認済み計画を管理者が実行
5. 写真本体を削除し、監査履歴にはメタ情報を保持

## 公開・権限制御

- 計画作成は所属事業所の候補写真に限定
- 承認は事業所管理者または管理者のみ
- 作成者と承認者の同一人物指定は禁止
- 完全削除実行直前に、保全指定・保存状態を再検査
- 対象状態が変わった場合は実行を停止

## 出力
完全削除計画をJSONで出力できます。計画には対象件数、容量、申請番号、作成者、承認者、実行者、各日時を含みます。
