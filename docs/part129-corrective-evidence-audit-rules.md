# Part 129 証拠資料アクセス監査ルール管理

## 概要
証拠資料のアクセス監査で使用する検出条件を管理画面から変更できるようにしました。固定値ではなく、運用実績に応じて基準を調整できます。

## 管理対象
- 権限外アクセスの検出有無
- ダウンロード理由未入力の検出有無
- 短時間大量取得の検出有無
- 大量取得を集計する時間幅
- 中優先度の件数閾値
- 高優先度の件数閾値
- 標準の監査対象時間

## 権限
ルール変更は次の権限だけが実行できます。
- 事業所管理者
- 管理者

## 変更統制
変更時には理由の入力を必須とし、次を履歴として残します。
- 変更日時
- 変更者
- 変更理由
- 変更前のルール
- 変更後のルール

## 検出時の記録
監査所見には検出時点のルールスナップショットを保持します。後からルールを変更しても、当時どの基準で検出されたか確認できます。

## 初期値
- 集計時間：10分
- 中優先度：5件以上
- 高優先度：10件以上
- 標準監査範囲：直近24時間
