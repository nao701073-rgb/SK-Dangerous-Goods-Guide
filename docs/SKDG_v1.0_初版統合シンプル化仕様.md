# SKDG v1.0 初版統合・シンプル化仕様

## 基本方針
- 初版は「迷わず使える」「入力が少ない」「見た目が整っている」を優先する。
- 申請書確認、申請番号管理、固縛力参考算出だけを簡素化対象とする。
- 危険物検索、関連法令、関連資料、コード別画面等は機能削除しない。
- 高度な運用・監査機能は初版の現場画面へ出さない。

## 申請書確認
標準画面は取込、読取内容確認、自動確認、原本照合、登録に限定する。前回記録・差分・進捗等の追加補助UIは標準表示しない。

## 申請番号管理
案件選択、簡易メモ、基本情報、写真、添付資料を主操作とする。申請番号管理画面へ監査・是正・削除証明等の運用管理UIを並べない。

## 固縛力参考算出
「輸送条件と貨物 → 写真 → 材質・接触状態 → 参考摩擦係数 → 不足項目 → 参考算出」を標準導線とする。

写真からの補助項目：
- 固縛材の種類
- 本数・個数
- 表示MSL
- おおよその鉛直角
- 貨物／パレット材質
- 床・接触面材質
- 表面状態

参考摩擦係数は保守側の候補として扱い、認証値や試験値を自動確定しない。

## 権限
システム状態はシステム管理者だけ表示する。ユーザー設定へ高度機能ON/OFFは追加しない。

## UI
- 白＋青基調を維持。
- 主要カードは同一角丸・余白・影に統一。
- 主要ボタンは高さ42px以上を基準。
- スマートフォンは原則1列。
- 横スクロールは必要な表以外で増やさない。
