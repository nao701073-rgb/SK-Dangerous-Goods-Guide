# Part 563 申請書確認一覧・登録前最終確認

## 目的
Part 562の人確認機能を維持しつつ、危険物が多い申請でも確認対象全体を俯瞰し、必要箇所へ短い操作で移動できるようにする。

## 変更
1. 確認対象一覧
   - 要修正
   - 人確認待ち
   - 確認済み
   を状態別に表示する。
2. 各対象から危険物明細へ直接移動できる。要修正は入力欄へ、人確認待ちは確認済み操作へ接続する。
3. 全件確認・修正完了後は登録前最終サマリーを表示する。
4. 最終サマリーから既存の「申請番号管理へ登録」処理を呼び出す。登録データ形式は変更しない。

## 安全側の維持
- 規定量超過、包装要件不一致、国連番号不足等は確認済み化できない。
- P200許可、IBC/T条件、原文確認等の警告・参照情報は人確認後も表示を保持する。
- P/P200/IBC/T判定、許容容量・許容質量算定ロジックは変更しない。
