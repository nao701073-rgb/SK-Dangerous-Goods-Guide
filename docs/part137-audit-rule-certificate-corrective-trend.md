# Part 137 適用証明是正処置の再発防止・傾向分析

## 目的
監査ルール適用証明の不一致に対する個別是正だけでなく、原因分類、再発防止策、管理者レビュー、月次傾向を一体で管理します。

## 追加機能
- 原因分類の登録
- 再発防止策、責任者、レビュー期限の登録
- 登録者と別担当者による管理者レビュー
- レビュー結果「承認済み」「要見直し」の管理
- 対象月ごとの原因分類別件数と進捗集計
- 月次傾向報告JSONの出力
- 是正処置CSVへの再発防止・レビュー項目追加

## 権限
登録・レビューは事業所管理者または管理者のみ実行できます。再発防止策の登録者本人による自己レビューは禁止します。

## 月次集計
- 是正処置総数
- 再発防止策登録済み件数
- 管理者レビュー待ち件数
- 承認済み件数
- 要見直し件数
- 原因分類別件数
- 要確認種別別件数
