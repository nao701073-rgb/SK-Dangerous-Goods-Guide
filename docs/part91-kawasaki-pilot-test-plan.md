# 川崎事業所 試験運用計画

## 1. 準備

- 川崎事業所の検査員アカウントを登録する。
- 事業所管理者、安全環境室管理者、ゲスト、検証者の試験アカウントを登録する。
- 各利用者の社内メールで認証コードを受信できることを確認する。
- 検証用申請番号だけを投入し、本番記録と明確に区別する。

## 2. 限定運用

- 危険物検索、検索条件保持、申請番号、写真上限、オンライン同期を確認する。
- ゲストと検証者が申請番号・写真へアクセスできないことを確認する。
- 安全環境室が川崎事業所の登録状況を閲覧できることを確認する。

## 3. 並行運用

- 既存業務手順とシステムを並行して使用する。
- 入力時間、検索時間、記録差異、同期失敗、写真容量を記録する。
- 業務判断は従来どおり最新版の法令・規則・社内手順に基づく。

## 4. 評価

- 認証、権限、監査ログ、バックアップ、復元、TLS、性能を評価する。
- 不具合と改善要望に重大度、担当、期限を設定する。
- 安全環境室が本番移行可否を判定する。

## 中止基準

- 権限外の申請番号・写真を閲覧できる。
- 写真または申請番号が消失する。
- 同期の二重登録が継続して発生する。
- バックアップから復元できない。
- 二段階認証が迂回可能である。
