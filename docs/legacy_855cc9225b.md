# Part 380 更新内容

## 構造化データ更新センター

法令改正・データ更新管理画面に、構造化データを管理画面から更新する機能を追加しました。

- 危険物基本データ
- 標札マスター
- 包装要件
- 特別規定
- 条文リンク
- 国内法令・IMDG Code対照
- 法令登録情報
- 品名・国連番号表示基準

各区分についてCSVひな型をダウンロードできます。CSVまたはJSONをアップロードすると、必須列、必須値、識別キー重複、国連番号形式などを検証します。検証後は更新候補として保存し、PDF原文・版番号・適用開始日との照合確認後に承認済みデータとして反映します。

ローカル運用では反映データをブラウザの端末内ストレージに保存します。複数端末で共有する正式運用では、サーバー側の承認・公開処理へ移行してください。
