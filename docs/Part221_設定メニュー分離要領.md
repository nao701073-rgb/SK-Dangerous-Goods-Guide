# Part 221 設定メニュー分離要領

## 変更内容

ホーム画面のメニューを次の2項目に分離した。

- ユーザー設定：すべての認証済み利用者に表示する。
- システム設定：事業所管理者、安全環境室長、システム管理者にだけ表示する。

システム設定URLへの直接アクセスについても、既存の役割判定により権限のない利用者を拒否する。

## 表示対象

| 役割 | ユーザー設定 | システム設定 |
|---|---:|---:|
| ゲスト | 表示 | 非表示 |
| 事業所利用者 | 表示 | 非表示 |
| 事業所管理者 | 表示 | 表示 |
| 安全環境室長 | 表示 | 表示 |
| 安全環境室職員 | 表示 | 非表示 |
| システム管理者 | 表示 | 表示 |
