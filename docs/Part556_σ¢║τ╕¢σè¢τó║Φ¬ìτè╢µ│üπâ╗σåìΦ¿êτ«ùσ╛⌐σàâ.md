# Part 556 固縛力確認状況・再計算復元

## 1. 登録済み詳細
申請番号詳細の「固縛力算出」タブで、最新版の確認状況を先に表示する。

表示項目：
- 判定
- 最厳方向の余裕・不足
- 確認事項数
- 確認者
- 確認日時

要確認が残る場合は、1操作で最新版の方向別結果・取付点・確認事項を展開する。

## 2. 再計算
登録済み結果から再計算する場合、Part 555の変更項目表示を維持し、編集途中でも読み込み時点の条件へ戻せる。

- ボタンには前回からの変更項目数を表示する。
- 復元後は登録前確認を再度実施する。
- 過去結果は削除せず、再登録結果は新しい履歴として保存する。

## 3. 非変更範囲
- CTU/CSS計算式
- MSL最小値判定
- 方向別必要抵抗力
- 摩擦計算
- 支保併用
- 保存データ構造
