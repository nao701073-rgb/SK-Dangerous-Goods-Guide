# 認証・権限セキュリティ確認票

- ログインIDの大文字小文字を区別せず一意に管理できる。
- パスワードはハッシュ化され、平文で保存・記録されない。
- 二段階認証コードはハッシュ化され、有効期限と試行回数がある。
- 認証コード再送に待機時間がある。
- ログイン失敗時にアカウント一時ロックが機能する。
- ゲストは申請番号・写真APIを利用できない。
- 検証者は検証記録以外の更新APIを利用できない。
- 検査員は所属事業所以外のデータを閲覧できない。
- 安全環境室だけが全事業所を横断閲覧できる。
- 利用者登録、認証、変更、無効化が監査ログに記録される。
- SMTP、JWT、DBパスワードは環境変数で管理される。
- HTTPS以外の本番アクセスを許可しない。
