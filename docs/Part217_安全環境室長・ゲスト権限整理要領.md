# Part 217 安全環境室長・ゲスト権限整理要領

## 1. 安全環境室長
- ユーザー設定に加え、システム設定画面を表示する。
- 全事業所の申請番号・関連写真を閲覧できる。
- 現時点では全体設定の変更、申請・写真の登録・編集・削除はできない。
- 将来のシステム管理者権限移行先は安全環境室長に限定する。

## 2. ゲスト
- 事業所利用者とは別の独立した役割とする。
- 所属事業所を持たない。
- ユーザー設定だけを利用できる。
- 危険物検索、申請番号、写真、関連法令、関連資料、履歴、管理画面にはアクセスできない。
- ホーム画面ではユーザー設定への案内だけを表示する。

## 3. 登録用ロールコード
- 安全環境室長: `safety-environment-director`
- ゲスト: `guest`
