# Part 204 変更概要

本版では、ログイン機能の試験運用に必要な改修を一括して実施しました。

- 初回ログイン日時の記録
- 初回パスワード変更の標準化
- 役割別MFA基準の一括適用
- アカウント有効期限の判定
- 未ログイン、ロック、MFA未設定、90日以上未使用の一覧化
- 利用者ごとのセキュリティ基準適用と点検記録
- セキュリティ操作履歴の保存
- 約50名から将来150名を想定した管理画面
- 試験運用準備要領の追加
- 旧「社内サーバー」構築手順書の削除
