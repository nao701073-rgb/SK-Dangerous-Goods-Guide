# SKDG v1.3.89 備考欄重量の危険物カード自動反映

## 背景
社内既存システムでは危険物重量を整数でしか入力できないため、小数を含む正味重量・総重量を備考欄へ記載する運用があります。

## 対応
備考欄から以下のような構造化記載を抽出します。

- `UN1954 正味重量:14.988(Kg) / 総重量:1,829.988(Kg)`
- `UN1956 正味重量:12.200(Kg) / 総重量:67.200(Kg)`

国連番号が一致する危険物明細にのみ反映します。

## 反映項目
- 申請総正味質量 N/W
- 申請総質量 G/W
- 個数が存在する場合は1容器当たりN/W
- 個数が存在する場合は1容器当たりG/W

## 優先順位
同一UN番号について備考欄に重量が明記されている場合は、表側の0または整数重量より備考欄の小数値を優先します。取込後の手動修正は可能です。

## 誤取込防止
国連番号と「正味重量/正味質量/NW」「総重量/総質量/GW」が同じ記載ブロックに存在する場合だけ重量として採用します。
