# Part 220 権限・承認・削除申請管理要領

## 目的
役割別の操作権限、削除申請、権限変更申請、承認履歴、定期棚卸しを一元管理する。

## 運用原則
- 安全環境室長は全事業所の申請番号・写真を登録・編集できるが、削除はできない。
- 削除が必要な場合は削除申請を作成し、システム管理者が承認する。
- システム管理者への権限移行先は安全環境室長に限定する。
- 権限変更と削除判断は監査ログへ記録する。
- ゲストは危険物検索、関連法令、関連資料、ユーザー設定のみ利用できる。

## 定期点検
50名での試験運用時は月次、150名規模では少なくとも四半期ごとに権限棚卸しを実施する。
