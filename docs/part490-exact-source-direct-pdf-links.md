# part490 コード詳細の原典準拠表示とPDF直接参照

## 表示仕様

- 「○○該当原文」カードは維持する。
- カード内には、危告示等の原典に記載された表、一覧、注記、追加規定を整理して表示する。
- 原典の文章、数値、単位、記号、括弧、対象国連番号は、要約・言い換え・簡略化しない。
- 原典にない解釈や補足説明は追加しない。
- 国内法令原文テキストAI要約はコード詳細カードから削除する。
- PDFページ画像、OCR形式の原文本文、原文テキストの再表示は行わない。

## 原典リンク

- 危告示、危規則、IMDG Codeの各ボタンは、中間表示画面を使用せず、PDFファイルの該当ページへ直接リンクする。
- 危告示のコード掲載ページは、登録済み原文データと原典PDFを照合する。
- IMDG Codeは、MSC.556(108)／Amendment 42-24 PDF内でコードが実際に掲載されているページをコード別に登録する。
- PDF内に該当コードを確認できない場合は、誤ったページやPDF先頭ページへの代替リンクを表示しない。

## P001・P002

- 既存の容器等級別の許容容量・許容質量表を維持する。
- 表の下へ、原典に記載された適用条件、注記、追加規定を原文のまま表示する。
- P001のPP1、PP2、PP4、PP5、PP10、PP31、PP33、PP81、PP93等を欠落させない。
- P002の肩文字に関する注記及び追加規定も同じ方法で表示する。

## 対象

P、LP、IBC、T、TP、BK、PP、B、SW、SP、SG等、危険物詳細から開ける登録済みコードへ共通適用する。VV、CV、V、S等は、原典データが登録された時点で同じ共通表示処理が適用される。

## 画面調整

- PCでは、表の横幅を確保し、原典リンクを2列で配置する。
- スマートフォンでは、表を画面幅内で折り返し又は必要に応じて横スクロールできるようにし、原典リンクを縦1列の全幅ボタンとして表示する。
- 色、フォント、罫線、余白は既存の危険物詳細画面の様式を維持する。
