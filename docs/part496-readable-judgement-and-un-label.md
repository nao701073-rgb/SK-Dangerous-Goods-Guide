# part496 判定基準の見やすさ・国連番号表記 改修記録

## 対象

登録済み危険物2,725行、国連番号2,248件のすべてを対象とする。

## 判定基準の表示

判定基準の法令本文を1文ずつ同じ表の行へ分割する方式を廃止し、次の情報単位で整理する。

1. 対象危険物の国連番号、分類・項目、等級、容器等級
2. 判定の原則
3. 判定条件と判定結果の対応表
4. 要件・条件
5. 例外・注記
6. 試験方法・数値条件
7. 原文参照リンク

PCでは原則として表形式を使用し、スマートフォンでは縦並びへ切り替える。横スクロールは発生させない。法令文言、数値条件、例外及び試験方法は省略・改変しない。

## 国連番号表記

国内法令関連画面の日本語UIでは、次のように統一する。

- 修正前：UN1123 判定基準の国内法令
- 修正後：国連番号1123 判定基準の国内法令

同じ変更を標札表示の国内法令、品名・国連番号表示の国内法令、関連国内法令、判定基準の参照ラベルへ適用する。法令原文、IMDG Code原文及び英語正式品名に含まれるUN表記は変更しない。

## デザイン

既存の色、フォント、罫線、角丸及び余白を維持する。
