# Part 200 管理者権限移行後の安定稼働・完了管理

## 目的

安全環境室長へシステム管理者権限を付与した後、直ちに旧管理者の権限を削除せず、安定稼働確認、支援期間、移行完了、旧管理者の権限縮小を段階的に記録する。

## 運用フロー

1. 正式切替後、安全環境室長が新しい権限で再ログインする。
2. ログイン、権限、監査ログ、バックアップ、法令更新、障害対応を確認する。
3. 「安定稼働確認」を1回以上記録する。
4. 旧管理者の移行支援期間終了後、安全環境室長本人が再認証して移行完了を確定する。
5. 移行完了後、利用者管理で旧管理者の権限を必要最小限へ変更する。
6. 変更後の権限、実施者、確認日を移行履歴へ記録する。
7. 以後、少なくとも90日ごとに管理者権限と監査状況を点検する。

## 安全制御

- 移行完了操作は移行先となった安全環境室長本人に限定する。
- 支援期間が終了していない場合は完了できない。
- 安定稼働確認が未記録の場合は完了できない。
- 旧管理者の権限は自動削除しない。利用者管理で変更し、別途確認記録を残す。
- 緊急復旧用アカウントは通常利用せず、利用時は監査記録を残す。

## データベース

`server/sql/058_admin_succession_completion.sql` により、移行完了情報、旧管理者権限縮小期限・確認情報、安定稼働点検履歴を保存する。
