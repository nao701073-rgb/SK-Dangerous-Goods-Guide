# SKDG v1.3.25 軽量化 第2段階

## 目的
v1.3.24で行った重複ストレージ読込削減に続き、案件数増加時の一覧処理と、画面起動・操作時の不要処理をさらに削減します。

## 変更
- 申請番号管理: applications/photos/documents/resultsを1回取得後、applicationId単位のMapへ索引化。
- 申請番号管理: 登録内容バッジの件数算出で毎カード全配列をfilterする処理を廃止。
- 申請書確認: XLS/XLSXを選択した時だけSheetJSを動的読込。CSVはブラウザ標準機能で直接解析。
- 固縛力参考算出: 初回の互換UI除去後、通常操作時は既知の旧UI要素だけを確認。

## 非変更
計算式、危険物判定、国内法令参照、権限、保存データ形式、DB構造は変更しません。
