# SKDG v1.2 画面整理・現場操作短縮

## 1. 目的
v1.1のシンプル操作を維持し、完了した情報を自動的に目立たなくして、利用者が現在行う操作に集中できるようにします。新しい管理ワークフローは追加しません。

## 2. 申請書取込・確認
申請書読込後は取込欄をコンパクト表示します。自動確認が完了し登録可能な場合は読取内容欄もコンパクト化します。利用者は「別の申請書を選ぶ」「読取内容を再確認」からいつでも戻れます。登録条件が再び未成立になった場合は、自動で通常表示へ戻します。

取込後の危険物明細は、PCではカード内スクロール、スマートフォンでは危険物単位のカード表示を維持します。既存の判定・登録可否ロジックは変更しません。

## 3. 申請番号管理
通常利用では、登録済み案件と選択中案件の簡易メモ・操作を中心に表示します。添付資料・関連写真の登録欄は「写真を追加」「添付資料を追加」を押した場合だけ開きます。確認・算出結果も必要時のみ展開します。

案件データ、写真、添付資料、確認結果の保存形式は変更しません。

## 4. 固縛力参考算出
申請書読込→輸送条件・貨物→写真→AI候補→材質・接触状態→参考摩擦係数→不足項目→参考算出の順番を維持します。

AI候補は個別選択のみとし、一括全選択を廃止します。選択件数を表示し、選んだ候補だけを既存入力へ反映します。反映後は材質・接触状態へ移動します。写真だけでMSL・安全性を確定しません。

## 5. ユーザー設定
「写真撮影後、AI候補へ自動で移動」を追加します。既定はONです。画面の機能そのものを増減する設定ではありません。

## 6. 維持事項
危険物検索・危険物詳細・関連法令・IMDG参照・原文表示・関連資料・P/LP/IBC/T/TP/BK/PP/B/VV/CV/V/SW/S/SP等のコード画面・オーバーパック表示用作成・検索履歴は削除しません。危険物判定、許容容量・許容質量、固縛計算式、申請番号データ構造、写真・添付保存構造も変更しません。
