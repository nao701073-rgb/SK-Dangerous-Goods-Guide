# Part 269 更新内容

## 申請番号管理の表示設定・保存条件

- 申請一覧の検索条件、年度、進捗、並び順をユーザーごとに保存できる「保存した表示条件」を追加。
- 保存した条件は選択するだけで再適用でき、不要になった条件は削除可能。
- 申請カードの表示項目をユーザーごとに選択可能。担当者、コンテナ番号、船名・航海番号、危険物情報、写真・資料件数、更新日時を個別に表示・非表示。
- 表示設定はブラウザ内に保存し、次回表示時も維持。
- 未入力項目は引き続き表示せず、案件ごとに得られた情報だけを確認できる構成を維持。

## 危険物検索・等級プルダウンの統一

- 等級欄下部の「類別をまとめて検索では、等級4・5・6の各区分を一括検索できます。」という補足表示を削除しました。
- 等級プルダウンの optgroup（「類別をまとめて検索」「個別等級」）を廃止し、他の検索条件と同じ通常のプルダウン形式へ統一しました。
- 4・5・6の一括検索機能および4.1～4.3、5.1～5.2、6.1～6.2の個別検索機能は維持しています。
