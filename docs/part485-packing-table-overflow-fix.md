# part485 包装要件表の列分離・はみ出し修正

## part484の確認結果

- 国連番号と正式輸送品名は同一フォント、同一ウェイト（800）で表示される。
- 12mm／6mm、通常画面／横画面実寸比較へ共通適用される。
- 実寸比較欄の固定高さと最大高さは解除され、長い品名に応じて表示領域が伸長する。
- 長い品名は枠内で折り返され、縦スクロール・下切れを防止する。

## part485の追加修正

- 包装要件の「容器の種類」と「許容容量又は許容質量」を明確に別列化。
- P002等の `60～400kg（型式による）` のような長い値をセル内で自然に折り返す。
- 数量・単位が外装容器欄へ混入しないよう、内装容器表・外装容器表に専用の列構造を付与。
- PCでは2表を左右表示、スマートフォンでは縦並び表示。
- 原文表の第4列にも共通の折返し規則を適用。
- P・LP・IBC等、同じ共通描画処理を使うすべての包装要件コードへ適用。
