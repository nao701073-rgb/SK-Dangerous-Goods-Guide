# SKDG v1.3.55 固縛力番号カード統一・誤緑表示修正

- 固縛力参考算出の番号付き入力・確認カードを、③「輸送条件と貨物を確認」の様式へ統一。
- ①申請書、②写真、③輸送条件・貨物、④固縛・支保条件、⑤互換番号カード、⑥参考算出で、番号丸・見出しフォント・背景・罫線・角丸・余白を共通化。
- ①の上に前カードの枠が残って見える余白／上端表現を解消。
- 旧「入力ミス防止チェック／基本条件は入力済み」の固定緑表示を廃止し、追尾ステータスを唯一の進捗表示とする。
- 実際の登録イベントがない状態で旧「登録が完了しました」表示が出た場合は抑止。
- 算出・写真AI・申請書取込・MSL・登録ロジック自体は変更しない。
