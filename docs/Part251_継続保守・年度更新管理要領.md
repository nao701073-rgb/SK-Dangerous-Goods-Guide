# Part 251 継続保守・年度更新管理要領

## 1. 目的
運用引継ぎ後も、管理責任、定期保守、法令・データ更新、障害・問い合わせ、年度更新、次期版計画を継続的に確認できるようにする。

## 2. 確認場所
`システム設定 → 開始・受入・定着 → 継続保守・年度更新管理`

## 3. 定期保守
利用者・権限、認証、バックアップ、復元、監査、法令改定、データ品質、性能、文書、問い合わせ・障害を定期的に確認する。

## 4. 法令更新
法令名、旧版・新版、施行日、差分、検証、承認、公開結果を記録する。PDF差し替えだけで本番データを無条件に更新しない。

## 5. 年度更新
年度総括、未完了事項、次年度責任者、次期版、次回点検日を記録する。

## 6. 判定条件
「継続運用可」以降は全点検項目の完了と重大障害0件を必要とする。「次期版準備完了」は次期版名称と主要内容の入力を必要とする。

## 7. 現行方針
本システムの利用は任意です。透かし表示、スクリーンショット検知・追跡、画面自動保存は現時点では実装しない。
