# v1.3.39 固縛力参考算出 サブメニュー修正

## 原因
`ctu-securing-calculator.html` の共通ヘッダースクリプト参照が、MSL確認報告書を生成するJavaScriptテンプレート文字列内に誤って配置されていた。このため固縛力参考算出の本画面では `v1338-common-header.js` が実行されず、サブメニューボタンへクリックイベントが登録されなかった。

## 修正
- 誤配置されたスクリプト参照を報告書テンプレートから削除。
- 共通ヘッダースクリプトを固縛力参考算出本画面のメインインラインスクリプト終了直後へ配置。
- v1.3.38のヘッダー表示・利用者表示・権限制御・軽量化仕様は維持。
