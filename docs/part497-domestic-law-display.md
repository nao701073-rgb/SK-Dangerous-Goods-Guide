# part497 国内法令表示修正

## 対象

登録済みのすべての危険物に共通して表示される「正式輸送品名・国連番号表示」欄を対象とします。

## 修正内容

- 見出しを「国内法令・IMDG Codeの主な参照」から「国内法令の主な参照」へ変更しました。
- IMDG Code 5.2.1.1を参照一覧及び文字高さ見出しから削除しました。
- 国内法令は次の3項目だけを表示します。
  - 危規則 第8条第1項・第9条
  - 危告示 第7条の3第1項・第2項
  - 危告示 第14条の2の2（オーバーパック表示）
- ボタン文言を「該当する国内法令を全画面で続けて表示」へ変更しました。
- ボタンを押した際は、外部の法令PDF全体やタブ切替画面を開かず、上記条文だけを整形した結合PDFをシステム内の全画面表示で連続して確認できます。
- スマートフォンでは、結合PDFと同じ内容を縦長の連続画像で表示します。
- 概要と重複していた「国内法令（主表示）」「国内法令の主な参照」及び積載方法の「表示まとめ」を削除しました。
- 危告示 第7条の3及び第14条の2の2の原文PDFページ対応を修正しました。

## デザイン

既存の色、フォント、罫線、角丸及び余白を維持しています。
