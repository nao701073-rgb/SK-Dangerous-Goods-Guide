# Part 133 監査ルール変更申請の担当者再割当・管理者引継ぎ

## 概要
承認待ちまたは適用待ちの監査ルール変更申請について、担当者不在や期限超過で処理が停滞しないように、担当者再割当と管理者引継ぎを追加しました。

## 担当者再割当
- 対象: 承認待ち、承認済み、予約適用待ち
- 新しい担当者と再割当理由を必須記録
- 変更前担当者、変更後担当者、変更者、変更日時を履歴保存
- 再割当後は通知を未確認状態へ戻す

## 管理者引継ぎ
- 承認期限または適用期限を超過した申請のみ対象
- 引継ぎ理由を必須記録
- 担当者を「管理者」へ変更
- 引継ぎ実行者、実行日時、理由を保存

## 権限
操作できるのは事業所管理者または管理者のみです。自己承認禁止など既存の承認統制は維持します。
