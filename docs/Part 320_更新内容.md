# Part 320 更新内容

## 申請番号補完機能のクイック操作化

申請番号管理を、社内既存システムに不足する補完情報の登録へさらに集中させた。

### 主な変更

- 画面の初期表示を「申請番号に補完情報を追加」へ変更
- 申請番号を選択し、簡易メモを直接保存できるクイック操作を追加
- 選択中の申請番号を引き継いで、写真登録・添付資料登録へ移動可能
- 新規登録、登録済み情報、写真、資料の導線を簡潔に整理
- 進捗状況や担当者などは詳細項目へ移し、通常操作では表示しない
- 一覧検索を申請番号・メモ中心に簡素化
- 並び順、保存条件、CSV等は「詳細な絞り込み」に収納
- 既存データ、写真、添付資料、権限制御との互換性を維持

## 運用方針

本機能は正式な申請管理を代替せず、写真・メモ・添付ファイルを簡単に紐付ける補完機能として運用する。
