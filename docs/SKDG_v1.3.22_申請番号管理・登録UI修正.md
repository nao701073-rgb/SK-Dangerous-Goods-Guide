# SKDG v1.3.22 申請番号管理・登録画面表示修正

## 1. 申請番号管理カードの「詳細」ボタン
カード左下の詳細ボタンが白い空欄として表示される事象を修正しました。

- ボタン文言を常に「詳細を開く」と再設定します。
- CSS側でも「詳細を開く」を表示する保険を入れ、汎用ボタンCSSの上書きで文字だけ消える状態を防止します。
- 押下先は従来どおり `application-detail.html?applicationId=...` です。

## 2. 申請書確認の申請番号登録画面
固縛力参考算出の登録表示を基準に統一しました。

表示順:
1. 申請番号管理へ登録
2. 登録先
3. 「未登録の案件として申請番号を入力」
4. 申請年度・申請番号・案件名（任意）
5. 「この確認結果を申請番号管理へ登録」
6. 登録後のみ「登録した申請を詳細確認」

申請書から取得した年度・番号は候補として反映し、利用者が登録直前に変更できます。
同じ年度・申請番号が既存の場合は新しいカードを作らず、同じ案件カードへ申請確認結果を追加します。

## 3. 空欄四角ボタンの修正
旧処理用の `intakeRegisterNew` / `intakeUpdateExisting` はHTML上では hidden でしたが、既存CSSの影響で白い空欄ボタンとして表示される場合がありました。
今回 `display:none !important` を指定し、確実に非表示にしています。

## 4. 維持する仕様
- 申請確認と固縛力参考算出は同一申請番号・同一案件カードへ登録可能。
- 申請詳細では「申請確認・許容容量／質量」と「固縛力参考算出」を別タブで確認可能。
- 原本照合者は任意で空欄登録可能。
- DBマイグレーションなし。
- 画面表示バージョンは「Version 1.0 試作版」のまま。
