# Part 538 申請確認表示・固縛力併用・MSL写真確認

## 1. 目的

Part 538では、申請書確認と登録後の再確認画面について、利用者が比較しやすい一覧表形式を維持する。また、固縛力参考算出について、現場で多い引張系固縛材と支保・当て材の併用、海上輸送の初期選択、固縛材・取付部のMSL確認支援、鉄道輸送用TY-GARD、写真証跡へ対応する。

## 2. 申請書確認・登録後再確認

表示順は次のとおりとする。

1. No.
2. 国連番号
3. 品名・原文
4. 容器等級
5. 容器コード
6. 申請数量
7. 許容容量・許容質量

申請数量欄には、個数、1容器当たり正味質量・総質量、申請総正味質量・総質量をまとめて表示する。PCでは一覧表、スマートフォンでは同じ情報順のカード表示とし、横スクロールを必要としない。

## 3. 引張系固縛材と支保・当て材の併用

「使用方法」に次を設定する。

- 引張系固縛材
- 支保・当て材
- 引張系固縛材＋支保・当て材（併用）

併用時は、引張系固縛材と支保・当て材の寄与を別々に入力・表示する。荷重分担、作用方向、接触状態を確認した場合だけ、承認された方法として両者を加算する。確認されていない場合は、剛性の異なる拘束を単純加算せず、保守的に強い方を採用する。

## 4. 輸送条件の初期値

新規算出時は「海上輸送 海域B（標準）」を初期値とする。登録済み案件を再表示する場合は、保存済みの輸送条件を優先する。道路・鉄道・他海域への変更は引き続き可能とする。

## 5. 材質・サイズからのMSL候補

次の3区分について候補値を表示する。

- 固縛材1本当たりMSL
- 貨物側取付部MSL
- CTU側固縛点MSL

候補値は入力補助であり、確定値ではない。優先順位は、メーカー仕様、刻印・証明書、承認された試験結果、参考候補の順とする。貨物側・CTU側の取付部は、材質や断面寸法だけでは溶接、局部強度、荷重方向、取付状態を評価できないため、図面・表示・試験・メーカー確認値がある場合だけ反映する。

## 6. TY-GARD鉄道ラッシング

固縛材に「TY-GARD（鉄道ラッシング）」を追加する。TY-GARD DS 60 cm幅について、日本総代理店の商品資料に示される鉄道輸送時の耐荷重8 tonを参考情報として登録する。ただし、耐荷重表示をそのままMSLと確定しない。

反映条件は次のとおり。

- 輸送条件が鉄道輸送または鉄道輸送（短時間衝撃）であること
- 参考マスターだけでは反映できず、メーカー仕様書、刻印・表示、試験成績・承認資料のいずれかを確認すること
- 製品型式、幅、貼付長さ、接着面、施工配置、温度・施工手順、輸送モードを照合すること

参照先：

- TY-GARD日本総代理店 商品一覧: https://webciss.sankyu.co.jp/portal/ty-gard/asp/newsitem.asp?nw_id=1076
- TY-GARD公式: https://ty-gard.com/

## 7. 貨物側・CTU側取付点の写真確認

スマートフォンのカメラまたは保存済み画像から、貨物側取付部・CTU側固縛点の写真を読み込める。

写真機能は次の用途に限定する。

- 刻印、定格、メーカー名、型式の確認
- 図面・メーカー仕様との照合補助
- 確認済みMSLの入力・反映
- 選択中の申請番号への案件写真登録

画像のみから強度を自動確定しない。確認MSLと刻印・表示内容の入力を必須とし、画像は端末内でJPEGへ変換・縮小し、GPS情報を保持しない。算出結果には画像本体ではなく、ファイル指紋、寸法、刻印・表示、確認値等のメタデータを保持する。案件写真へ登録する場合は既存の写真保存上限・権限・監査・同期ルールを使用する。

## 8. 既存計算の維持

CTUコード・CSS Codeの既存計算関数、弱点となるMSLの最小値採用、摩擦、壁・支保、直接固縛、トップオーバー、転倒評価は維持する。Part 538の変更は、併用条件の追加、入力補助、確認証跡、表示改善を中心とする。
