# 運用管理手順書

## 日次確認
- APIヘルスチェック
- PostgreSQLと写真保存領域の空き容量
- 同期エラーと競合件数
- アカウントロック状況
- バックアップ成否

## 月次確認
- TLS証明書の残存期間
- 事業所別の写真枚数・容量
- 無効利用者と異動者の権限
- 監査ログの異常操作
- 復元試験

## アカウント管理
- 利用者は所属事業所を必須とします。
- 安全環境室管理者のみ全事業所を閲覧できます。
- 退職・異動時は速やかに無効化します。
- ローカル認証時は12文字以上、英大文字・小文字・数字・記号を必須とします。
- 初期パスワードは初回ログイン時に変更します。

## 写真管理
- 1申請番号、1事業所、1ファイル、総容量の各上限を設定できます。
- 上限変更は安全環境室管理者が実施し、監査ログへ記録されます。
- 削除は論理削除を基本とし、物理ファイル消去は保存期間経過後に管理作業として実施します。

## 同期競合
同じ申請番号を複数端末で更新した場合、バージョン番号が一致しなければ競合として返します。利用者はサーバー最新版を再取得し、必要な内容を統合して再保存します。同一同期IDの再送は二重登録せず、以前の結果を返します。

## 障害時
1. 新規登録を一時停止
2. API、DB、保存領域の状態確認
3. 直近バックアップの確認
4. 復元が必要な場合は復元手順書に従う
5. 復旧後に整合性確認を実行
6. 影響範囲と対応を監査記録へ残す
