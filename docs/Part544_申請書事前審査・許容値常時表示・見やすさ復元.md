# Part 544 申請書事前審査・許容値常時表示・見やすさ復元

## 1. 修正目的
Part 543で許容容量／許容質量の判定処理を追加したが、Excel取込時に「容器等級」の列を「容器コード」と誤認する場合があり、容器コードが `II` 等となって許容値を取得できないケースがあった。Part 544では列判定を修正し、以前の公開版／Part 536の確認画面に近い視認性へ戻す。

## 2. 容器コード取込修正
- 列名は完全一致を優先する。
- 「容器等級」と判定した列を「容器コード」へ重複使用しない。
- 容器コード列が特定できない場合は、行内から `1A1`、`1A2` 等の容器コード形式を補助探索する。
- `I`、`II`、`III` は容器コードとして採用しない。

例：UN1133、容器等級IIの場合
- 1A1 → 許容容量 450L
- 1A2 → 許容容量 250L

## 3. 事前審査表示
各危険物No.の編集カード上部に確認帯を固定表示し、次を最優先で強調する。
- 個数
- 1容器当たり正味質量
- 許容容量・許容質量

補助表示として、1容器当たり総質量、申請総N/W、申請総G/W、容器等級、容器コードを同じ確認帯内に表示する。編集フォーム自体は維持する。

## 4. 判定ルール維持
- 同一単位で規定量を超過：`規定量超過・要確認`
- Lとkgは自動換算しない。数値差が±20%以内のときだけ：`容量比較 要確認`
- 少量危険物：内装容器上限と外装容器1個当たり総質量30kg以下を従来どおり別判定
- 4G等の組合せ容器は、少量危険物以外では現物の容器性能表示・条件を確認

## 5. レスポンシブ
PCでは重要3項目を横並び、スマートフォンでは縦並びとし、横スクロールを使わず確認できる。
