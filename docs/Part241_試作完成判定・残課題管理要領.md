# Part 241 試作完成判定・残課題管理要領

## 1. 目的

試作版として完成させる範囲と、クラウド配置先の決定後に実施する作業を明確に分離し、完成判定が外部契約や実利用者情報の未確定によって曖昧にならないようにする。

## 2. 試作完成の必須条件

- メニュー・画面構成
- ログイン・役割別権限
- 主要業務機能
- 危険物・法令データ品質
- 法令・データ更新
- 利用履歴・監査
- 保全・障害対応
- 総合自動検査
- 仕様書・要領書

すべて完了した場合にのみ「試作完成」を選択できる。

## 3. 配置先決定後の作業

- クラウド配置先
- URL・HTTPS・CORS
- 認証メール
- 初期利用者約50名の登録
- 50名・150名想定の性能試験
- 写真保存・復元試験
- 実端末確認
- 職制承認・利用者周知

これらは試作完成判定とは分離して記録する。

## 4. 現行方針

- 本システムの利用は任意とする。
- 透かし表示、スクリーンショット検知・追跡、画面自動保存は現時点では実装しない。
- 利用履歴は、不適切利用の確認、セキュリティ、障害調査、運用改善、正当な監査に限定する。
- 安全環境室長は全事業所の申請番号・写真について閲覧、登録、編集が可能で、削除は不可とする。
