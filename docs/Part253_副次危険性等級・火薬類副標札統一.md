# Part 253 副次危険性等級・火薬類副標札統一

## 変更内容

- 火薬類が副次危険性となる場合は、区分1.1～1.6を個別表示せず、数字「1」の共通副標札1種類を表示します。
- 主危険性の火薬類は、従来どおり等級1.1～1.6を区別します。
- 詳細検索の「副次危険性等級」プルダウンは、実在する次の選択肢だけに統一しました。
  - 1 火薬類
  - 2.1 引火性高圧ガス
  - 3 引火性液体類
  - 4.1 可燃性物質
  - 4.2 自然発火性物質
  - 4.3 水反応可燃性物質
  - 5.1 酸化性物質
  - 6.1 毒物
  - 8 腐食性物質
- 副次危険性等級の選択肢から、2 高圧ガス、2.2、2.3、5.2、6.2、7、9を削除しました。
- 複数の副次危険性等級は `3/6.1` のようにスラッシュ区切りで表示します。
- UNデータ全件の `subsidiaryRisk` を正規化し、SP番号、注記番号、頁番号が副次危険性等級として表示されないようにしました。
- 検索結果、詳細画面、簡易詳細、標札解決処理、CSV出力で同じ規則を使用します。
