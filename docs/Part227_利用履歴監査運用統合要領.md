# Part 227 利用履歴監査運用統合要領

## 1. 目的
利用履歴の確認、異常利用候補への対応、保存期間管理および定期監査レビューを一つの画面で管理する。

画面上の利用に関する表示は、次の一文に統一する。

> 本システムの利用は任意です。

## 2. 管理対象
- ログイン・認証
- 危険物検索・詳細
- 関連法令・関連資料
- 申請番号・写真
- ユーザー設定・システム設定・管理操作

## 3. 定期監査レビュー
日次・週次・月次の集計を確認し、「確認済み」「継続確認」「管理対応へ移行」のいずれかを記録する。警告候補だけで不適切利用と断定しない。

## 4. 権限
本機能はシステム管理者だけが利用できる。履歴検索、レポート出力、レビュー保存も監査ログへ記録する。

## 5. 未実装機能
透かし表示、スクリーンショット検知・追跡および画面自動保存は現時点では実装しない。
