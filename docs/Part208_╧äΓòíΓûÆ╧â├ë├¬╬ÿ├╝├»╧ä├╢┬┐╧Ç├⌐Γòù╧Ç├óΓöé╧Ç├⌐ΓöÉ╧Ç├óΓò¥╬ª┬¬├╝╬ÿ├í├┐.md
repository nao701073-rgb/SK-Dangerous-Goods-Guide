# Part 208 統合運用センター要領

## 目的
利用者管理、認証、法令更新、障害、バックアップ、監査、管理者権限移行を横断して確認し、対応漏れを防止します。

## 主な機能
- 運用状態の自動集計
- 分野別の正常・要注意・重大判定
- 優先対応事項の一覧化
- 最近の障害、法令更新、バックアップ確認
- 月次統合レビューと監査記録
- JSON形式の監査レポート出力

## 運用方法
1. 月初または定例会前に統合運用センターを開きます。
2. 優先対応事項を各管理画面で処理します。
3. 利用者、法令、認証、バックアップ、障害の状態を確認します。
4. 月次統合レビューを登録します。
5. 必要に応じて監査レポートを保存します。

## 権限
システム管理者だけが利用できます。将来、安全環境室長へ管理者権限を正式移行した後は、安全環境室長が本画面を管理します。
