# 第28回実装：IMDG Code収納検査関連条文

## 追加内容
IMDG Code Amendment 42-24から、危険物コンテナ収納検査に直接関係する条文を
19項目選定して関連資料へ登録。

## 選定基準
- 国内法令に具体的な詳細が規定されていない
- 危告示ではコードだけが示され、IMDG Code表の確認が必要
- 容器、表示、標札、書類、隔離、CTU収納状態の検査に直接使用する

## 除外
- 船舶設備・消火設備
- 船上でのみ使用する一般積付け
- ばら積み専用規定
- 収納検査に直接関係しない運航規定

## 資料整理
「IMDGコードに基づく検査・検品業務に関する資料 初版」は関連資料から削除。
将来、別のサブタイトル・別区分で再登録できるよう、現在の資料レジストリから分離した。
