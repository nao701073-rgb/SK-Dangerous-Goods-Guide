# Part 561 申請書確認かんたん操作化

## 目的
申請書確認を、経験差にかかわらず同じ順番で操作できるようにする。既存の危険物判定・許容値判定・申請番号管理登録処理は変更せず、操作案内と表示を整理する。

## 基本フロー
1. 申請書取込
2. 自動確認
3. 要確認だけを確認
4. 申請番号管理へ登録

## 主な改善
- 対象危険物、確認済み、要確認の件数を上部に集約。
- P200・許可、IBC、ポータブルタンク、包装要件、容量・質量、容器コード等の確認ポイントを自動集約。
- 「次の要確認」で要確認の危険物へ順番に移動。
- 「要確認だけ表示」で確認済み危険物を一時的に非表示。
- 使用頻度の低い案件情報を「その他の案件情報」へ整理。
- JSON／CSV出力を通常登録操作から分離。
- スマートフォンで次操作を画面下部に固定表示。
- 確認完了後は原本照合者入力、申請番号管理への登録へ順番に案内。

## 維持する仕様
- P包装・P200・IBC・ポータブルタンクの参照要件と許容値判定。
- P200「x」の許可案内。
- 少量危険物の既存判定。
- L／kg異単位の±20%注意喚起。
- 同一単位の規定量超過判定。
- 新規登録／既存申請更新／登録後詳細確認。
- 固縛力参考算出の計算式・MSL判定・保存データ。

## データ移行
DBマイグレーションなし。
