# Part 568 要確認高速ナビ・現場入力補助

## 1. 申請書確認
「3．要確認だけを確認」の直下に要確認ナビを追加しました。未確認行だけを既定表示し、前後ボタンで対象行へ直接移動できます。全件表示へ切り替えても、判定結果・確認状態・登録データには影響しません。

登録前には、要確認の残数と原本照合者の入力状態を表示します。既存の登録可否判定そのものは変更していません。

## 2. 申請番号管理
選択中案件の確認記録と取付点MSL台帳を読み、次に確認すべき操作を一つ表示します。

優先順位は次のとおりです。
1. 申請書確認記録なし → 申請書確認
2. 申請書に未解決項目あり → 要確認の再確認
3. 使用予定MSL取付点に未確認あり → 固縛力画面のMSL確認
4. 上記がなければ → 必要に応じて固縛力参考算出

この表示は作業案内であり、申請の正式な進捗ステータスを新設するものではありません。

## 3. 固縛力参考算出
かんたん入力の近くに「現場入力チェック」を追加しました。使用方法・固縛方法に応じて、貨物質量、接触面状態、固縛材MSL、貨物側MSL、CTU側MSL、支保力、支保力根拠、併用成立条件などの入力状態を表示します。

不足がある場合は「最初の不足項目へ」で該当欄へ移動できます。貨物側／CTU側MSLは、写真撮影・アップロードのショートカットから既存の写真確認機能を直接開始できます。

取付点MSL台帳が案件に登録されている場合は、使用予定取付点の確認済み件数も表示します。

## 4. 非変更事項
- 固縛力の計算式
- 方向別抵抗力の算出
- 直接固縛で採用する最小MSLのロジック
- 引張系＋支保材併用時の二重計上防止
- 海上輸送の初期値
- 申請書の危険物判定・許容容量／許容質量判定
- `reviewEvidence` の保存形式
- DBスキーマ
