# Part 370 更新内容

- ログインセッションを明示的なログアウトまで維持するよう修正。
- ユーザー設定・システム設定へ移動してもログイン画面へ戻らないよう認証状態を永続化。
- システム設定画面上部の「ユーザー設定」「システム設定」重複ボタンを削除。
- システム管理者のお気に入り見出しを「システム管理者さんのお気に入り」に変更。
- 法令改正・データ更新管理、案件判定根拠スナップショット、国内法令・IMDG Code対照は、システム管理者、安全環境室長、安全環境室職員、検証者だけに表示・アクセスを許可。
- 関連資料の資料別操作を「資料を開く」「メモ」「お気に入り」に簡素化。個人管理機能はメモとお気に入りのみに統一。
- PC・スマートフォン向けのレスポンシブ表示を調整。
