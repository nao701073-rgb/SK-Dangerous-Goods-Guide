# Part 312 更新内容

## 本人向けログイン履歴・端末管理

- ユーザー設定に「ログイン履歴・端末管理」を追加
- 本人の最近の認証履歴を最大50件表示
- ログイン成功、多要素認証、パスワード変更、全端末ログアウト等を日時・接続元・端末種別とともに確認可能
- 最終ログイン日時、パスワード変更日時、多要素認証状態を概要表示
- 本人操作による「すべての端末からログアウト」を追加
- 全端末ログアウト実行時はトークンバージョンを更新し、既存ログイン状態を無効化
- パスワード変更時のセキュリティイベント記録を追加

## 互換性

- 既存のログイン画面、MFA、初回パスワード変更、表示テーマ、申請番号管理データの保存形式は変更していません。
