# Part 333 更新内容

## 権限エラー画面のレスポンシブ表示改善

- 指定済みの表示順を維持しました。
  1. 利用可能な権限の案内
  2. 「設定画面へ戻る」
- 権限エラー画面専用のレイアウトを追加し、PC・スマートフォンの双方で読みやすくしました。
- スマートフォンの動的な画面高とセーフエリアへ対応しました。
- 「設定画面へ戻る」の操作領域を44px以上とし、タッチ操作をしやすくしました。
- 小さい画面では「設定画面へ戻る」を画面幅に合わせて表示します。
- 見出しと説明文を `aria-labelledby` および `aria-describedby` で関連付けました。
- 見出しフォーカス、即時通知、画面タイトルの変更は従来どおり維持しています。
- 「現在の権限：未認証」等の表示は追加していません。
