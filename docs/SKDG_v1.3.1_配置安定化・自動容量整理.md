# SKDG v1.3.1 配置安定化・自動容量整理

## 変更点
- 固縛力参考算出を開いた直後に「1. 申請書・航路から入力」「2. 写真から入力」を必ず最上部へ表示。
- `v1-ctu-simple.js` の `.quick-entry` / `.quick-flow` 不整合を修正し、写真入力ステップを確実に生成。
- 申請書確認は取込直後の短時間だけ結果欄を固定し、DOM更新が落ち着いた時点で一度に表示してレイアウトシフトを抑制。
- Clean Updaterでは、既存システムの重複資産を更新時にSHA-256再照合し、完全一致した対象だけ自動削除。
- 法令、IMDG、標札、危険物マスター、関連資料の機能・原文資産は削除対象外。

## 容量整理方針
対象は旧名称側の完全重複だけ。ファイルが片方しかない、またはハッシュが一致しない場合は削除しない。
