# part494 判定基準・Tコード表示改修

## 判定基準

登録済み危険物2,725行を対象に、危告示第2条の定義ページを「判定基準」として表示していた処理を廃止しました。備考2に具体的な判定基準がある分類・項目は、PDF 268〜276ページの該当箇所へ直接表示します。

- 備考2(1)：火薬類
- 備考2(2)：高圧ガス
- 備考2(3)：引火性液体類
- 備考2(4)：可燃性物質、自己反応性物質、重合性物質、自然発火性物質、水反応可燃性物質
- 備考2(5)：酸化性物質、有機過酸化物
- 備考2(6)：毒物
- 備考2(7)：腐食性物質
- 備考2(8)：環境有害物質

病毒をうつしやすい物質、放射性物質等及び環境有害物質以外のクラス9は備考2の対象ではないため、固有の定義又は危告示別表第1の当該品名・備考ページを表示します。

## Tコード

T1〜T22の要件表を横長5列から縦型2列へ変更しました。次の項目は横スクロールなしで確認できます。

- タンクの記号
- 最小試験圧力
- タンク外板の最小板厚
- 圧力安全装置の種類
- 底部開口
- 代替使用可能なTコード

既存の色、フォント、罫線、余白を継承しています。
