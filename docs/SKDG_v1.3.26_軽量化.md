# SKDG v1.3.26 Performance Hotfix — 軽量化 第3段階

## 方針

v1.3.25までの機能・表示仕様・計算結果・保存形式・権限を維持し、ブラウザ側の無駄な再読込と再描画を減らしました。

## 主な変更

1. **申請番号管理のデータキャッシュを継続利用**
   - 案件・写真・資料・申請確認結果・固縛力算出結果は、データ変更イベントが発生するまで再取得しません。
   - 一覧の検索・絞り込みでカードDOMだけが再描画された場合は、直前に作成した案件ID索引を再利用します。

2. **検索入力1文字ごとの全件再取得を廃止**
   - 従来の `input` イベントごとの強制再処理を削除しました。
   - 一覧構造が実際に変わった場合のみ、軽量な表示補正を行います。

3. **固縛力画面の完全DOM走査を初期1回へ削減**
   - 旧互換UI除去の完全走査は初期化時のみです。
   - load後と初期レンダリング追補は、ID中心の軽量処理に変更しました。

4. **SheetJSのページ描画待ちを回避**
   - 固縛力画面のSheetJSを同期読込から非同期読込へ変更しました。
   - Excel申請書を使用しない通常操作では、外部ライブラリの取得がページ描画を止めません。

5. **画面下部の重いセクションを遅延描画**
   - 現場貨物単位、不足・是正支援、登録欄は画面に近づくまでレイアウト・描画を遅延します。
   - 印刷時は遅延を解除し、従来どおり全内容を出力します。

## 変更なし

- DB構造・マイグレーション
- 固縛力計算式
- MSL参考候補
- 危険物申請確認の判定内容
- 申請番号管理の保存内容
- 権限・表示対象
- 画面上の `Version 1.0 試作版` 表示
