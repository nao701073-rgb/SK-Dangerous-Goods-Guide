# Part 176 関連資料の表示意図修正

## 修正内容

- 「かみ砕いた説明」の見出しを「概要」へ変更しました。
- 検査・検品業務資料の図・写真・表について、画像を掲載するだけでなく、各画像が何を示し、検査で何を確認するための資料かを要約表示します。
- 画像は従来どおり拡大して、元資料の注記・凡例・数値・表を確認できます。
- 理解しづらい規定のAI要約10件では、CTU Codeの要点だけでなく、登録済みの国土交通省公表『CTU Code（仮訳）』PDFの該当ページを同じモーダルウィンドウ内で開きます。
- モーダルでは「条文テキスト」と「原文ページ（表・図を含む）」を切り替えられます。

## 注意

AI要約・概要は理解補助です。実務判断ではPDF本文、図、表、脚注、注記および適用法令を確認してください。
