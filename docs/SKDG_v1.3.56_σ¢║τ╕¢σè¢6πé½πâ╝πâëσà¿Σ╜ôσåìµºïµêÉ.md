# SKDG v1.3.56 固縛力参考算出 6カード全体再構成

## 修正目的
v1.3.55で番号カードの見た目を統一した際、①カード上端に余白状の枠が残ること、①と②が連続した一体カードのように見えること、③以降の表示が不安定になる事象が確認されたため、DOMを後から大きく包み直す方式を廃止して6段階全体を再構成した。

## 6段階
1. 申請書・航路から入力する
2. 写真を撮影・アップロードする
3. 輸送条件と貨物を確認
4. 貨物底面とCTU床面
5. 固縛・支保条件を確認
6. 参考算出を確認

## 変更内容
- ③「輸送条件と貨物を確認」のカードを共通デザイン基準とした。
- ①〜⑥の番号丸、見出しフォント、見出し帯、罫線、角丸、本文余白を統一した。
- ①と②を別々の独立カードとして明示し、カード間に一定の余白を設けた。
- ①上端に残っていた空白帯・二重枠の原因となる旧ランタイムラップを廃止した。
- quickEntryPanel自体は外枠を持たないカードデッキとし、③〜⑥を個別カードとして表示する。
- v1PhotoStepの入力機能・イベント連携は削除せず、②写真カード内の入力補助として移動する。
- v1ContactStepは④「貨物底面とCTU床面」として独立カード表示する。
- 旧v1.3.55のランタイムラップがキャッシュ等で先に実行された場合も、v1.3.56側で元のDOM構造へ戻す互換処理を入れた。
- 追尾ステータスを唯一の進捗表示とし、重複する旧緑色の「基本条件は入力済み」表示は非表示とする。
- 申請書取込、写真AI、MSL補助、参考算出、登録ロジックは変更しない。

## 表示安定化
- ③〜⑥の対象カードは旧ウィザードCSSが残っていても表示されるよう、対象カード単位で可視状態を保証する。
- 常時監視やsetIntervalは使用せず、初期化時の有限回互換処理だけを使用する。
