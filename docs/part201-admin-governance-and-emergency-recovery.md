# Part 201 管理者権限の継続統制・緊急復旧管理

## 目的
安全環境室長へのシステム管理者権限移行後も、管理者権限が過大・不要な状態で残らないよう定期的に点検し、管理者がログインできない緊急時に備えた復旧手順を記録する。

## 追加機能
- 管理者権限の定期棚卸し
- 未使用・停止候補アカウントの記録
- 過大権限の指摘および是正措置
- 次回点検日の管理
- 緊急復旧用アカウントの保管確認
- MFA、監査ログ、代替連絡体制の確認
- ログイン訓練・完全復旧訓練の結果記録
- 定期点検と復旧訓練の監査レポートJSON出力

## 運用原則
1. 通常の管理業務は安全環境室長の個人アカウントで行う。
2. 緊急復旧用アカウントは通常業務に使用しない。
3. 緊急復旧用アカウントの認証情報そのものは本システムへ入力しない。
4. 管理者権限は少なくとも四半期ごと、または人事異動時に点検する。
5. 復旧用アカウントを使用した場合は、理由、承認者、操作内容を監査記録に残す。
