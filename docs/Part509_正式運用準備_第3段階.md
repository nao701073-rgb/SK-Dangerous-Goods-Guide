# Part 509 正式運用準備 第3段階

## 対象

著作権、契約・ライセンス、引用・転載条件および社内公開範囲を、原典の正確性承認とは別の管理工程として扱うための実装です。

本段階は、法的な利用可否を自動判定するものではありません。権利者、契約書、公式利用条件、ライセンス、社内規程等を、権限を有する担当者が確認・承認するための台帳、画面、公開制御および公開用パッケージ生成機能を提供します。

## 初期台帳

Part 508一式に含まれるコンテンツ資産を走査し、635件を初期台帳として分類しました。

- 国内法令関係：366件
- IMDG Code等のライセンス確認対象：241件
- 国際ガイダンス：12件
- 整理情報・AI要約：1件
- 第三者資料または権利関係不明：15件
- 高リスクとして初期分類：256件
- 管理対象容量：約211.4MB

これらは分類作業の結果であり、権利確認・公開承認が完了したことを意味しません。初期状態はすべて「未確認」です。

## 実装内容

1. 原典PDF、抜粋PDF、ページ画像、整理情報をファイル単位で管理します。
2. 次の情報を記録します。
   - 権利者・発行者
   - 契約、許諾、公式利用条件、ライセンスの参照
   - 利用根拠
   - 公式URL・出典URL
   - 必要な出典・著作権表示
   - 許可する公開範囲
   - 外部公開時の表示方法
   - 権利確認期限、次回見直し日
   - 対象ファイルのSHA-256
3. 登録・提出者、権利確認者、公開範囲承認者を別の利用者に限定します。
4. 次の8項目を確認しなければ「権利確認済み」にできません。
   - 権利者・発行者
   - 契約・公式利用条件・ライセンス
   - 複製・抜粋・画像化・転載の可否
   - 社内利用の対象者・部署・保存場所
   - 外部公開の可否または対象外
   - 出典・著作権表示
   - 期限・版更新・契約変更時の再確認条件
   - 対象ファイルの版・SHA-256
5. 公開範囲は次の4区分で管理します。
   - 試作・権利確認中
   - 社内・認証済み利用者
   - 社内・権限者限定
   - 外部公開・承認済みのみ
6. 資料ごとの処理は次から選択します。
   - 全文・ファイル表示
   - 承認済み抜粋のみ
   - 書誌情報のみ
   - 公式外部リンクのみ
   - 表示しない
7. 画面内の資料リンクに公開範囲ゲートを設けます。
8. ファイルを直接公開しないため、外部公開用のサニタイズ済みパッケージ生成機能を追加しました。
9. ファイル内容の変更をSHA-256で検出し、承認済み資料は再確認待ちへ戻します。
10. システム設定と専用管理画面から公開範囲を変更できます。

## 外部公開時の重要事項

画面上でリンクを非表示・無効化するだけでは、既知のURLからファイルへ直接アクセスできる可能性があります。GitHub Pages等へ公開する場合は、必ず次のコマンドで公開承認のないファイルを物理的に除外したパッケージを作成します。

```text
npm run build:public-sanitized -- --scope public-approved --decisions <決定台帳JSON> --output <公開先フォルダ>
```

決定台帳JSONは、「著作権・社内公開範囲管理」画面の「決定台帳をJSON出力」から取得します。

## 適用手順

1. Part 508適用済みフォルダを複製して保管します。
2. Part 509更新ZIPをフォルダ構成のまま上書きします。
3. `server`フォルダで`npm run migrate`を実行し、`097_part509_copyright_publication_scope.sql`を適用します。
4. APIを再起動します。
5. システム管理者でログインし、「著作権・社内公開範囲管理」を開きます。
6. 「資料台帳を更新」を実行します。CLIでは`npm run rights:catalog`でも実行できます。
7. 各資料について、権利確認への提出、8項目の確認、公開範囲の承認を行います。
8. 外部公開前に決定台帳を出力し、公開用サニタイズ済みパッケージを生成します。
9. 生成レポートで、除外件数、書誌情報のみの件数、高リスク未解決件数を確認します。

## 完了条件

- 635件の初期台帳と実ファイルが一致する。
- 高リスク資料の権利・利用条件が確認されている。
- 登録・提出者、権利確認者、承認者が別利用者である。
- 外部公開対象は「外部公開」の明示承認がある。
- 社内限定資料が外部公開パッケージに含まれない。
- 書誌情報のみ・外部リンクのみの資料は、原典ファイルを同梱しない。
- ファイル変更時に再確認が必要な状態へ戻る。
- 公開範囲、承認者、確認日、根拠、期限、チェックサムが監査履歴に残る。

## 未実施事項

本実行環境では、各資料の契約書、公式利用条件、購入ライセンス、社内規程および権利者からの許諾内容を確認できないため、法的な利用可否の判断は実施していません。635件はすべて初期分類・未確認状態です。

また、導入先PostgreSQLへの台帳登録、複数利用者による権利確認・承認、実際の外部公開先への配置試験は未実施です。これらはIT室、安全環境室および必要に応じて法務・契約担当が確認する必要があります。
