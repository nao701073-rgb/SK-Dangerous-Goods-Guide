# Part 139 再是正処置の進捗・完了管理

## 概要
再発防止策の効果確認で「効果不十分」と判定された場合に作成する再是正処置について、登録後の進捗、担当者変更、完了申請、別担当者による完了確認までを管理します。

## 主な機能
- 再是正処置の進捗率（0～100%）と進捗内容を記録
- 進捗更新者・更新日時・履歴を保存
- 担当者変更と変更理由を記録
- 担当変更履歴を保存
- 対応完了後は完了確認待ちへ移行
- 対応完了者本人による自己確認を禁止
- 別担当者の完了確認後に再是正処置を完了
- 親となる是正処置へ再是正完了日時・確認者・確認結果を反映

## 権限
進捗更新、担当者変更、完了登録、完了確認は事業所管理者または管理者のみ実行できます。

## 処理フロー
効果不十分判定 → 再是正処置登録 → 進捗更新 → 必要に応じて担当者変更 → 完了申請 → 別担当者による完了確認 → 親是正処置へ解決結果反映
