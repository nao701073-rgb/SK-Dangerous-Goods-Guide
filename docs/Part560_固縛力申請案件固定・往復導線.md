# Part560 固縛力申請案件固定・往復導線

## 目的
申請番号管理の詳細画面から固縛力参考算出を開始・再計算する際、同じ申請番号を再度選択する操作をなくす。

## 変更内容
- `applicationId`付きで固縛力参考算出を開いた場合、その申請を登録先として固定表示する。
- 固定中は申請案件セレクタと新規申請番号入力を通常表示しない。
- 別案件へ保存する必要がある場合だけ「登録先を変更」で従来の選択UIを表示する。
- 「この申請に戻す」で元の申請へ再固定できる。
- 固縛力算出画面から申請詳細の「固縛力算出」タブへ戻るリンクを追加する。
- 申請詳細側には、算出画面を開くと同じ申請が自動で登録先になることを明示する。

## 変更しないもの
CTU/CSS計算式、MSL最小値判定、摩擦計算、方向別判定、支保併用、履歴保存、再計算データ復元、登録データ構造は変更しない。
