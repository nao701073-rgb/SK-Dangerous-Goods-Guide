# SKDG v1.3.82 写真ドラッグ＆ドロップ表示修正

## 対応内容
- 固縛力参考算出「写真を撮影・アップロードする」の黒背景上で、ドラッグ＆ドロップ案内文字が暗く読みにくかった表示を修正。
- 案内を写真ステージ下部の白文字オーバーレイとして配置し、中央の説明文と横並びにならないよう修正。
- 写真読込後は測定キャンバスを遮らないよう案内を非表示。ドラッグ中のみ再表示。
- PCのドラッグ＆ドロップを現行の写真入力へ橋渡し。貨物側MSL、CTU側MSL、取付点根拠写真のドロップも同様に接続。
- 手動で複数写真を選択した場合は写真一覧に保持し、一覧から表示する写真を切替可能。

## 変更していないもの
CTU/CSS計算式、A/B/C海域、摩擦、支保、固縛抵抗、最弱MSL、v1.3.81の三段階判定、申請番号管理、認証・権限、データベース構造は変更していません。
