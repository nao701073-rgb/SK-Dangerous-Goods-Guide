# Part 148 全体統合・権限表記・版情報整理

## 実施内容

### 1. 権限名称の統一
利用者向け表示を次の3区分へ統一しました。

- 利用者
- 事業所管理者
- 管理者

既存データとサーバーAPIとの互換性を保つため、内部ロール値 `safety-environment-admin` は変更していません。画面上の名称だけを「管理者」に統一しています。

### 2. 版情報の更新
`data/app-config.json` の版情報を Part 148 に更新し、試験運用統合版であることを明示しました。

### 3. ホーム画面の整理
既に実装済みの「国内法令対照」を将来機能扱いから外し、関連法令画面への導線を有効化しました。

### 4. 未使用画像の整理
参照されていない旧ロゴ・作業用画像を削除し、配布容量を削減しました。

### 5. 互換性方針
内部ID、ロール値、既存localStorageキー、API契約は変更していません。表示と構成を整理しつつ、既存データを引き続き利用できるようにしています。
