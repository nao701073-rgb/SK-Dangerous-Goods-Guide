# Part 318 更新内容

## 1. 権限別ホーム画面の導線整合
安全環境室長のホーム画面から、実際には利用できない利用者管理・本番運用統合管理への直接リンクを削除しました。危険物検索、関連法令、関連資料、許可されたシステム設定への導線に整理しています。

## 2. 利用モード表示
権限別ホーム画面に、現在の利用モードを表示します。

- 事業所利用者：所属事業所での通常利用
- 事業所管理者：所属事業所の利用者管理
- 安全環境室長：全事業所の確認・統括
- 安全環境室職員：全事業所の閲覧専用
- システム管理者：システム全体の管理
- ゲスト：検索・法令・資料の限定利用
- 検証者：検証・確認専用

## 3. 検証者のアクセス修正
検証者が権限別ホーム画面の「総合検証」から、総合検証画面へ正式にアクセスできるよう修正しました。

## 4. 申請番号管理の方針
申請番号管理は社内既存システムを正式な管理元とし、本システムでは参照、最低限の案件情報、関連写真、添付資料の整理に留めます。本更新では申請番号管理の追加拡張は行っていません。
