# Part 284 更新内容

## アクセス情報の拡充

システム設定画面のアクセス情報を、利用者へ案内しやすい構成へ改善しました。

- システムのトップURLと現在開いているページURLを分けて表示
- `pages/`配下の画面からホーム画面のURLを自動生成
- GitHub Pages、HTTPS公開、HTTP接続、ローカルサーバー、ファイル直接起動を判定
- ほかの端末へ案内できる可能性を「共有可否」として表示
- トップURLと現在ページURLを個別にコピー
- ホーム画面を別タブで開く操作を追加
- Web Share API対応端末ではトップURLを共有
- スマートフォンではURLと操作ボタンを縦並びで表示

ローカルURLやファイル直接起動のURLを誤って利用者へ案内しにくい表示としています。
