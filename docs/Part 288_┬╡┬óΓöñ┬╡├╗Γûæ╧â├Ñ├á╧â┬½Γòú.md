# Part 288 更新内容

## アプリ導入状態の確認

- ブラウザ表示、アプリ表示に加え、アプリとして追加可能かを表示します。
- 対応ブラウザでインストール条件を満たした場合のみ「アプリとして追加」ボタンを表示します。
- 既にアプリ表示で起動している場合は「追加済み」と判定します。

## オフラインデータ更新確認

- Service Workerの登録状態から、最新・更新中・更新待ちを表示します。
- 「オフラインデータを更新確認」から登録済みService Workerの更新確認を実行できます。
- 新しいデータが待機中の場合は、再読み込みを案内します。

## 互換性

- 申請番号、写真、添付資料、検索条件などの既存保存形式は変更していません。
