# Part 144 案件再開ワークフロー統合管理

## 概要
案件再開の承認から再調査、追加是正、再評価、再クローズまでを一つの一覧で監視できるようにしました。

## 追加内容
- 状態別サマリー
  - 再開承認待ち
  - 再調査中
  - 再調査承認待ち
  - 追加是正中・確認待ち
  - 再評価待ち
  - 再クローズ承認待ち
  - 期限超過
  - 再クローズ済み
- 状態、事業所、キーワードによる絞り込み
- 調査結果、原因、追加是正内容を含む横断検索
- 再開案件台帳のCSV出力
- 再開申請と再調査レコードをまとめたJSON出力
- サーバー用ダッシュボードVIEWと検索インデックス

## 権限
承認、再調査、追加是正、再評価、再クローズの操作は、事業所管理者または管理者のみ実行できます。自己承認禁止は各工程で維持します。

## 運用上の考え方
期限超過を検出しても自動承認・自動クローズは行いません。担当者が内容を確認した上で処理します。
