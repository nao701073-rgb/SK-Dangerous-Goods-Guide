# Part 116 写真完全削除計画の通知ダッシュボード

## 概要
写真完全削除計画について、承認待ち、実行待ち、期限超過、管理者引継ぎ、未確認通知を一画面で把握できるようにしました。

## 追加機能

- 通知サマリーカードから該当計画へ絞り込み
- 状態、担当者、作成者、承認者による検索
- 未確認通知だけの表示
- 通知の確認済み記録
- 優先度表示
  - 至急：期限超過
  - 優先：管理者引継ぎまたは期限接近
  - 通常：その他の未完了計画
- 通知一覧CSV出力

## 通知確認記録
通知確認時には以下を保存します。

- 計画ID
- 確認者
- 確認日時
- 通知履歴

通知を確認済みにしても、承認や完全削除が実行されたことにはなりません。承認権限および実行権限は、従来どおり事業所管理者または管理者に限定します。
