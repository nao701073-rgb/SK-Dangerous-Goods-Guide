# Part 336 更新内容

## 固縛力参考算出アイコンの仕上げ

- 採用された青地・白線のデザインを既存の主要機能アイコンへ正式適用
- コンテナ内枠、パレット貨物、左右の固縛材を簡潔な線画で表現
- コンテナ外部の固縛と誤認しにくいよう、コンテナ内貨物であることを説明文へ明記
- 「将来実装」の状態を `aria-disabled` と説明関連付けで支援技術へ通知
- 装飾SVGをスクリーンリーダーおよびキーボードフォーカスの対象外に設定

## 維持した仕様

- 主要機能アイコンの青色背景・白色線画・統一サイズ
- 「将来実装」の表示
- 権限エラー画面の「ホームに戻る」導線
- ログイン画面、権限別表示、申請番号管理の既存仕様
