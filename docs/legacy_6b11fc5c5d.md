# Part 292 更新内容

## 関連資料画面

- 登録資料にファイル形式の絞り込みを追加しました。
  - PDF
  - Word
  - Excel
  - CSV
  - テキスト
  - 画像
  - その他
- 登録データに含まれる分類を自動的にプルダウンへ補完するようにしました。
- 「国際条約」分類を表示対象へ追加しました。
- 並び順に「言語順」「ファイル形式順」を追加しました。
- 適用中の条件をチップ表示し、検索語・分類・言語・形式・並び順を個別に解除できるようにしました。
- 資料カードのメタ情報を日本語表記へ整理しました。
- スマートフォンでは検索・絞り込み項目を縦並びで表示します。

## 互換性

- 既存の関連資料データおよび各種保存データ形式は変更していません。
