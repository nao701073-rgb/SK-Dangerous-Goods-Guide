# SKDG v1.1 操作導線・画面構成まとめ改善

## 1. 目的
v1.0.1のシンプル化を維持しながら、日常操作で必要な移動と入力だけを短くします。新しい管理ワークフローは追加しません。

## 2. ホーム
主要6機能へのクイック入口をホーム検索の直下へ配置します。ユーザー設定で1つだけ「よく使う機能」を選び、先頭表示できます。

## 3. 申請書取込・確認
画面下部に単一の次操作ボタンを配置し、状態に応じて「ファイル選択」「自動確認」「確認結果へ移動」「申請番号管理へ登録」を切り替えます。進捗カードは追加しません。

補助出力と取込履歴は折りたたみ内へ移動します。取込後の危険物明細のPC内スクロール、スマホカード表示はv1.0.1を維持します。

## 4. 申請番号管理
案件一覧を先に表示し、選択案件の簡易メモ、写真、添付資料へ続く順番へ整理します。詳細案件入力は新規作成・編集時だけ表示します。高度な絞り込みは初期状態で閉じます。

## 5. 固縛力参考算出
申請書と写真から補助できた入力を識別し、「不足項目だけ補う」部分では候補入力済みの項目を折りたたみます。必要時は「入力済みも表示」で全項目を確認できます。

AI候補はカード全体をタップして選択できます。「表示中の候補を選択」は利用者の明示操作であり、自動採用ではありません。MSLや安全性は写真だけで確定しません。

## 6. ユーザー設定
既存の見やすさ設定に「ホームで最初に表示する機能」を追加します。機能の表示・非表示を増やす設定ではありません。

## 7. 維持事項
危険物検索・危険物詳細・関連法令・関連資料・原文参照・コード別画面・オーバーパック表示用作成は削除しません。既存の危険物判定、許容容量・許容質量、固縛計算式、保存データ構造も変更しません。
