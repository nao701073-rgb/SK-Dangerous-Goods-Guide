# Part 287 更新内容

## 利用環境診断・端末内保存の保護

- `navigator.storage.persisted()`を利用し、端末内データが永続ストレージとして保護されているかを表示します。
- 対応ブラウザでは「端末内データを保護」ボタンから`navigator.storage.persist()`を実行できます。
- 利用環境の確認結果を日時入りのテキストファイルとして保存できます。
- 非対応環境では保存保護ボタンを表示せず、既存機能を妨げません。

## 互換性

- 既存の申請番号、関連写真、添付資料、検索設定の保存形式は変更していません。
- 保存保護の許可可否はブラウザ側の判断となります。
