# SKDG v1.3.18 ログイン背景表示修正

## 修正内容
- ログイン画面の時間帯別港湾イラストが表示されず、薄い青色背景だけになる問題を修正。
- 原因は `.login-scene` が `z-index:-2` で body の描画レイヤーより背面へ回る場合があったこと。特に Chrome の `file://` 起動で再現し得る。
- 背景レイヤーを `z-index:0`、ログインUIを `z-index:1` とし、body 内の独立スタッキングコンテキストで確実に表示する。
- 06:00–10:00 朝、10:00–16:00 昼、16:00–19:00 夕方、19:00–06:00 夜の4背景は維持。
- 時間帯画像が読み込めない場合は、従来の `login-business-background-4k.png` をフォールバック表示する。
- `login-business-background-4k.png` もHotfixへ同梱。
- DB移行なし。表示バージョンは `Version 1.0 試作版` のまま。
