# part469 IMDG条文連携

危告示のSP・E・SW・P・PPコード原文中に「IMDGコード／IMDG Code」の条文番号が記載されている場合、危険物詳細のコード参照画面で該当するIMDG Code原文ページを続けて表示します。

- 対象条文番号：国内コード原文から自動抽出した37件
- ページ画像：IMDG Code 2024 Edition (Amendment 42-24), Resolution MSC.556(108)から生成
- PC・スマートフォン：同じ専用ページ画像を使用
- `4.2.13.1`：現行42-24本文で同一番号を確認できないため、誤ったページへ誘導せず注意文を表示
