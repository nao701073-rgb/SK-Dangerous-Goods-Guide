# Part 250 切替後運用・引継ぎ管理要領

## 1. 目的
運用開始後の初期安定化、問い合わせ・障害対応、バックアップ、法令更新、運用担当者への引継ぎを一つの記録として管理します。

## 2. 利用対象
システム管理者が利用します。将来、安全環境室長へシステム管理者権限を正式移行した場合は、安全環境室長が引き継ぎます。

## 3. 初期安定化
ログイン、権限制御、主要業務機能、認証メール、性能、バックアップ、復元、監査、問い合わせ窓口を確認します。

## 4. 運用引継ぎ
仕様書・要領書、管理者認証、バックアップ、法令更新、障害対応、利用者管理、監査、次回点検を引き継ぎます。

## 5. 判定条件
「安定運用」以降は初期安定化項目がすべて完了し、重大障害が0件であることが必要です。「引継ぎ準備完了」「運用引継ぎ完了」は、運用引継ぎ項目もすべて完了している必要があります。

## 6. 注意事項
本画面の記録は運用管理用です。クラウドAPI接続後は、`post_deployment_operations_reviews`へ記録する構成を想定しています。
