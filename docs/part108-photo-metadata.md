# Part 108 写真メタデータ自動取得

## 概要
申請番号への写真登録機能について、JPEG写真に含まれるEXIFメタデータを活用し、撮影日時、向き、位置情報を自動取得する機能を追加しました。

## 追加機能

### 1. 撮影日時の自動取得
- EXIF DateTimeOriginal がある場合は最優先で採用
- DateTimeOriginal がない場合は EXIF 日付を採用
- EXIF がない場合はファイル更新日時を採用
- 取得した日時は「撮影日時」欄へ自動反映

### 2. 向き補正
- EXIF Orientation を読み取り、圧縮保存時に回転ずれを補正
- スマートフォン撮影画像で縦横が崩れる問題を軽減

### 3. 位置情報の取得
- JPEG写真に GPS 情報がある場合、緯度・経度を保存
- 画面の圧縮結果欄および拡大表示で確認可能

### 4. CSV出力
登録済み写真一覧を CSV 出力できます。
出力項目例：
- 申請番号
- 撮影日時
- 撮影日時取得元
- 登録者
- 事業所
- 保存容量
- 元画像容量
- 保存寸法
- 圧縮モード
- GPS
- 代表写真
- コメント

## 保存項目
写真レコードに以下を追加しています。
- capturedAtSource
- exifOrientation
- gps

## 留意事項
- EXIF 解析は主に JPEG を対象としています。
- PNG など EXIF 非対応または情報がない形式では、ファイル日時を利用します。
- 本番運用で位置情報を扱う場合は、社内規程や個人情報・機密情報の取扱い基準に従って運用してください。
