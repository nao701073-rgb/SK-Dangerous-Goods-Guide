# Part 323 更新内容

## 目的

申請番号管理を社内既存システムの補完機能として維持しながら、ログイン権限とメニュー表示の判定を一本化しました。

## 変更内容

- 申請番号管理の表示可否を `applicationsRead` 権限で統一しました。
- ホーム画面の上部メニュー、主要機能カード、スマートフォン下部メニューに同じ権限属性を設定しました。
- 権限別ホーム画面のショートカットを、権限マスターに応じて自動的に除外する仕組みに変更しました。
- ゲストおよび検証者には申請番号管理の導線を表示しません。
- 事業所利用者、事業所管理者、安全環境室長、安全環境室職員、システム管理者の既存権限は維持します。
- 申請番号管理カードの説明文を「社内既存システムの申請番号に、簡易メモ、関連写真、添付資料を補完します。」へ変更しました。

## 変更しない事項

- 申請番号管理の権限別閲覧・登録・更新範囲
- 写真、簡易メモ、添付資料の既存データ形式
- ゲストによるURL直接指定時のアクセス拒否
- 社内既存システムを正式な申請番号管理元とする方針
