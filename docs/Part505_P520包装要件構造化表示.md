# Part 505 - P520包装要件の構造化表示

## 対象

危告示原典PDF 320～323ページに掲載されたP520包装要件の全表、注記及び追加規定。

## 表示方針

- PDF抽出文字列の連続表示を廃止。
- 固体の組合せ容器、固体の単一・複合容器、液体の単一・複合容器に区分。
- OP1～OP8と容器の対応を表形式で再現。
- OP2、OP4は内装容器・外装容器を区別。
- コンテンツ幅1040px以下ではカード表示へ切替。
- 768px以下は必ずカード表示。
- 注記1～7、PP21、PP22、PP94、PP95を独立欄で表示。
- 原典PDFリンクは320～323ページを表示。

## デザイン

既存の色、フォント、罫線、角丸、余白を維持する。
