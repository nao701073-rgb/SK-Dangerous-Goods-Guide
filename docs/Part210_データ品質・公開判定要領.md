# Part 210 データ品質・公開判定要領

## 目的
法令PDF、CSV、JSON等から生成した危険物データを公開する前に、重複・欠損・形式不整合・参照情報を自動検査し、旧版との差分確認と管理者承認を記録する。

## 標準手順
1. 更新ファイルを作業用フォルダへ保存する。
2. `npm run data:normalize` で同一レコード内の完全重複を整理する。
3. `npm run data:audit` で品質監査レポートを生成する。
4. `npm run data:compare -- 旧版/un-data.js 新版/un-data.js 差分レポート.json` で追加・変更・削除を確認する。
5. 変更箇所を原典PDFと照合する。
6. 設定画面の「データ品質・公開判定」で確認事項を記録する。
7. `npm run data:release-check` が合格した後に公開する。

## 公開判定
- pass: エラー・警告なし。
- review-required: エラーなし、警告あり。原典照合と承認が必要。
- blocked: エラーあり。修正完了まで公開禁止。

## 注意
自動検査は原典確認を代替しない。品名、分類、容器等級、包装要件、特別規定、積付け、隔離等の変更は必ず有効な原典と照合する。
