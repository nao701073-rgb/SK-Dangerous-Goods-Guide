# part491 判定基準・コード詳細表示の改善

- UN0005を含む全危険物で、分類に関する国内法令は「判定基準」と表記する。
- 判定基準は危告示の該当条文を先に表示し、危告示第2条はPDF 1ページを開く。
- 誤ってPDF 2ページを収録していた危告示第2条の抜粋PDFを修正する。
- コード詳細の「整理済み情報」見出しを削除し、不要な空白を残さない。
- 原文中のP、LP、IBC、T、TP、BK、PP、B、VV、CV、V、SW、S、SP等をコード番号として認識し、検証済みページ対応が登録されているコードをIMDG Code該当ページへの直接リンクにする。ページ対応が未登録のコードには推定リンクを付けない。
- IBCコード詳細に、危告示別表第1備考6(3)(iii)の最大内容積表を参考表示する。
- 既存の色、フォント、罫線、角丸、余白を維持する。
