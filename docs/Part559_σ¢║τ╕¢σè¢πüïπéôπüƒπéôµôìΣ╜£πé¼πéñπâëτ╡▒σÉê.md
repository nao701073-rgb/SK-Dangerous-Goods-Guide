# Part559 固縛力参考算出 かんたん操作ガイド統合

## 目的
Part553～558で追加した入力完了表示、入力ミス防止、進行状況、次操作案内を整理し、通常利用者が固縛力参考算出から申請番号管理への登録まで同じ順序で操作できるようにする。

## 画面上の基本手順
1. 条件入力
2. 算出
3. 登録前確認
4. 申請番号管理へ登録

「かんたん操作ガイド」は入力状態、算出状態、登録前確認、登録先を監視し、現在位置と次の操作を1ボタンで表示する。

## 重複表示の整理
既存の Part553 入力状況・4段階表示、Part558 入力ミス防止カードは判定処理を残し、新ガイドが有効な場合は画面上で非表示とする。これにより既存ロジックを壊さず表示だけを一本化する。

## 安全側の扱い
- 直接固縛では貨物側MSL、CTU側MSL、鉛直角も確認対象とする。
- 引張系固縛材＋支保・当て材では支保材の個数・確認済み支保力も確認対象とする。
- 登録前確認を自動で完了させない。
- 登録先が未指定の場合は自動登録せず、申請番号入力へ案内する。
- 計算式、係数、MSL判定、方向別必要抵抗力、支保併用ロジックは変更しない。
