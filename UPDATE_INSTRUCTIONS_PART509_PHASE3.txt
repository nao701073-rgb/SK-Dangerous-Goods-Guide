Part 509 正式運用準備 第3段階 更新手順

1. Part 508適用済みフォルダを複製してバックアップしてください。
2. 本ZIPの内容を、フォルダ構成を維持したままPart 508フォルダへ上書きしてください。
3. serverフォルダで次を実行してください。
   npm run migrate
   npm run rights:scan
   npm run rights:catalog
   npm run security:phase3
4. APIを再起動してください。
5. システム管理者で「システム設定」→「著作権・社内公開範囲管理」を開いてください。
6. 資料台帳635件が表示されることを確認してください。
7. 外部公開する前に、決定台帳JSONを出力し、公開用パッケージを生成してください。

注意
- 初期台帳は権利確認済みではありません。すべて未確認です。
- 画面上の非表示だけでは直接URLを防げません。外部公開にはサニタイズ済みパッケージを使用してください。
- 契約・ライセンス・利用条件の最終判断は、権限を有する担当者が行ってください。
