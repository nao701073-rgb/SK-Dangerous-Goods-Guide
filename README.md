# SK Dangerous Goods Guide Part 500 差分更新

この差分はPart 499適用済みフォルダへ上書きしてください。

## 変更内容

- 各サブ画面のメニューを、ホーム画面のメインメニューと同じ項目・順序・アイコンへ統一
- 現在開いている機能をメニュー上で選択状態として表示
- 判定基準の国内法令を、標札表示・品名表示の国内法令と同じ全画面PDF表示様式へ統一
- 危告示別表第1 備考2の13種類の判定基準を、見出し・説明ボックス・整理表・注記付きPDFとして収録
- スマートフォンでは結合PDFと同内容の縦長画像を表示し、横スクロールなしで確認可能
- 備考2以外を参照する危険物も、タブ切替を使わず該当原文ページを1画面内で順番に表示
- Part 499までの火薬類標札表示およびEmS日本語併記を維持
