# SK Dangerous Goods Guide Part 503 差分更新

この差分は、**Part 502適用済みフォルダ**へ、フォルダ構成を維持したまま上書きしてください。

## 主な変更

### 1. 中央保存とバックアップ

- 申請情報、申請書、添付資料、写真をPostgreSQLと永続ストレージで中央管理
- ファイルのSHA-256照合、資料の版管理、取消し・復元
- 定期バックアップ、保管期間、遠隔保管、復元試験記録
- 「システム保守・バックアップ」画面に中央バックアップ状態を追加

### 2. サーバー側の権限制御

- APIでログイン、役割、事業所範囲を毎回検証
- ゲストによる申請番号管理、写真、添付資料の取得を拒否
- 画面の非表示だけに依存しない構成

### 3. 法令内容の人による承認

- 原典PDF、更新データ、変更セットを中央保存
- 作成者、原典照合者、承認者を分離
- 承認済み版のみ公開
- 「法令原典照合・承認管理」画面を追加

### 4. 訂正履歴

- 申請情報の訂正前後、理由、操作者、日時を版ごとに保存
- 申請番号管理画面から中央訂正履歴を確認
- 元の記録を上書きして消去しない

### 5. 読み込み速度

- 法令・コードマスターをメタ情報とコード情報へ分割
- 約1.46MBの全危険物判定割当データを通常画面では読み込まない構成へ変更
- Nginxのgzip・長期キャッシュを継続利用

## 重要

中央保存、サーバー側権限制御、自動バックアップ、共有監査履歴、人による承認ワークフローは、`server/` を配置しAPI接続した場合に有効です。GitHub Pages等の静的公開だけではこれらの機能は動作しません。

詳細は `docs/Part503_中央保存・権限制御・法令承認・訂正履歴・性能改善.md` を参照してください。
