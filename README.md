# SKDG v1.3 Update

SKDG v1.2を基準にした、現場操作の安定化・写真入力・容量整理更新です。

## 主な変更
- 申請書取込後の自動スクロール・連続再配置を整理し、画面のカクつき／崩れを抑止。
- ホームの重複した「よく使う機能」を削除。
- 関連法令の「拡張基盤」導入カード、関連資料の「資料レジストリ」導入カードを非表示。機能本体は維持。
- 固縛力参考算出は、ページ上部から「申請書・航路 → 写真 → 輸送条件・貨物 → 接触面 → 固縛材／支保・あて材 → 参考算出」の順で操作。
- 固縛材と支保・あて材を別カードに分離し、写真AIからそれぞれ候補表示。検査員が採用した候補だけ反映。
- 材質プルダウンが空になる原因だった報告書HTML内のscript終端不具合を修正。
- 強度の根拠、取付点別MSL台帳等の厳密入力は標準の簡単操作から外し、MSL・角度は写真入力を中心に整理。
- ホームと危険物検索の検索例を同一のUN1203/GASOLINE例へ統一。
- 全体容量監査を実施し、法令・IMDG・標札等を維持したまま、完全重複ファイルだけを安全確認後に削除できるPowerShellを同梱。

危険物検索、危険物詳細、関連法令、関連資料、原文参照、コード別画面、オーバーパック等の既存機能は削除していません。DBマイグレーションはありません。
