# SKDG v1.1 操作導線・画面構成まとめ改善

v1.0.1を基準に、現場で迷わず使えることを優先して複数のUI改善をまとめた更新です。

## v1.1の主な改善

### ホーム
- 主要6機能を「よく使う機能」としてホーム上部にまとめました。
- 危険物検索、申請書取込・確認、申請番号管理、固縛力参考算出、関連法令、関連資料へ1タップで移動できます。
- ユーザー設定で、よく使う機能の先頭だけ選べます。機能そのものを非表示にはしません。

### 申請書取込・確認
- 画面下部に「次の操作」を1つだけ表示します。
- 未取込時は「ファイルを選択」、取込後は「自動確認」、登録可能時は「申請番号管理へ登録」に自動で切り替わります。
- JSON/CSV出力と取込履歴は「補助出力・取込履歴」にまとめ、通常操作の邪魔にならないよう折りたたみました。
- v1.0.1の取込後レイアウト崩れ対策を維持します。

### 申請番号管理
- 標準の並びを「案件一覧 → 選択案件のメモ・操作 → 写真・添付」に寄せました。
- 詳細な案件入力画面は、新規作成・編集を明示したときだけ開きます。
- 高度な絞り込み条件は初期状態で閉じます。
- 運用キュー、日次進捗、削除証明等は通常画面へ戻していません。

### 固縛力参考算出
- v1.0.1の「申請書 → 輸送条件・貨物 → 写真 → AI候補 → 材質・接触状態 → 参考摩擦係数 → 不足項目 → 参考算出」を維持します。
- AI候補カード全体をタップして選択できるようにしました。
- 「表示中の候補を選択」「選択を解除」を追加しました。候補は検査員が操作するまで確定しません。
- 申請書・写真から候補入力できた項目は「不足項目」では初期状態で折りたたみ、「入力済みも表示」で確認できます。
- MSLや安全性を写真だけで自動確定しません。

### ユーザー設定
- v1.0.1の文字サイズ、大きな操作部品、動き抑制を維持します。
- 「ホームで最初に表示する機能」を1項目だけ追加しました。

## 変更していない重要機能
危険物検索、危険物詳細、標札、許容容量・許容質量、関連法令、IMDG参照、原文表示、関連資料、P/LP/IBC/T/TP/BK/PP/B/VV/CV/V/SW/S/SP等のコード画面、オーバーパック表示用作成、検索履歴は削除していません。

「システム状態」は引き続きシステム管理者（safety-environment-admin）だけに表示します。

DBマイグレーションはありません。
