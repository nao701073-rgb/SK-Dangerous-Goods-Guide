SKDG v1.3.14 Hotfix 更新手順
================================

対象
----
v1.3.13を適用済みのSKDGフォルダーへ上書きするHotfixです。
画面上の表示版は「Version 1.0 試作版」のままです。
DBマイグレーションはありません。

更新内容
--------
1. 「固縛力参考算出 ― 使用根拠」の原典ジャンプを全項目再検証。
2. 海上輸送 海域A/B/Cの根拠をCSS Code Table 2–4から、正しいCTU Code 第5章5.3（PDF page 17）へ修正。
3. 海域Bについて Hs、cx、cyを根拠欄に明記。
4. 直接固縛の摩擦75%をCTU Code PDF page 81へ直接接続。
5. 通常摩擦／例外摩擦をCTU Code PDF page 109／110へ分離。
6. 貨物側取付部MSL、CTU側固縛点MSL、採用MSLをCTU Code page 98 + CSS Code Annex 13 §4.4へ接続。
7. 不要指定されたCTU構造区分、コンテナ寸法、固縛方法等には原典ボタンを表示しない。
8. 「原典をまとめて確認」は表示しない。

手順
----
1. 現在のSKDGフォルダーをバックアップしてください。
2. SKDG_v1.3.14_Hotfix_Update.zip を展開します。
3. 展開されたフォルダー構成を維持したまま、v1.3.13フォルダーへ上書きしてください。
4. SKDGを開いているブラウザータブをすべて閉じます。
5. index.html を開き直してください。必要に応じて Ctrl+F5 を実行してください。
6. 固縛力参考算出 → 算出根拠を開く → 各「原典ページへジャンプ」を確認してください。

確認ポイント
------------
- 海上輸送 海域B → CTU Code PDF page 17
- 海域B: 8 m < Hs ≤ 12 m、cx=0.3、cy=0.7
- 直接固縛の摩擦75% → CTU Code PDF page 81
- 摩擦表 → CTU Code PDF page 109/110
- MSLと破断強度 → CTU Code PDF page 85
- 貨物側／CTU側取付点の最弱要素 → CTU Code PDF page 98
- CSS Code Annex 13 §4 / Table 1 → MSC.1/Circ.1623 PDF page 3

注意
----
- 「（標準）」は本システムの初期選択表記であり、CTU Codeの用語ではありません。
- MSL、取付点強度、施工条件は、刻印、メーカー仕様、証明書、試験成績、承認済みCargo Securing Manual等の確認済み資料を優先してください。
