SKDG v1.3.80 更新手順

基準：v1.3.79

1. ZIPを展開し、既存v1.3.79へ上書きしてください。
2. pages/ctu-securing-calculator.html を開きます。
3. 海上輸送A/B/Cを切り替え、算出結果の「方向別設計荷重」を確認します。
4. 10tの例では、A=前後29.43/側面49.05kN、B=前後29.43/側面68.67kN、C=前後39.24/側面78.48kNとなることを確認します。
5. 貨物質量を40%+60%へ分配する表示・計算がないことを確認します。
6. 直接固縛で貨物側MSLまたはCTU側MSLを空欄/0にした場合、簡単入力では算出を停止することを確認します。
7. 詳細入力では、3要素MSLがそろわない直接固縛は0kNとして扱い、警告が表示されることを確認します。
8. 固縛材MSL 12.1kN、貨物側20kN、CTU側10kNの場合は採用MSL 10.0kNのままであることを確認します。
9. 支保経路を使用した場合、同一経路のCTU境界抵抗が二重加算されないことを確認します。
10. 保守的モードでは、CTU境界・支保・直接固縛が無条件に単純加算されないことを確認します。
11. CSS Codeモードでは、CTU A/B/CではなくCSS Annex 13の船舶条件側計算が使用されることを確認します。
12. CSS Codeの速力欄は船舶のservice speedとして入力し、service speedが15kn未満でも15knへ強制されないことを確認します。
13. service speedより低い減速運航を根拠とする場合、横加速度にはその低減を適用できない旨の案内が表示されることを確認します。

注意：本機能は参考算出です。Cargo Securing Manual、承認図書、メーカー資料、刻印・証明書および実際の荷重経路を優先してください。
DBマイグレーションはありません。

【追加再監査】
- Annex 7 4.1.6に合わせ、CTU境界／支保の剛性経路と伸びを伴う直接固縛を同一滑動抵抗として単純加算しません。
- 剛性経路が成立する場合はmax(CTU境界, 支保)を採用し、直接固縛は同一滑動抵抗へ加算しません。
- 「承認済み併用」は根拠記録用とし、この参考算出の算術加算を再有効化しません。

- CSS Annex 13の表2/3/4/5、fz、MSL換算、CS=MSL/1.5・代替法1.35、有義波高fRを再照合済みです。
