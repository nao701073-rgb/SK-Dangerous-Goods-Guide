SKDG v1.3.13 Hotfix 更新手順
==============================

対象
----
v1.3.12を適用済みのフォルダーへ上書きしてください。

手順
----
1. 現在のSKDGフォルダーをバックアップします。
2. このZIPを展開し、フォルダー構成を維持したままv1.3.12へ上書きします。
3. 開いているSKDGタブを閉じます。
4. index.htmlを開き直し、必要に応じてCtrl+F5で再読み込みします。
5. 固縛力参考算出で次を確認してください。
   - CTU構造区分は「汎用コンテナ」とだけ表示される。
   - 汎用コンテナ時だけコンテナサイズ・種類が表示される。
   - 写真読込後、基準となる実寸に選択コンテナの内幅候補が入り、写真測定長さにもAI候補が表示される。
   - 「AI寸法補助：…収納可能…」の表示が出ない。
   - 算出根拠の「原典をまとめて確認」がない。
   - CTU構造区分、コンテナ寸法、固縛方法、本数等に不要な原典ボタンがない。
   - 海上輸送条件およびCTU側固縛点MSLの原典はCSS Code Annex 13の該当ページへ接続する。

DB
--
DBマイグレーションはありません。

表示版
------
Version 1.0 試作版を維持します。
