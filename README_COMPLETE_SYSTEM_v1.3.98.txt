SKDG / 検査・検品業務サポートシステム
v1.3.98 COMPLETE VERIFIED SYSTEM
作成日: 2026-08-10

【位置づけ】
本パッケージは部分更新ではありません。v1.3.91-complete を基準に、v1.3.92 以降の固縛力参考算出に関する必要変更を再統合した完全版です。

【固縛力参考算出の主な統合内容】
・PC初期表示は1列。ページ最上部の「1列表示 / 2列表示」で手動切替。
・2列表示では Step1+2 / Step3+4 / Step5+壁抵抗確認 を実際に左右配置。Step6は全幅。
・壁抵抗確認を Step5 と Step6 の間へ配置。
・前/後/左/右の方向別壁抵抗採否と15cm隙間候補を統合。写真/AI候補だけでは壁抵抗を自動採用せず、検査員確認を必須とする。
・壁抵抗チェック変更後の自動再算出と算出状態同期。
・前後/左右の同率重点方向表示。
・Step5の入力順、表示数、幅を統一。採用MSLを明示。
・Step6に現在の算出条件、現在判定の強調、重点確認方向、必要抵抗力/評価抵抗力/余裕不足を整理表示。
・v1.3.91までのExcel申請書取込、申請番号引継ぎ、備考UN重量取込等を保持。

【配置】
既存のv1.3.91-completeをバックアップしたうえで、本完全版の内容をプロジェクトルートへ配置してください。
Git管理環境では .git / .github / .vscode / 環境固有の .env 等を意図せず削除・上書きしないでください。

【重要】
固縛力参考算出は業務上の参考算出です。壁抵抗、支保、固縛、MSL、接触条件等については、写真AI候補だけで確定せず、検査員の現場確認・仕様資料・メーカー資料等を優先してください。
