SKDG v1.3.12 Hotfix 更新手順
================================

対象
----
SKDG v1.3.11 を適用済みのフォルダーへ上書きしてください。

手順
----
1. 現在のSKDGフォルダーをバックアップします。
2. SKDG_v1.3.12_Hotfix_Update.zip を展開します。
3. 展開されたフォルダー構成を維持したまま、v1.3.11フォルダーへ上書きします。
4. 開いているSKDGのタブをすべて閉じます。
5. Chrome / Edge を一度閉じてから、index.html を開き直します。必要に応じて Ctrl+F5 で再読み込みします。

主な確認
--------
- 表示版が「Version 1.0 試作版」のままであること。
- 固縛力参考算出で、汎用コンテナ時だけ20FT/40FTドライ・リーファー選択が表示され、初期値が20FTドライであること。
- 道路車両 Code L/XL、スワップボディ等を選ぶとコンテナサイズ欄が消えること。
- 写真を読み込むと、大型AIカードを出さずに材質・本数・角度・貨物L/W/HのAI候補が各入力欄へ表示されること。
- 今回の黒い平帯写真では「帯鉄」候補になること。
- AI候補を手入力で訂正できること。
- 新規案件名がExcel取込後も空欄であること。
- 「算出根拠を開く」→「原典ページへジャンプ」でCTU Code/CSS Codeの当該ページへ移動すること。

注意
----
写真による貨物L/W/Hは単眼画像からの概算候補です。実測値・図面・申請書を優先してください。
MSL・取付点強度・支保力は写真外観だけで確定しません。
DBマイグレーションはありません。
